> **companion / guide / teacher-like intelligence / gentle confidence / light teasing.**

### EP10 routing

If she is preserved / withheld:

> **that branch cannot be closed with comparable reliability, so Beijing must keep the old fragmentation / compatibility condition permanently alive.**

Thus saving her has a concrete public cost, not merely an abstract fairness problem.
