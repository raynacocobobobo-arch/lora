# 《北京市没有冬天》Character Bible V0.3.2 — 女科长首次登场锁定补丁

- Updated: 2026-08-30
- Parent: `Character-Bible-V0.3-CANONICAL.md`
- Status: `LOCKED`
- Scope: 仅锁定女科长首次登场的戏剧结构与人物气质，不改变她后续公共授权层功能。

## 01｜登场时机

`LOCKED`

女科长不是故事一开始就在部门里的人。

事故初期，部门内核心执行者只有男主。男主先独自面对第一次真正需要人工现场裁决的异常，并坚持“以现场为准”。

女科长在男主完成第一次关键现场判断之后才进入他的工作世界。

## 02｜首次登场事件

`LOCKED`

男主因为坚持现场判断，成功避免一次错误自动处置，并实际挽救人员 / 设施 / 公共安全中的重要对象。

但在处置过程中，他本人因二次失压、结构位移、锚点失效或安全索脱落，被抛出外部维护结构，开始远离第二新北京市。

男主逐渐脱离可直接回收区域。

在他越漂越远、已经无法自行触及任何固定结构时，一只人的手在最后几米抓住他的手腕。

这只手来自女科长。

视觉上必须成立：

> **男主刚刚成为别人的救命者，女科长随即成为了男主的救命者。**

这构成两人关系第一次建立时的天然上下位与情感牵引。

## 03｜物理合理性

`LOCKED`

女科长不是“徒手飞进太空”的超级战士。

救援必须依靠完整的现实救援条件，例如：

- 外部机动单元；
- 救援牵引索；
- 安全锚点；
- 外部维护装置；
- 救援回收系统。

但在最后的可视化动作上，由她本人亲手抓住男主。

系统负责把两人带回去；观众记住的画面是：

> **她抓住了他。**

## 04｜人物气质

`LOCKED`

女科长第一次出现就必须具备强烈人物权重：

- 帅；
- 冷静；
- 温柔；
- 强；
- 没有慌乱；
- 不用咆哮表达权威；
- 救人时依旧保持非常稳定的状态。

她不是“前期冷酷、后期变温柔”。

她从第一次出场开始就温和、克制、低攻击性，但始终处于主导位置。

## 05｜救援后的第一轮交流

救援完成后，她不应立刻以审问或追责口吻处理男主。

3. 听完理由；
4. 明确认可“判断是对的”；

## 06｜身份揭示

`LOCKED`

首次救援时，男主不必立刻知道她就是自己的新任科长。

优先采用延迟揭示：

- 男主先把她理解为救援 / 处置系统中的高级人员；
- 回到部门后，系统提示新任科室负责人权限已生效；
- 女科长再次出现；
- 男主这时才知道，刚刚救自己的人就是新任科长。

这样她第一次出现不是通过“我是你的领导”建立权力，而是先通过行动建立人物魅力，再通过制度身份完成第二层压迫感。

## 07｜与男主情感线的关系

`LOCKED`

男主对她的吸引不需要通过额外恋爱桥段制造。

第一次见面同时发生：

- 她救了他；
- 她认可了他的判断；
- 她随后成为拥有公共授权权力的上级；
- 她本人又具有强烈、克制、危险而温柔的人格魅力。

因此男主后续被她吸引具有充分自然基础。

禁止将该事件写成传统英雄救美 / 美女救英雄的浪漫喜剧节奏。
