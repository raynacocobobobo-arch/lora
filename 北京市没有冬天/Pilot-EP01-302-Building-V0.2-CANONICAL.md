# 03｜302楼：不是“确认一栋楼”，而是确认里面的人

`LOCKED`

302楼在物理世界中真实存在，楼内仍有人。

但事故后的某一层区域结构 / 公共系统模型把302楼判定为：

> **不存在 / 已失去有效结构身份 / 不再计入当前相关模型。**

精确系统术语 `TBD`。

该错误前提正在触发真实的自动结构 / 重力状态处置。

核心戏剧事实不是：

> “数据库里有没有302楼。”

而是：

> **系统认为这里没有需要保护的人，但男主在现场确认有人真实存在。**

小女孩是这一事实的主要人物化锚点。

男主在现场看到 / 听到 / 以物理方式确认她的存在。具体方式 `TBD`。

因此第一次核心判断应服务：

> **数字系统说她不存在；现场告诉男主，她就在这里。**

这构成“以现场为准”的第一集人物化表达。

# 04｜302楼的核心物理异常：局部重力方向反转

`LOCKED PHENOMENON / ENGINEERING TBD`

302楼的主要物理危险不再定义为“结构把男主甩出去”。

新的锁定现象是：

> **302楼局部重力方向出现异常偏转，并在关键阶段发生反转。**

这不是普通失重，也不是魔法式反重力。

现场表现方向可以包括：

- 水或碎屑开始沿不符合日常“向下”的方向移动；
- 悬挂物、家具、人体受力方向逐渐异常；
- 局部空间仍保留熟悉建筑几何，但“下方”开始失效；
- 最终稳定生活区原本的重力方向发生明显反转。

具体视觉节奏 `TBD`。

必须满足：

- 该异常来自轨道城市真实结构 / 参考系 / 控制状态冲突中的某种工程原因；
- 不新增一套方便剧情的万能反重力设备；
- AI / 自动系统仍然可以局部合理；
- 错误关键来自统一参考 / 结构模型前提失效，而不是 AI 突然变笨；
- 男主必须亲自进入系统无法可靠验证的现场；
- 男主的介入仍然是阻止 / 冻结 / 修正一项基于错误前提的处置，而不是掌控整套城市重力；
- 302楼最终被暂时保住。

精确工程原因，包括旋转结构、载荷、参考系、控制节点、连接结构、局部重力生成方式之间的因果关系，全部 `TBD`，必须在 screenplay lock 前单独校验。

# 05｜男主深入危险的理由

`LOCKED`

男主不是为了证明自己、逞英雄或吸引女科长注意而深入危险。

他继续往里走，是因为：

> **只有进入现场，才能确认系统无法验证的关键物理状态；如果不确认，错误处置会继续作用在真实存在的居民和建筑上。**

因此他的行动同时建立：

- 职业能力；
- “以现场为准”的原则；
- 他在少数事实冲突案例中为什么不可直接替代；
- 他对“自己的判断终于真的有用”的第一次正反馈。

该正反馈是后续 B Story 的种子，但 EP01 不直接让男主口头承认这种满足感。

# 06｜小女孩：Two-Beat Civilian Echo

`LOCKED DIRECTION`

小女孩不作为独立长期支线主角，也不需要复杂家庭背景。

她承担：

> **Two-Beat Civilian Echo**

### Beat 1｜EP01

- 她是302楼内真实存在的人；
- 男主的现场判断帮助阻止302楼因错误模型 / 重力异常继续恶化；
- 对她而言，男主第一次帮助确认的是：
  > **她、她的家、她所在的楼都真实存在。**

### Beat 2｜中后段

最低共同现实重建推进后，302楼仍然被承认：

- 真实存在过；
- 居民真实生活过；
- 男主当初救它是正确的。

但由于统一后的结构 / 公共安全 / 城市重连条件，302楼可能无法继续作为永久公共住宅留在未来北京中。

因此小女孩需要再次出现，形成回声：

> **前面的问题是“我们存在吗？”**
>
> **后面的问题变成“既然我们真的存在，为什么还是不能留下？”**

这用于体现：

> **物理真实 ≠ 永久公共有效。**

以及：

> **恢复共同现实不是判断哪些过去是真的，而是决定哪些真实发生过的东西能够共同进入未来。**

302楼最终退出的精确原因、迁移方式、小女孩台词与后续命运全部 `TBD`。

# 07｜世界观延迟揭示：先藏住“这里不在地球”

`LOCKED`

EP01 前段应尽可能让第一次观看的观众把场景理解为：

> **某个高度未来化但仍然像北京的城市。**

不要在开场直接用：

- 月球大全景；
- 轨道城市完整外景；
- 明确宇宙窗景；
- 解释性字幕；
- 角色对白直接告诉观众“我们在绕月轨道”。

局部生活空间保持正常、成熟、城市化，正常状态下重力方向稳定。

观众应先接受“这是北京”，再发现“北京并不在地球”。

# 08｜重力反转：男主“向天空坠落”并完成第一次轨道北京 Reveal

`LOCKED`

男主成功完成关键现场判断 / 阻止错误处置后，302楼局部重力异常并未立即恢复。

在关键阶段：

> **局部重力方向发生反转，男主开始沿原本观众会理解为“向上 / 向天空”的方向坠落。**

这明确取代 V0.1 中“男主被结构甩出 / 抛离”的设定。

这一动作必须是：

> **正确现场判断完成后，残余物理异常继续产生的危险后果。**

不是男主无意义鲁莽导致。

世界揭示顺序方向：

1. 男主开始违反观众日常直觉地“向天空坠落”；
2. 原本类似天空 / 城市边界的空间出现事故裂隙或外部开口；
3. 裂隙后首先出现真正的黑色外部空间；
4. 男主进一步接近 / 越过局部安全城市边界；
5. 观众第一次看到巨大的地球；
6. 随镜头展开，才真正理解这是一座巨型轨道城市 / 城市复合体。

“天空裂隙”的精确建筑性质、男主是否真正越过气密边界、外部安全层级、地球相对大小、月球是否同时出现与具体轨道几何均 `TBD`，必须遵守已锁绕月轨道世界设定。

核心体验：

> **一个人在北京里向天空坠落，然后观众才发现所谓天空外面是真正的宇宙。**
