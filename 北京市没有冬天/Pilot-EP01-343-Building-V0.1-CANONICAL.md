该变化不能写成幸灾乐祸，而是：

# 03｜343楼：不是“确认一栋楼”，而是确认里面的人

`LOCKED`

343楼在物理世界中真实存在，楼内仍有人。

但事故后的某一层区域结构 / 公共系统模型把 343楼判定为：

> **不存在 / 已失去有效结构身份 / 不再计入当前相关模型。**

精确系统术语 `TBD`。

该错误前提正在触发真实的自动结构处置。

核心戏剧事实不是：

> “数据库里有没有343楼。”

而是：

> **系统认为这里没有需要保护的人，但男主在现场确认有人真实存在。**

小女孩是这一事实的主要人物化锚点。

男主在现场看到 / 听到 / 以物理方式确认她的存在。具体方式 `TBD`。

因此第一次核心判断应服务：

> **数字系统说她不存在；现场告诉男主，她就在这里。**

这才构成“以现场为准”的第一集人物化表达。

# 04｜343楼的物理危险

`LOCKED FUNCTION / ENGINEERING TBD`

系统不是因为“愚蠢”而攻击一栋楼。

真正方向是：

> **相关自动结构控制正在按照“343楼不再属于当前有效结构模型”的前提，继续进行事故后的结构 / 载荷 / 旋转体系重配置。**

如果继续执行，真实存在的343楼会进入严重结构失稳，最终可能被撕裂 / 解体 / 失去安全承载能力。

当前只锁功能，不锁工程解释。

必须满足：

- AI / 自动系统仍然可以局部合理；
- 错误来自统一参考 / 结构模型前提失效，而不是 AI 突然变笨；
- 男主必须亲自深入系统无法可靠验证的现场；
- 男主的介入是冻结 / 阻止 / 改变一项正在发生的错误自动处置，而不是用万能权限“修好全城”；
- 343楼最终被暂时保住。

“重力撕裂”的具体物理机制、结构连接、载荷路径、旋转参数等全部 `TBD`，后续必须单独做工程逻辑校验。

# 05｜男主深入危险的理由

`LOCKED`

男主不是为了证明自己、逞英雄或吸引女科长注意而深入危险。

他继续往里走，是因为：

> **只有进入现场，才能确认系统无法验证的关键物理状态；如果不确认，自动处置会继续作用在真实存在的居民和建筑上。**

因此他的行动同时建立：

- 职业能力；
- “以现场为准”的原则；
- 他在少数事实冲突案例中为什么不可直接替代；
- 他对“自己的判断终于真的有用”的第一次正反馈。

该正反馈是后续 B Story 的种子，但 EP01 不直接让男主口头承认这种满足感。

# 06｜小女孩：Two-Beat Civilian Echo

`LOCKED DIRECTION`

小女孩不作为独立长期支线主角，也不需要复杂家庭背景。

她承担：

> **Two-Beat Civilian Echo**

### Beat 1｜EP01

- 她是343楼内真实存在的人；
- 男主的现场判断帮助阻止343楼因错误模型继续失稳；
- 对她而言，男主第一次帮助确认的是：
  > **她、她的家、她所在的楼都真实存在。**

### Beat 2｜中后段

最低共同现实重建推进后，343楼仍然被承认：

- 真实存在过；
- 居民真实生活过；
- 男主当初救它是正确的。

但由于统一后的结构 / 公共安全 / 城市重连条件，343楼可能无法继续作为永久公共住宅留在未来北京中。

因此小女孩需要再次出现，形成回声：

> **前面的问题是“我们存在吗？”**
>
> **后面的问题变成“既然我们真的存在，为什么还是不能留下？”**

这用于体现：

> **物理真实 ≠ 永久公共有效。**

以及：

> **恢复共同现实不是判断哪些过去是真的，而是决定哪些真实发生过的东西能够共同进入未来。**

343楼最终退出的精确原因、迁移方式、小女孩台词与后续命运全部 `TBD`。

# 07｜世界观延迟揭示：先藏住“这里不在地球”

`LOCKED`

EP01 前段应尽可能让第一次观看的观众把场景理解为：

> **某个高度未来化但仍然像北京的城市。**

不要在开场直接用：

- 月球大全景；
- 轨道城市完整外景；
- 明确宇宙窗景；
- 解释性字幕；
- 角色对白直接告诉观众“我们在绕月轨道”。

局部生活空间保持正常、成熟、城市化，重力方向稳定。

观众应先接受“这是北京”，再发现“北京并不在地球”。

具体物理过程 `TBD`。

这一动作必须是：

> **他完成正确现场判断之后产生的危险后果。**

不是因为无意义鲁莽。

世界揭示顺序方向：

1. 原本类似“天空 / 城市边界”的空间出现破裂或外壳裂口；

3. 男主进一步脱离局部城市空间；
4. 观众第一次看到巨大的地球；
5. 随镜头展开，才真正理解这是一个巨型轨道城市 / 城市复合体。

> **观众与男主一起从熟悉的北京局部空间，突然跌入真实宇宙尺度。**

`LOCKED MACRO BEATS / TIMING TBD`
