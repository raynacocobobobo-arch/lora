# 《北京市没有冬天》EP04 — LATEST CANON SNAPSHOT V1

- Updated: 2026-08-31
- Status: `LOCKED / LATEST CONSOLIDATED SNAPSHOT`
- Base: `Pilot-EP04-Cinema-Daily-Life-V0.1-CANONICAL.md` + later character/relationship decisions.

## 01｜核心定位

`LOCKED`

EP04 是第一集真正意义上的 **灾后日常 / 呼吸集**。

不是再制造一个大灾难，而是让观众看到：

> **北京已经严重割裂，但人仍然上班、处理小问题、看电影。**

男女主经过若干小型事实冲突工作后，最后来到电影院。

电影院内部的记录 / 系统对“今晚这场放映是否成立”存在冲突。

他们不追求恢复电影院完整历史，只确认：

> **足以让今晚这场电影继续放映的事实。**

Dominant turn：

> **现实不必先被完全统一，人也可以在有限共同事实中继续生活。**

## 02｜《罗生门》

`LOCKED`

- 放映影片为《罗生门》；
- 女科长是真的喜欢电影，不是为了向观众讲主题才看；
- “Rashomon”只形成生活层和主题层的轻微映照：不同叙述可以并存，但公共行动仍需要足够事实；
- 不安排角色对电影做理论讲解。

## 03｜三人关系第一次完整进入私人时间

`LOCKED FUNCTION`

EP04 需要让：

- 男主；
- 女科长；
- 私人伴随 AI；

第一次在非高压危机中自然共处。

功能不是三角恋，而是建立三个不同认知主体之间的工作外存在。

私人 AI 此时仍是与男主共同持续经历时间的长期连续人格；这为 EP05 的“根据资料生成的 AI 新人”提供连续性对照。

男主 + 私人 AI 的固定居家生活、日常仪式和家庭空间行为仍然 `TBD / NEEDS_REVIEW`，EP04 不得顺手把这些锁死。

## 04｜女科长

- 她可以自然留下看电影；
- 她不是时时刻刻代表制度讲话；
- EP04 必须让观众看到她有自己的普通兴趣和生活感，否则后面公共责任会变成单一“领导功能”。

## 05｜三个主题词

## 06｜结构功能

EP03 → EP04：从一次紧张的有限连接，进入已经逐渐形成的事实冲突处置日常。

EP04 → EP05：

> 先让生活看起来正在继续；
> 再让 EP05 用一场婚礼提醒观众，有些人的时间并没有继续。
