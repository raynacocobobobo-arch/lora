# 01｜EP05 核心不变

EP05 仍然是 **Wedding Mirror**。

既有锁定继续成立：

- 开场从 EP02 的男主 / 女科长公共现场开始；
- 镜头转到与他们擦肩而过的普通女人；
- 真人新郎已经在最初陨石事故中失去；
- 真人新娘在 EP02→EP03 之间只是继续普通生活，不是在筹备婚礼；
- 她逐渐意识到“暂时”正在成为真实生活结构；
- EP03 的成功真实改变人们对有限跨区流动的判断；
- 婚礼阶段较早允许观众识别新郎是 AI 投影 / 人格重建；
- 观众表面故事 = **真人新娘活到今天 + AI 新郎完成迟来的婚礼**；
- 唯一大 Reveal = **新娘也不是从 EP02 连续活到今天的真人，而是 AI 人格化投影 / 重建**；
- 私人 AI 继续作为“观众真正跟随其连续跨过多集”的正面对照；
- EP05 人工 / 投影雪之后出现极少量真实局部雪，递给 EP06；
- 主题继续：**连续｜承诺｜失去**。

本次 V3 只关闭此前唯一开放的宏观机制：

> **真人新娘后来怎样失去连续性。**

# 02｜新锁定：不是“EP03 通道事故”，而是“成功连接改变生活选择后的新暴露面”

`LOCKED / HIGH PRIORITY`

明确禁止把新娘失去连续性简化成：

> **EP03 开了一条路 → 她后来在同一条路上发生交通事故 / 直接死亡。**

这会把 EP03 的复杂后果降格成“成功其实是错误”。

当前锁定的因果功能是：

> **EP03 真实做成一次有限跨区连接以后，城市里的行为预期发生变化；人们第一次重新相信有限跨区移动可以作为真实生活选择。真人新娘也因此重新安排自己的生活，并迁居 / 调整到另一个局部区域。她在那里真正生活了一段时间。随后持续群岛化使该区域再次失去稳定共同连接，她的连续人生由此从北京共同可验证现实中中断。**

关键：

> **EP03 没有“害死她”。**

更准确：

> **EP03 的成功创造了新的生活可能；围绕这种可能形成的新生活，也暴露在此前不存在的新风险里。**

这属于 Preservation Paradox 的私人生命版本。

# 04｜连续性中断方式：区域再次失去稳定共同连接

`LOCKED_DIRECTION`

后来，北京继续群岛化。

新娘所在区域再次进入：

> **与其他北京失去稳定共同连接 / 转入更彻底本地运行。**

这里不锁成：

- 爆炸；
- 列车事故；
- 气闸事故；
- 七分钟错位复刻；
- 授权冲突复刻；
- EP08 式武装冲突；
- 某个反派行为。

重要的是：

> **这次失联最初看起来甚至仍像城市已经习惯的“暂时中断”。**

真人新娘最后一个可确认的连续状态，应该发生在：

> **区域完全失去共同可验证连续性之前。**

她最后一场真人戏不需要是遇险。

更推荐：

> **一个普通生活状态。**

她已经在新地方生活、工作、买东西、独自处理日常，甚至比 EP02 时更能继续向前。

这使失去真正落在：

> **一个正在继续生活的人。**

# 05｜关键锁定：后来“数据回来了，人没有回来”

`LOCKED / CORE CONTINUITY FUNCTION`

区域失去稳定共同连接之后，真人新娘不再作为同一个连续主体被北京重新确认。

但之后，城市可以通过某种有限方式重新取得她在失联前 / 失联期间留下的部分数据。

可用来源功能包括：

- 自动缓存；
- 延迟数据包；
- 本地档案；
- 设备 / 存储回收；
- 后续有限读取；
- 其他自然数据残留。

具体技术媒介继续 `TBD`。

只锁：

> **关于她的大量真实信息后来可以被重新得到，但这不等于她作为同一个连续主体重新回来。**

内部简写：

> **数据恢复 ≠ 连续性恢复。**

这些真实留下的数据，后来成为婚礼 AI 新娘人格重建的资料来源之一。

注意：

> **这不是上传她，也不是她预先制造自己的数字替身。**

婚礼 AI 新娘仍然是：

> **基于真实留下的信息、关系与记录形成的后续人格重建。**

# 06｜Fairness Rule：观众自动补连续性，但剧本不能作弊

`LOCKED`

真人新娘最后一个可确认连续状态之后，必须进入时间省略。

之后婚礼阶段出现高度一致的“她”。

观众因为前面真实跟随过她，会自然补出：

> **她后来从失联区域出来了，并活到了今天。**

但剧本实际从未证明：

> **EP02 那个真人新娘从 A 点连续活到了婚礼 B 点。**

因此继续守住 V2 Fairness Rule：

- 空白期之后不能出现只有连续真人肉身才能完成、且明确跨越空白期的证据；
- 不通过虚假闪回来欺骗；
- 不偷偷给观众错误时间戳；
- 不用“原来之前那些真人画面也是 AI”这种反悔式揭示。

A 点真人历史全部真实。

B 点婚礼人格也真实存在。

错的是观众自动补出的：

> **A → B 一定是同一个主体连续活过来。**

# 08｜EP03→EP05 与 EP03→EP08：同一成功的两条后果分支

`LOCKED / CROSS-EPISODE`

EP03 的成功产生两条不同后果线：

### 私人生活分支 → EP05

> **有限跨区移动重新成为可信生活选择 → 普通人重新安排人生 → 新依赖 / 新暴露面 → 新娘 continuity break。**

### 公共制度分支 → EP08

> **一次成功通道被复用 → 运营习惯 → 管理 / 安全 / 排序 → 地方公共秩序重叠 → 正当性冲突。**

因此 EP05 与 EP08 不重复。

EP05 问：

> **成功连接如何改变一个人的生活轨迹？**

EP08 问：

> **成功连接如何长期沉积成公共制度冲突？**
