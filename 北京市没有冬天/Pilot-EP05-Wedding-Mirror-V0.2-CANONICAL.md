# 03｜EP05 是 EP02 的社会回响

`LOCKED`

EP02 中，北京不断出现：

- 区域失联；
- 桥梁 / 结构分离；
- 人员伤亡不明；
- 不同现场行动组失去联系；
- 孤岛逐渐形成。

这些信息在 EP02 中首先以系统状态、现场任务和城市尺度出现。

EP05 的功能之一是把其中一个抽象状态：

> **“人员失联 / 状态未确认”**

重新变成一个具体的人和一个具体家庭的时间伤口。

内部结构可概括为：

> **EP02 给数字和状态；EP05 给脸、关系与未完成的人生。**

# 04｜婚礼的社会氛围：婚礼，同时也像纪念 / 等待仪式

`LOCKED DIRECTION`

EP05 的婚礼仍是真正的婚礼，不改写成纯追悼会。

但由于真人新郎在群岛化事故中处于：

> **失联、未确认死亡、无法返回**

的状态，婚礼现场自然带有一种更大的社会背景：

- EP02 后有多名现场人员、居民和行动组成员仍失联；
- 城市里开始出现等待、纪念、原定仪式继续举行等不同私人回应；
- 来宾中可以有灾后处置体系人员、其他部门人员、家属或普通朋友；
- 整体感受接近“大家来到这里，不只是参加一个普通婚礼，也在面对那一批还没有答案的人”。

但不得写成统一官方大型追悼大会。

婚礼仍然属于新娘自己的私人选择。

来宾规模、具体邀请逻辑、是否有其他失联家庭、仪式正式名称全部 `TBD`。

# 06｜为什么必须放在 EP04 后

`LOCKED`

EP04 已经建立：

- 男女主有稳定工作日常；
- 两人第一次自然共享非工作时间；
- 私人伴随 AI、男主、女科长三人关系第一次完整呈现；
- 城市在严重割裂中仍然继续工作、放电影、维持普通生活。

EP05 随后重新把 EP02 的后果推回来：

> **日常可以恢复，但失联者并没有因此回来。**

因此 EP04 → EP05 的节奏必须形成反差：

> **先让观众感觉生活正在继续，再提醒观众有些人的时间仍停在群岛化那一天。**

# 07｜EP04 的私人伴随 AI → EP05 的 AI新郎

`LOCKED FUNCTION`

EP04 刚让观众充分体验：

> **私人伴随 AI 是与男主共同持续经历时间的长期人格关系。**

EP05 紧接着出现 AI新郎：

> **根据真人新郎长期留下的信息生成的“像他”的 AI影像。**

因此 EP04 → EP05 必须产生自然对照：

- 两者都可能高度拟人；
- 两者都可以让人产生真实情感；
- 但人格连续性和共同经历的性质不同。

本集不需要用理论对白解释这一差异。

优先让观众通过连续两集的体验自行感受到区别。
