# 01｜核心事件不变

`LOCKED`

两个区域都需要同一个 AI hub / 共享中枢资源维持更好的运行状态。

女科长此前已经基于当时信息做出合理、部分执行的分配 / 接入判断。

新的实际状态出现后，原来的二选一失效。

所有人自然继续问：

> **hub 到底给 A，还是给 B？**

私人 AI 最终重新定义问题：

> **为什么 hub 必须被保存？**

第三路：

> **永久退出 / 切掉 hub，让 A、B 两边都以更低能力继续存在。**

结果：

- hub 永久失去；
- A 活下来；
- B 活下来；
- 两边都降级；
- 一部分维护连续性 / 未来能力永久结束；
- 维护人员最终状态仍不得擅自美化。

Dominant Turn：

> **第三路可以改变谁付代价，但不能把代价变成零。**

# 02｜V2 最高修正：EP07 是第一次局部承认“全部保存失败”

`LOCKED / HIGH PRIORITY`

EP01–EP06 的默认目标一直是：

> **尽可能全部保存。**

大家想：

- 保人；
- 保结构；
- 保交通；
- 保医疗；
- 保生活；
- 保两边的时间 / 冬季；
- 保住以后还能接回完整北京的可能。

EP07 第一次遇到一个无法继续维持这个默认目标的具体问题：

> **A、B、hub 三者不能全部保存。**

所以这一集真正的思想转轴不是：

> “AI想到聪明第三路。”

而是：

> **第一次有人承认：我们必须从“需要保存的对象集合”里主动拿掉一个真实、有价值、仍然可以工作的东西。**

这就是：

> **“全部保存”第一次局部失败。**

---

# 03｜为什么 EP07 仍然不是 EP10 的主动收缩

`LOCKED / CRITICAL DISTINCTION`

EP07 虽然第一次主动舍弃一个正常设施，但目标仍然是：

> **最大化保存 A + B 两个主体 / 区域。**

所以：

> **舍 hub，是为了保更多。**

并没有进入：

> **“真实、可继续的一个区域 / 人格主体也可以为了未来边界主动退出。”**

内部类比：

> **切掉一个器官，是为了保住身体。**

EP09 / EP10 才进一步问：

> **如果“身体的一部分”本身也真实、仍然有生活、甚至技术上还能继续，我们是否仍可以选择不把它带进未来？**

因此：

- EP07 = `local preservation break`；
- EP09 = `institutionalize the break`；
- EP10 = `city-scale active contraction`。

不能再把三者混成同一层。

`LOCKED`

# 05｜V2 新增：EP06 的经验在 EP07 被历史化 / 内化

`LOCKED CHARACTER ARC`

EP06 私人 AI 已经亲身经历：

- 女科长能够临时使用她的判断，但公共权力也受边界限制；
- 女科长不能把自己一边的“现在”强制变成全北京标准；
- 三个人都必须接受自己只拥有一部分现实；
- 公共规则不是“谁有权谁说了算”，而需要能够反过来限制所有参与者。

EP07 她开始读“你们留下来的东西”以后，把：

- 与男主长期相处中“可以不同意而关系不破裂”的经验；
- 女科长的权限自我约束；
- EP06 共同 reference 的经验；
- 北京历史 / 事故 / 公共选择留下的记录；

逐渐抽象成自己的内部判断原则：

> **规则如果只在代价落到别人身上时成立，就不是共同规则。**

不是角色必须说出的金句。

它是她后半季独立判断的底层。

# 06｜这个原则怎样真实进入 hub 案件

`LOCKED FUNCTION`

原来的 A/B 问题隐含一种不对称：

> **默认 hub 一定要保，所以必须让 A 或 B 中一个承担完整失去。**

私人 AI 重新检查这个默认前提。

她的思路不是：

> “数学上切 hub 总效用更高。”

而是：

> **为什么我们只讨论让 A 或 B 付完整代价，却把 hub 的继续存在当成不可触碰的前提？**

于是第三路把代价重新分配：

- A 不被完整牺牲；
- B 不被完整牺牲；
- hub 退出；
- A、B 都承担降级。

这正是原则的第一次现实应用：

> **共同规则不能只要求某一方成为代价。**

但仍然没有无损答案。

# 07｜第三路不是正义答案

`LOCKED`

V2 必须继续防止一种误读：

> **“大家平均倒霉，所以公平。”**

不成立。

切 hub 后：

- 两边能力下降程度未必相同；
- 谁失去的具体服务未必对称；
- hub / 维护链自身是真实损失；
- “平均分配损失”不自动等于正义。

本集只能证明：

> **A/B 二选一不是唯一可能的代价分配。**

不能证明：

> **第三路就是绝对公平。**

`LOCKED / V3.2`

# 09｜男主：第一次接受“第三路仍然意味着真正失去”

`LOCKED`

男主前面越来越擅长：

- 找现场；

- 做成一次有限连接；

但他仍然倾向：

> **只要能多保一点，就继续多保。**

所以 EP09 的 302 对他仍然会痛。

# 11｜EP07 → EP08：局部“全部保存失败”必须被系统级证明

`LOCKED / NEW CAUSAL LINK`

如果 EP07 后剧情立刻跳 EP09，观众可能把切 hub 理解成：

> **保全行为本身开始互相伤害。**

> **EP08 = 系统证明继续以“完整保全”为目标会产生公共灾害。**

这才给 EP09 足够理由改变城市治理目标。

# 13｜主题词不改，但解释加深

> **不可逆｜牺牲｜降级**

### 不可逆

hub 永久退出，不是临时故障。

### 牺牲

不是“牺牲很伟大”，而是：

> **第一次主动承认全部保存失败，并决定哪一项不再保存。**

### 降级

第三路的成功不是恢复，而是：

> **两个区域都以更差状态继续。**
