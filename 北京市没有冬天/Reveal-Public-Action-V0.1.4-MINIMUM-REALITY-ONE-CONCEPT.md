# 01｜只保留一个核心概念

`LOCKED / SUPERSEDES NARROWLY`

第一季不需要让观众理解两套并列理论：

- 最低共同现实；
- 最小共同体。

角色与公共行动线只保留：

> **最低共同现实。**

它同时回答：

- 哪些公共事实 / 规则必须重新共同有效；
- 哪些区域 / 连接 / 基础设施能够在这些共同条件下继续属于同一座北京；
- 哪些真实存在过的局部状态必须退出未来公共运行。

# 02｜“最小共同体”降为结果描述

`LOCKED`

`Reveal-Public-Action-V0.1.2-MINIMUM-COMMON-CITY.md` 已锁的物理结果继续有效：

> **北京不会完整恢复；它会永久失去一部分区域、连接、基础设施和数字连续性，并实际变得更小。**

但“最小共同体”不再作为另一套制度 / 哲学方案与最低共同现实并列。

更准确的内部关系是：

> **最低共同现实 = 城市重新成为同一座城市的治理 / 公共行动。**
>
> **更小的北京 = 这个行动必须接受的物理结果。**

内部仍可用“最小共同体”帮助创作理解，但不得强迫角色反复解释两个概念差别。

`LOCKED`
