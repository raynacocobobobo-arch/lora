## Revision rule

When an EP01–EP10 episode is revised through the Master-V3 backprop pass:

- create / activate the next Latest Snapshot version;
- preserve prior snapshot versions;
- only supersede earlier text where the new revision addresses the same matter;
- if a macro function changes, update the relevant row(s) of Master V3's episode state matrix / ladders;
- only update derived documents when their specialized table remains useful;
- do not auto-resolve `TBD` / `NEEDS_REVIEW` merely to make documents look complete.

Do not attempt to keep every historical document textually identical. Preserve history, but keep the current authority path unambiguous.
