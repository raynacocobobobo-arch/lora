# 02｜使用边界

`LOCKED`

这组词是每集的主题压缩，不是剧情梗概，也不是必须被角色说出口的理论术语。

后续创作遵守：

- 不为了让每集都符合总主题，强行制造“牺牲”；
- EP03 / EP04 / EP06 / EP09 的核心不应被硬解释成牺牲；
- 主题词应通过行动、制度、基础设施、关系和后果体现，而不是哲学对白；
- 若未来剧情发生明确 Canon 修订，主题词可以通过新 patch 修订，但不得静默漂移。
