# 01｜EP02 的核心定位

`LOCKED`

EP02 不是“一座桥出故障”的单案集。

它是第二新北京第一次明确进入：

> **统一城市协调层持续失效，城市在整集过程中一块一块失去连接，逐步形成若干孤岛。**

开合大桥是男女主当前负责的主要现场，但只是全城同时发生的众多失联 / 分离事件之一。

EP02 的核心观感应是：

> **北京不是瞬间碎掉，而是在观众眼前不断失血。**

# 02｜“系统 AI 崩溃”必须定义为城市级统一层失效

`LOCKED`

不得写成所有 AI 同时宕机。

当前事故状态是：

- 城市级统一系统 AI / 统一城市模型 / 跨区协调与仲裁层发生严重功能性崩溃；
- 区域 AI、结构 AI、交通 AI、医疗 AI、能源 AI、生命支持 AI、本地缓存模型和硬控制层仍在大量正常运行；
- 它们可以非常聪明，也可以在本地事实和本地职责范围内完全正确；
- 失去的是让这些系统持续看见“同一个北京”、共享同一状态并完成跨区优先级仲裁的上层能力。

核心延续：

> **不是 AI 发疯，而是很多局部正确的系统正在失去共同城市模型。**

# 03｜系统级 AI 主机与备份中心

`LOCKED`

1. 城市级统一系统 AI 的主要主机 / 核心计算节点所在设施遭受物理撞击并严重损毁；

4. 同时城市能源网络和跨区基础设施正在分裂，因此备份中心无法立即接替全城统一运行；
5. 城市级统一系统预计需要一段较长时间才能恢复到足够重新承担全城协调的状态。

# 04｜女科长正式到岗：不是临时灵机一动，而是启动预案

`LOCKED`

EP02 中，女科长正式进入男主所在部门并接到上级任务。

上级并不是第一次想到“信号越来越差怎么办”。

第二新北京在灾前已经对极端情况下：

- 城市级协调层功能下降；
- 跨区通信持续恶化；
- 区域系统逐渐转入本地运行；
- 统一仲裁能力消失；

因此 EP02 中应发生：

- 上级正式启动对应预案；
- 女科长接到任务；
- 她的临时 / 应急公共处置权限升级；
- 男主所在的原本高度边缘化、近乎被自动化掏空的小部门，被纳入事实冲突现场处置体系；
- 男主的现场判断能力因此开始重新获得真实功能价值。

这不是男主突然成为全城核心，而是既有灾难预案重新启用一类“统一系统无法替代”的现场判断岗位。

# 07｜桥梁冲突：结构保全 vs 撤离连续性

`LOCKED`

桥梁事件中存在两套都合理的公共 / 专业系统逻辑。

### A｜结构保全逻辑

结论：

> **桥必须尽快分离。**

理由方向：

- 当前连接持续传递异常载荷 / 结构风险；
- 延迟分离可能让局部故障扩大到更大城市结构；
- 保护的是更多人口和更大范围主体城市安全。

### B｜撤离 / 公共连续性逻辑

结论：

> **桥不能立即分离。**

理由方向：

- 桥对面仍有大量人员通过该桥撤离；
- 该桥是当前仍可承担大规模撤离的关键 / 唯一有效通道；
- 过早分离意味着一部分仍有机会撤离的北京市民被直接留在对岸。

这不是“身份是不是北京”的抽象争议。

EP02 当下的冲突是：

> **现在开，还是再给撤离争取一点时间。**

而两边都可能死人。

# 08｜男主与女科长的职责必须严格分开

`LOCKED`

男主不拥有“开桥 / 不开桥”的最终公共决定权。

男主的职责是：

- 进入现场；
- 核验桥体真实状态；
- 判断系统模型是否与现场一致；
- 给出当前物理极限、风险窗口和可继续维持的大致边界；
- 对自己的现场判断负责。

他可以确认：

- 现在开会造成什么；
- 延迟会增加什么风险；
- 现场最多还能承受到什么程度。

但：

> **最终决定何时开桥，由女科长承担。**

女科长负责：

- 在不完整事实下作公共判断；
- 在结构总体风险与仍未撤离人员之间决定截止时刻；
- 使用预案升级后的有限权限承担该决定后果。

这构成男女主核心功能关系：

> **男主告诉她现实还能允许什么。**
>
> **女科长决定现实接下来必须发生什么。**

# 10｜北京必须在整集过程中不断“失血”

`LOCKED`

群岛化不得一次性完成。

EP02 在男女主处理桥梁事件期间，系统背景必须不断出现其他地区的新事故 / 分离 / 失联状态。

表现方向包括但不限于：

- 某区桥梁完成紧急分离；
- 某区桥梁 / 联络结构直接断裂；
- 某区域伤亡状态不明；
- 某区域跨区数据骨干失联；
- 某区域系统转入本地独立运行；
- 某处撤离完成；
- 某处撤离失败或状态无法确认。

用户讨论中的 `A12 / A22` 等仅为临时示例编号，**不锁具体编号**。

播报 / 状态更新应越来越频繁，形成持续加压。

重要：

> **这些不是“新闻插播”，而是男女主所在公共系统不断收到的城市运行状态变化。**

整集结束时，观众才真正意识到：

> **北京已经从一张连续的城市网络，变成多个仍能局部运行但逐渐失去联系的孤岛。**

# 12｜整季硬压力：系统恢复时间 vs 孤岛生存时间

`LOCKED`

城市级统一系统有一个预计恢复时间。

但不同孤岛的独立生存能力并不相同。

可能存在：

- 能源充足但医疗能力不足；
- 食物充足但热控 / 生命支持正在下降；
- 结构稳定但关键耗材缺乏；
- 可长期独立运行；
- 只能维持短期；
- 状态完全未知。

因此整季形成一个核心硬压力：

> **城市级统一系统最终可能恢复，但部分孤岛上的人未必能坚持到那一天。**

这不是统一的“全城72小时氧气倒计时”。

应当是：

> **一个较明确的系统恢复时间，面对多个不同的孤岛生存窗口。**

具体系统恢复时间、各孤岛寿命、哪些区域最先进入危险期全部 `TBD`，应根据整季集数与叙事日历反推后再锁。
