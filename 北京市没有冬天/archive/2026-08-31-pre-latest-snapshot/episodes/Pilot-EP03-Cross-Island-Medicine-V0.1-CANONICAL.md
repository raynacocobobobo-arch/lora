# 02｜群岛化的交通 / 流动定义

`LOCKED`

EP02 之后的“孤岛”不得理解为所有区域都绝对物理封死。

群岛化主要意味着失去：

- 稳定的大容量跨区公共交通；
- 常规自动化物流；
- 连续统一的跨区调度；
- 可自动信任的实时状态；
- 一套全城共同有效的公共授权链。

但部分区域之间仍可能残留：

- 老工程线；
- 维修轨道；
- 小型货运舱 / 转运舱；
- 临时气密接口；
- 低容量工程运输；
- 需要人工现场确认后才能短时启用的连接窗口。

这些残存连接只能承担：

> **少量关键物资、少量必要人员、关键零部件等生存级流动。**

它们不能恢复：

- 大规模撤离；
- 常规跨区通勤；
- 正常商业物流；
- 大规模人口自由流动。

内部边界：

> **能送一箱药，不等于能撤一万人。**

具体容量、频率和路线 `TBD`。

# 03｜主事件：跨岛送药

`LOCKED`

EP03 的主事件为：

> **一个与主角所在区域失去稳定公共连接的孤岛 / 半孤岛医疗节点，需要一批关键药物或医疗耗材。**

该物资在灾前属于普通城市物流可以轻松完成的调度任务。

事故后：

- 物资仍然存在；
- 目标区域仍然有人；
- 两者物理距离未必极远；
- 但已经不存在一条全城系统能够自动承诺“从这里到那里一定成立”的连续公共物流链。

因此任务从“调货”变成：

> **把若干仍然局部成立、但不再共享统一现实和统一授权的残存运输段，临时拼成一次可执行的跨岛生命线。**

药物 / 医疗耗材具体种类、患者数量、目标医院 / 医疗站、运输总距离全部 `TBD`。

# 04｜运输方式：不是主角亲自背药跑完全程

`LOCKED`

男女主不是快递员，也不成为唯一完成全部运输的人。

运输必须体现城市仍由大量局部系统、机器人、医疗人员、工程人员和运输节点共同维持。

男女主主要介入：

- 原本自动系统无法确认的物理接口；
- 不同区域状态相互冲突的运输节点；
- 临时路径是否真正连续；
- 某些必须重新确认才能执行的公共动作。

药物可以经过多段：

> 区域仓储 / 医疗节点 → 小型货运段 → 工程 / 维修连接 → 人工确认接口 → 另一运输段 → 目标孤岛。

# 05｜男主职责

`LOCKED`

男主负责回答：

- 某段残存线路物理上是否真的还能使用；
- 某个接口是否真的能够对接 / 开启 / 承载；
- 系统状态与现场物理状态是否一致；
- 哪个节点仍有真实连续的物理通路；
- 临时启用会产生什么现场风险；
- 当前物理条件最多允许什么规模 / 多久的窗口。

男主不负责决定整个城市资源政策，也不拥有全城交通调度权。

内部关系继续遵守：

> **男主告诉她现实还能允许什么。**

# 06｜女科长职责

`LOCKED`

女科长负责把多个局部仍然成立的运输段，临时纳入一次可承担责任的公共行动。

她主要回答：

- 哪些临时跨区动作可以被批准；
- 哪个区域 / 节点可以接收来自另一套局部现实的货物；
- 在统一授权链失效时，哪些有限权限可以拼接成一次临时有效行动；
- 谁承担这次开放 / 转运 / 接收的公共责任；
- 什么时候必须终止这条临时生命线。

她不是通过一句命令恢复常规物流。

这次授权只对：

> **这一批关键物资 / 这一段有限窗口**

成立。

内部关系继续遵守：

> **女科长决定现实接下来必须发生什么。**

# 07｜“老系统”的使用原则

`LOCKED DIRECTION`

EP03 优先使用至少一段较老、低复杂度、工程用途的残存运输 / 连接设施。

其价值不是“旧技术神奇地比新技术可靠”，而是继续遵守 Series Bible 已锁原则：

> **不是老技术更可靠，而是老技术需要成立的前提更少。**

正常时代它可能效率低、容量小、需要更多现场确认，因此已被自动化公共物流边缘化。

灾后恰恰因为它不依赖完整全城模型，成为临时生命线的一部分。
