# 02｜302 当前状态：真实、仍可继续，但不再当然值得长期维持

`LOCKED DIRECTION`

EP09 中的 302 不得被写成已经彻底报废、马上坍塌、无人居住的废墟。

必须同时成立：

- 302 真实存在；
- EP01 中对其真实性的现场确认没有被推翻；
- 居民及其生活历史必须被承认；
- 结构 / 环境 / 公共服务仍存在继续维持的现实可能；
- 继续维持并非绝对不可能；
- 但它需要城市长期保留额外例外、连接、资源或独立维护条件；
- 在未来更小、可持续的北京中，它成为一个“是否还应继续保留”的真实选择。

核心不是：

> **救不了，所以放弃。**

而是：

> **它还能继续，但北京已经不能再什么都继续。**

具体维护成本、例外类型、迁移方案与工程原因全部 `TBD / NEEDS_REVIEW`。

# 04｜私人伴随 AI：不是缺席，而是通过男主重新看见 302

`LOCKED`

原 EP09 V0.1 中“AI 实时能力不足 → 男主不等待她 → 独立完成普通现场工作”的人物方向被本补丁修订。

EP09 不是为了证明：

> **男主已经不需要私人 AI。**

而是第一次完整展示：

> **AI 已无法可靠直接看见 302 当前现场，男主成为她的现场感官。**

男主进入 302 后，把必要的真实现场信息带给她。

信息可以包括的类型：

- 当前仍有人生活；
- 通道、结构、环境设备的实际状态；
- 现场与旧记录不同的变化；
- 是否处于长期生活而非临时避难状态；
- 302 作为“真实生活空间”仍然成立的证据。

精确观察项目与对白全部 `TBD`。

核心关系：

> **男主替她看现场。**
>

# 05｜私人 AI 必须独立得出自己的判断

`LOCKED`

私人 AI 在获得男主提供的当下现场信息后，将其与自己仍拥有的：

- 历史资料；
- 长期城市状态；
- 维护与资源关联；
- 最低共同现实重建方向；
- 未来城市可持续条件；

结合起来，形成自己的判断。

该判断当前锁定为：

> **302 应退出未来北京的持续维护体系。**

这个结论不能来自：

- 她没看见所以误判；
- 冷酷概率自动牺牲少数；
- 服从女科长命令；
- 为了推动终局而突然改变价值观。

必须成立的是：

> **她完全理解 302 真实存在、仍有价值、仍可能继续，却仍然认为“可以继续”不等于“应该永远保留”。**

这证明她不是男主的工具，也不是只负责支持男主情绪的附属人格。

# 06｜男主的功能：诚实确认，而不是替公共层级制造借口

`LOCKED`

男主不能为了让 302 被放弃而把现场报告写成：

> “302 已无价值 / 已无法维持。”

他的现场结论必须保持其一贯原则：

> **以现场为准。**

因此他应诚实确认：

- 302 真实存在；
- 现场具体状态是什么；
- 它是否仍有继续维持可能；
- 继续维持需要承担哪些现实条件。

然后把“是否继续把它纳入未来北京”留给公共决定。

这使男主不成为替制度粉饰代价的人。
