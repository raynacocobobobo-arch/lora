# 《北京市没有冬天》Pilot Recurring Locations / Entity Registry V0.1 — CANONICAL

- Updated: 2026-08-30
- Status: `LOCKED / PILOT ASSET MINIMUM`
- Purpose: 只定义 Pilot 前3–5集真正需要反复复用的最小人物 / 场景资产，不提前扩展整座第二新北京市。
- Production principle: 优先复用稳定空间、角色和机位，降低纯 AI 连载中的环境漂移、人物比例漂移和重复建模成本。

---

# 01｜总体原则

`LOCKED`

Pilot 阶段只建立必要资产。

每个 recurring location 后续视觉生产应固定五类信息：

1. `Geometry`：空间布局和尺度关系；
2. `Material / Age`：材质、年代、长期使用痕迹；
3. `Fixed Anchors`：门、窗、桌、设备、通道等不得随镜头随机漂移；
4. `Camera Anchors`：3–5个高频复用标准机位；
5. `Mutable State`：允许随剧情变化的灯光、损伤、临时标识、人员和系统状态。

当前 Canon 只锁功能和复用边界，不锁具体美术设计。

# 02｜Recurring Location A：男主 / 女科长部门

`LOCKED`

功能：

- EP01建立男主工作已被高度自动化；
- 女科长到任后成为两人固定工作基地；
- 接收异常 / 工单 / 现场请求；
- 展示两人越来越成熟的工作默契；
- 承载少量非现场关系戏；
- 强调该部门是“小型事实冲突处置节点”，不是城市级控制中心。

视觉原则：

> **普通、成熟、略旧、功能性强，甚至有一种部门已经被自动化时代边缘化的感觉。**

禁止做成：

- NERV式总部；
- 巨大控制大厅；
- 全城调度中心；
- 霓虹HUD科技空间。

具体布局、美术与标准机位 `TBD`。

# 03｜Recurring Location B：男主家

`LOCKED`

功能：

- 私人伴随 AI 的主要稳定空间；
- 展示男主真正的私人生活；
- 展示私人伴随 AI 与城市系统 AI 的根本差异；
- 外部城市访问逐渐丢失后，家仍作为两人较长时间维持的稳定私人共同现实；
- 为后期伴随 AI 主机站代价建立情感基础。

视觉原则：

> **普通成熟住宅，不豪华、不“未来样板间”。**

需要让观众相信男主已经在这里生活很久。

# 04｜Recurring Location C：302楼

`LOCKED`

302楼取代此前讨论中的343楼编号。

当前权威事件文件：

`Pilot-EP01-302-Building-V0.2-CANONICAL.md`

302楼既是 EP01 主事件地点，也是中后段公共现实代价的回声地点。

建议按资产复用划分三个子区域：

### 302-A｜住宅公共区

- 居民生活痕迹；
- 小女孩出现；
- 让“系统里不存在的楼”仍然明显是一个真实有人生活的家。

### 302-B｜维护 / 结构接口区

- 男主深入现场；
- 重力异常视觉逐渐升级；
- 关键现场判断发生的工程空间。

### 302-C｜楼体外部 / 周边连接结构

- EP01重力反转后的外部方向坠落与世界 Reveal 相关空间；
- 中后段再次回到302楼时可用于迁移 / 退出公共住宅体系的视觉回声。

302楼具体重力系统、结构机理、建筑布局 `TBD`。

# 05｜Recurring Location D：固定跨区连接节点

`LOCKED DIRECTION`

Pilot 建立一个可重复使用的跨区交通 / 维护 / 公共接口节点。

功能：

- 男女主进入不同区域；
- 显示区域之间的授权边界；
- 显示时间、地图、身份、公共状态逐渐出现冲突；
- 私人伴随 AI 外部访问逐渐缩小时，可成为“她只能跟到这里 / 数据开始不可靠”的视觉边界之一；
- 后期可以反向表现区域逐步重新接入共同现实。

它应当是普通公共基础设施，不设计成神秘传送门或大型控制中心。

正式名称、位置、美术与具体系统功能 `TBD`。

# 06｜Recurring Location E：老电影院

`LOCKED / PILOT RECURRING CANDIDATE`

EP04使用一家保留地球时代经典电影放映传统的老电影院。

功能：

- 当日最后一个小型工作事件；
- 展示“无需先解决所有历史矛盾，只确认足够让当前公共行动成立的必要事实”；
- 工作结束后自然转入女科长的私人电影爱好；
- 承载男主、女科长、私人伴随 AI 第一次完整的非紧急三人关系场景。

是否在 EP04 后继续复用电影院尚可根据 Pilot 剧情决定；即使只主要用于 EP04，也建议按稳定资产制作，避免单集内部镜头漂移。

正式名称、座位区、入口、放映厅尺度、影片展示方式 `TBD`。

# 07｜World-Reveal Constraint：EP01 前不得提前泄露轨道北京

`LOCKED`

EP01 在男主因302楼局部重力反转向城市外部方向坠落之前，画面必须尽可能维持：

> **“这是某个未来北京城市空间”**

的第一观看理解。

EP01 Reveal 前禁止通过资产设计无意泄露：

- 明确宇宙窗景；
- 月球大全景；
- 轨道城市完整外观；
- 显然只有空间站才会存在的夸张视觉语言；
- 角色解释所处绕月轨道。

302楼 Reveal 以后，宇宙外部视角才正式解锁。

此约束适用于所有 EP01 资产生成提示和镜头设计。
