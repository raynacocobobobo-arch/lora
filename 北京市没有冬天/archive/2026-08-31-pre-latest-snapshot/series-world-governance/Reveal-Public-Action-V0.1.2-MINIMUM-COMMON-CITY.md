# 01｜终局不是“修回完整北京”

`LOCKED`

第一季最终恢复目标不得写成：

> **把灾前第二新北京市的全部区域、全部基础设施、全部公共能力和全部灾后现实无损修回。**

经过陨石撞击、群岛化、区域现实分叉与后续重连以后，第二新北京已经发生不可逆变化。

因此终局必须承认：

- 一部分区域已经永久失去；
- 一部分连接不再值得或无法继续维持；
- 一部分基础设施需要关闭 / 弃用 / 切除；
- 一部分灾后形成的局部秩序不能全部继续拥有公共效力；
- 一部分人口、服务与城市功能需要迁移或重新收缩；
- 北京最终能够继续存在，不等于北京能够完整回来。

核心结论：

> **北京不是因为所有东西都被修好才重新成为北京。**
>
> **北京是因为它终于接受自己不可能全部回来，才重新成为北京。**

# 02｜最小共同体

`LOCKED CONCEPT / FORMAL IN-WORLD TERM TBD`

终局城市物理层的内部创作概念锁定为：

> **最小共同体。**

这里的“最小”不是人口越少越好，也不是追求最小城市规模。

它指：

> **在已经无法无损维持全部第二新北京市的前提下，保留足以让仍然留下的人重新生活在同一座城市、同一套公共秩序与同一个公共“现在”中的最低可持续城市共同体。**

它与“最低共同现实”相互对应但不等同：

- **最低共同现实**回答：哪些公共事实 / 规则必须共同有效；
- **最小共同体**回答：哪些城市结构、人口、服务和公共能力能够在这些最低共同现实下继续作为同一座北京共同存在。

正式制度名称是否叫“最小共同体”继续 `TBD`；该词当前作为锁定的内部创作概念使用。

# 03｜终局动作从“继续修”转向“决定什么应该停止”

`LOCKED DIRECTION`

第一季后段的城市级行动不能一直维持：

> **再修一条、再接一个区、再恢复一个旧系统。**

必须出现方法论转向：

> **当继续维持某些区域 / 系统只会要求城市永久保留彼此冲突的现实、消耗无法承担的资源或阻止最低共同现实成立时，北京必须开始决定什么应该停止。**

这可以包括但不限于：

- 永久关闭无法共同维护的区域；
- 放弃部分旧交通 / 能源 / AI / 公共服务结构；
- 将居民迁入仍可长期共同维持的城市结构；
- 切断会继续制造公共现实分叉的旧系统依赖；
- 让某些真实存在过、甚至曾经合理有效的灾后城市状态停止继续拥有未来公共效力。

具体对象与顺序全部 `TBD`。

该方向与 EP07 的中枢切除形成尺度升级：

> **EP07 第一次证明：第三条路有时不是修复，而是放弃一个已经不能被公平维持的中心。**
>
> **终局则把这一原则推进到城市尺度。**

# 04｜最重要的情感落点

`LOCKED`

第一季结局的核心情感不得是：

> “北京终于恢复成原来的样子。”

也不得是：

> “人类终于战胜灾难，把所有系统都修好了。”

当前锁定的终局情感定义为：

> **北京已经失去了很多东西，甚至变得比以前更小，但剩下来的人终于重新生活在同一座城市、同一个现在里。**

这句话不是必须出现在对白中的台词，而是终局所有结构、镜头和选择必须服务的内部情感标准。

感人的地方来自：

- 北京没有完整回来；
- 某些失去永远不会逆转；
- 某些人、区域、设施和私人世界不会进入新的共同城市；
- 但留下来的人不再分别生活在彼此冲突的“北京”里；
- 他们重新拥有一个共同的公共现在。

因此结局不是复原，而是：

> **带着缺口重新成为共同体。**

# 05｜与“秩序与牺牲”的关系

`LOCKED`

“最小共同体”是第一季最高层主题 **“秩序与牺牲”** 在城市物理层的最终表达。

第二新北京重新拥有秩序的代价，是：

> **它必须主动放弃一部分自己。**

因此牺牲不是抽象的集体主义颂歌，而是具体发生在：

- 城市结构；
- 公共能力；
- 区域利益；
- 灾后形成的新生活；
- 数字基础设施；
- 个人长期共享的私人现实。

被放弃的部分不能被写成“本来就没价值的垃圾系统”。

它们必须允许：

> **真实存在过、真实服务过人、甚至对某些人而言是他们灾后唯一成立的家和秩序。**

只有这样，城市收缩才真正具有代价。

# 06｜私人伴随 AI 的终局代价因此获得城市级语境

`LOCKED FUNCTION / EXACT MECHANICS TBD`

男主私人伴随 AI 所依赖的主机站最终被弃用，不应显得像为了人物悲情单独发明的一刀。

它必须属于更大的城市级收缩逻辑：

> **为了让最小共同体成立，一部分无法继续进入新公共现实的旧基础设施必须停止。**

私人伴随 AI 主机站恰好属于其中之一。

因此男主最终面对的不是：

> “北京还是她？”

而是：

> **当他已经接受城市必须放弃某些真实而珍贵的东西才能重新成为共同体时，同一个原则终于落到他自己最珍贵的私人现实上。**

私人 AI 的最终主动性、男主是否拥有阻止能力、两人的双重选择与具体关闭机制继续 `TBD / NEEDS_REVIEW`，不得由本补丁擅自补齐。

# 07｜与北京时间 / 冬季结局的完整因果链

`LOCKED`

`Reveal-Public-Action-V0.1.1-END-TIME-WINTER.md` 的既有终局因果继续有效，并由本补丁补足城市物理层。

完整方向现在为：

1. 城市接受无法无损恢复全部第二新北京；
2. 最低共同现实重建推进，开始决定哪些差异可以保留、哪些公共冲突必须终止；
3. 无法共同维持的区域 / 连接 / 基础设施被关闭、放弃、迁移或退出未来公共运行；
4. 第二新北京收缩为一个更小、残缺、但可持续共同运行的**最小共同体**；
5. 仍属于这个共同体的区域重新共享唯一有效的北京标准时间；
6. 城市重新拥有同一个公共“现在”；
7. 统一公共冬季协议重新有效；
8. 下雪。

雪依然不是解决方案。

雪只是证明：

> **这个已经变小、已经失去很多东西的北京，终于又能共同生活在同一个现在里。**

# 08｜明确禁止

`FORBIDDEN`

- 结局恢复灾前完整北京；
- 一次总重启让所有区域无损回来；
- 把“最小共同体”写成简单撤城 / 逃亡 / 放弃维护；
- 把被关闭区域写成毫无价值、无人生活的废料；
- 把城市收缩写成纯技术优化，没有人类与公共代价；
- 让最低共同现实与最小共同体变成同一个概念；
- 为了结局感人而取消已发生的损失；
- 因北京变小而否定其“北京”身份；
- 用庆功式大团圆覆盖失去；
- 用下雪表示所有人都获得补偿。

终局必须同时成立两件事：

> **它失去了很多。**
>
> **它重新成为了同一座北京。**
