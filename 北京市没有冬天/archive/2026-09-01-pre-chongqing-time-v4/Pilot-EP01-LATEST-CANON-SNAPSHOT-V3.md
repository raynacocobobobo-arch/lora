# 01｜核心事件不变：302 现实冲突

EP01 仍然是：

> **302 现实冲突 + 男主判断第一次重新触碰现实 + 女科长真实物理救援 + 城市外部尺度视觉揭示。**

本集只回答：

> **系统无法确认，不等于现实不存在。**

它不回答：

> **真实存在是否必须被永久保存。**

后一问留到 EP09。

# 02｜时间线：陨石已经发生

`LOCKED / USER-CORRECTED`

EP01 正片开始时：

> **第二新北京已经经历过陨石撞击。**

城市已完成 / 正在持续：

- 首轮气密隔离；
- 自动结构支撑；
- 能源 / 通信改线；
- 局部生命保障自治；
- 持续维修与临时包覆；
- 灾后公共恢复。

因此 EP01 不是灾难发生集。

302 是：

> **灾后系统现实与物理现实已经出现裂缝的第一个具体案例。**

# 03｜Opening：给观众基础设定，但不做设定讲座

`LOCKED_DIRECTION`

EP01 开头允许观众知道：

- 这里是第二新北京市；
- 城市位于太空 / 月面轨道体系；
- 此前发生过陨石撞击；
- 城市仍在恢复；
- 男主的现场复核工作已高度自动化。

表现只需极短、生活化、工作化。

不需要把“在太空”当成悬念隐藏。

结尾仍保留强视觉冲击，但其性质是：

> **第一次真正看见整座城市与地球 / 月球的空间尺度关系。**

而不是：

> **“原来他们在太空。”**

# 04｜删除 302 小女孩：避免与 EP03 医疗女孩功能重复

`LOCKED / USER-APPROVED CONSISTENCY PATCH`

EP01 V2 的 302 小女孩不再作为当前 Canon 的具体存在载体。

原因：

- EP03 已有医疗女孩；
- 她后续还承担 EP08 强回调；
- 若 EP01、EP03 连续两次都用“小女孩 + 男主现场救援”，前 3 集人物语法会过度重复。

因此 EP03 医疗女孩保留为本季主要儿童角色。

EP01 的“具体存在”改为：

> **302 内一个匿名、实时、可交互的居民信号 + 独立现场物理证据。**

居民不要求露脸，不要求命名，不要求后续回归。

# 05｜302 的新具体事实链

`LOCKED_FUNCTION / EXACT IMPLEMENTATION TBD`

统一城市系统 / 相关公共记录当前无法确认：

> **302 存在有效居民 / 有效公共实体。**

男主到现场后获得第一层新事实：

> **一个统一系统没有纳入可信状态的、来自 302 内部的实时应急通信 / 本地通信信号。**

该信号必须满足：

- 不是旧录音；
- 不是预存消息；
- 能对男主当前动作 / 询问产生实时回应；
- 证明“此刻里面存在一个行动中的主体”具有强可能性。

但私人 AI 合理指出：

> **单一信号不足以证明完整现场状态，也不足以证明结构安全。**

她是对的。

男主随后通过现场获得第二层独立事实，例如功能上可能是：

- 新鲜人工操作痕迹；
- 当前生命保障负载变化；
- 局部热 / 空气 / 机械状态；
- 刚刚发生的人为物理响应；
- 其他不能由旧记录简单解释的实时现场事实。

具体形式 `TBD`。

最终形成足够确认：

> **302 内此刻确实有人。**

# 06｜EP01 不是“AI 错、人对”

`LOCKED`

私人 AI 仍处于整季外部访问最强阶段。

她掌握：

- 广域结构风险；
- 路线；
- 自动公共系统状态；
- 大量实时城市信息。

她反对男主继续深入必须合理。

她可以正确指出：

> **实时信号本身不能证明结构安全，也不能证明系统其他风险判断失效。**

男主也不反驳这一点。

他的判断只增加一个新事实：

> **系统当前决策空间里漏掉了一个此刻真实存在的人。**

因此本集继续保持整季基因：

> **不同主体掌握不同范围的现实，两个合理判断可以冲突。**

# 07｜男主的动作权限

`LOCKED`

男主不是定义 302 主权的人。

他只拥有足够窄的现场权限去：

- 冻结 / 延迟基于“无人”前提继续执行的自动公共动作；
- 标记现场事实冲突；
- 要求重新确认；
- 把新的物理事实送回公共判断链。

具体自动动作继续 `TBD`。

EP01 的权限种子是：

> **暂停错误前提。**

不是：

> **永久定义未来北京。**
