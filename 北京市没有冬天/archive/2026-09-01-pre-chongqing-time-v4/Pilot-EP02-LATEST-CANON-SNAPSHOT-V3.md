# 01｜核心定位：不是撞击发生，而是撞击后抢救来到极限

`LOCKED / USER-CORRECTED TIMELINE`

陨石撞击发生在 EP01 之前。

EP02 开始时：

> **第二新北京已经在灾后持续抢救、支撑、修补。**

本集主事件是：

> **陨石撞击留下的一组旧工业—城市骨架损伤仍在传播 / 恶化；一条大型跨区结构已经被人、AI 和公共系统撑了很久，终于接近“继续维持会把更大结构拖入风险”的临界点。**

所以 EP02 仍然是：

> **北京被迫失血。**

不是：

> **北京主动选择变小。**

# 02｜所有人仍然在“救、撑、修、保”

`LOCKED`

撞击以后 AI / 自动系统先救了北京。

到 EP02 仍然继续：

- 结构支撑；
- 局部气密；
- 能源改线；
- 生命保障自治；
- 撤离；
- 物流；
- 跨区连接抢救；
- 临时本地授权。

这些都不是地方分裂宣言。

角色仍相信：

> **先撑住，以后还能接回来。**

# 03｜主现场：一条已经被撑了很久的跨区结构

`LOCKED DIRECTION`

巨型桥 / 可开合结构 / 旧跨区骨架具体形态继续 `TBD`。

但状态必须明确：

> **它不是今天刚被撞坏；它是灾后一直被临时支撑、反复抢救，并且仍承担撤离、物流、生活关系的真实连接。**

两个正确目标继续冲突：

### A｜继续撑

保护：

- 尚未撤完的人；
- 必要物资 / 医疗；
- 生活关系；
- 尽可能多的跨区可达性。

### B｜停止继续撑

保护：

- 更大的结构稳定；
- 其他区域；
- 避免已有损伤继续传播；
- 防止一个正在失败的连接把更多北京一起拖下去。

因此不是：

> **保留 vs 牺牲。**

而是：

> **两种保全开始互相挤压。**

# 04｜男主与女科长分工

`LOCKED`

男主负责：

> **现实还允许这条连接安全维持多久。**

他确认：

- 现场受力；
- 模型与实际差异；
- 结构传播风险；
- 撤离 / 通行窗口；
- 超过哪一状态以后继续抢救会扩大损失。

女科长负责：

> **什么时候停止继续抢救。**

她不是根据自己的技术直觉切桥，也不是提前执行“更小北京”理论。

她承担一个公共时点决定：

> **继续多救一点，还是到这里必须停止，否则会让更多真实主体一起进入风险。**

# 05｜Dominant Turn V3

`LOCKED`

> **灾后所有人一直在维持一条持续恶化的跨区连接；男主确认安全抢救窗口已经逼近极限，女科长最终承担“停止继续抢救”的公共决定。结构随后真正失去，第二新北京被动新增一个孤岛边界。**

情感核心：

> **我们已经尽量救了，还是没能全部救回来。**

不是：

> **我们终于学会应该主动牺牲一块北京。**

# 06｜人物 State Delta

### 男主

EP01：

> **我的判断真的改变现实。**

EP02：

> **我的判断也会成为别人承担公共后果的依据。**

他的专业事实不等于公共决定，但会进入公共决定链。

### 女科长

第一次真正承担：

> **一个所有人都在救、但最终仍有人没被救到的公共时点。**

她尚未失去对“事实 + 程序 + 责任链”的信念。

### 私人 AI

仍然是前期“尽量保存更多”的主体。

她可以基于更大范围生存概率倾向更早止损，但目标仍是：

> **保更多北京。**

# 09｜EP02 → EP08

`LOCKED`

EP02 新孤岛边界产生跨区刚需。

EP03 临时生命线成功以后反复使用。

长期沉积：

> **工程接口 → 生命线 → 运营管理 → 双方安全责任 → 两套地方公共秩序重叠 → EP08。**

因此 EP08 的冲突来自 EP02/03 的真实成功和长期运行，不是突然出现的政治边境。
