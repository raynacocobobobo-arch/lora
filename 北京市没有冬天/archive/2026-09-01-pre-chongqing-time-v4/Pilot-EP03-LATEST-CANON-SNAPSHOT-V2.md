# 01｜核心定位

`LOCKED`

EP03 仍然是一次跨区送药 / 医疗转移。

它不负责重新连接北京，也不负责提前发明一套治理理论。

它第一次证明：

> **完整系统没有恢复，仍然可以把一次真实连接做成。**

Dominant Turn：

> **两个区域都认为对接已经完成，但现实中的可通行状态没有真正重合；男主重新找到真实物理窗口，女科长只授权这一次，药真正过去。北京没有恢复连接；他们只是把一次连接做成了。**

本集三个主题词继续锁定：

> **有限｜连接｜充分**

“充分”不是残缺版真相。

它指：

> **不需要先恢复所有共同事实，只需要获得足以让当前动作成立的真实事实。**

# 02｜承接 EP02：修正旧表述

`LOCKED / V2 CORRECTION`

V1 曾用：

> **“EP02：桥断了，北京为了活下来而分开。”**

这句话现在容易误读成：

> 北京主动把分开当成求生策略。

根据 EP02 V2 与 Master V3.2，当前正确承接是：

> **EP02：事故正在把北京撕开。AI、人和公共系统一直在抢救受损连接、撤离、物流和生命保障，但最终没能把那条连接完整救回来。**

所以 EP03 的心理起点仍然是：

> **以后应该能修回来；眼下先解决一个不能等的问题。**

人物尚未进入：

> “也许北京未来本来就应该更小。”

那是后段才会发生的目标转向。

# 05｜七分钟：不是简单“两个钟表差七分钟”

`LOCKED_DIRECTION / EXACT MECHANISM TBD`

七分钟必须保留。

但 V2 明确：

> **现在不把它锁死成 A 区 12:00、B 区 12:07 的简单时钟偏差。**

更准确的剧情功能是：

> **两个本地系统各自根据自己的时间基准、流程状态、结构反馈与局部历史，都合理地判定某个“对接完成 / 可以通过”的状态已经成立；但这些状态映射到真实物理结构时，可通行窗口相差七分钟。**

因此七分钟同时具备：

1. **悬念功能**：药等不起；
2. **工程功能**：男主必须重新测量真实窗口；
3. **世界功能**：共同“现在”已经出现裂纹；
4. **递进功能**：为 EP06 更严重、更稳定的公共时间分叉留空间。

不要让 EP03 把 EP06 的问题提前讲完。

当前锁的是：

> **流程 / 状态在物理世界中的七分钟错位。**

精确成因仍 `TBD / VALIDATE_LATER`。

# 06｜Handshake：本集第一次真正成为普通工作词

`LOCKED FUNCTION / EXACT UI OR DIALOGUE TBD`

EP01 已经可以有一个非常轻的 handshake / identity-verification failure seed。

EP03 应第一次让：

> **“握手完成 / HANDSHAKE COMPLETE”**

成为观众能够看见或听见的普通技术工作状态。

但表现必须非常干。

不做：

- 哲学强调；
- 母题特写；
- 角色解释“什么叫握手”；
- 为 EP10 故意眨眼。

观众第一遍只应该理解：

> **系统说好了。**

然后现场告诉男主：

> **还没接上。**

### Protocol Handshake 能证明什么

当前只需内部明确：

它可以确认某些必要的：

- 身份；
- 权限；
- 双方准备状态；
- 接口 / 流程状态；
- 版本 / 基准中的一部分。

但它不能自动证明：

> **真实物理通路此刻已经能让药 / 人通过。**

所以本集母题：

> **Handshake complete ≠ Reality connected.**

并且：

> **Handshake 状态不是假的；它只是回答了一个比“现实到底接上没有”更窄的问题。**

这必须保护整季“AI / 系统不是撒谎，只是不能代表全部现实”的基调。

# 07｜真正两难：不是“救不救病人”

`LOCKED`

病人当然应该被救。

如果冲突写成：

> 救人 vs 不救人

没有真正两难。

本集两边真实价值是：

## A｜等待完整规则 / 状态恢复

保护：

- 流程完整；
- 责任链清楚；
- 标准安全条件；
- 避免把临时异常变成长期公共规则。

从制度角度完全合理。

## B｜当前刚需不能等待完整恢复

病人承担的是：

> **等待成本。**

如果继续等两个区域完整同步、重新建立标准跨区程序：

> **程序可以更完整，但病人未必还有时间。**

所以本集真正问题：

> **当完整公共规则暂时无法给出动作，而一个具体生命又不能等待时，是否可以只基于足够事实，承担一个一次性、窄范围的公共例外？**

女科长的答案是：

> **这一次可以。**

但这不等于：

> **以后都可以。**

# 08｜男主：第一次真正“把一个连接做成”

`LOCKED CHARACTER DELTA`

男主不是：

- 修复所有系统；
- 证明 AI 错；
- 创造新网络；
- 改写两边历史；
- 成为跨区主权者。

他做的是：

> **重新确认现场真实结构状态与可通行窗口，让数字上“已经完成”的连接第一次在现实中真正成立一次。**

他的季弧继续推进：

### EP01

> **我的判断终于真的改变现实。**

### EP02

> **我的判断也会成为公共决定和别人承担后果的依据。**

### EP03

> **我的现场判断能够让一个原本没有真正发生的连接发生。**

这应该给男主明显但克制的正反馈。

这个阶段不要急着惩罚他的“被需要”。

相反，观众应该越来越相信：

> **他确实很有用。**

这样他的 False Belief 才会越长越牢：

> **只有这个破碎的北京，才真正需要我的判断。**

终局放弃这种特殊必要性才有成本。

# 09｜女科长：第一次展示“只批准足够的东西”

`LOCKED CHARACTER / GOVERNANCE SEED`

女科长的能力不能只是“敢签字”。

EP03 要建立一个后来极重要的工作习惯：

> **在完整答案不存在时，她可以把授权范围压缩到只够当前动作成立。**

也就是：

- 不宣布两区重新连接；
- 不给线路永久制度身份；
- 不解决双方所有历史差异；
- 不把当前例外扩展为新总规则；
- 只对当前必要动作负责。

内部工作语法：

> **事实只确认到足够；授权也只给到足够。**

这是“最低共同现实”的早期行为祖先。

但当前角色不能命名它，也不能意识到自己正在形成未来治理理论。

### 她此时还没有意识到的次生后果

每一个一次性授权如果真的解决问题，就可能产生下一次合理请求。

她只是不断让合理行动成立。

回头以后才会发现：

> **被执行过的例外会留下制度沉积物。**

这条后果在 EP04–08 逐渐显现。

# 10｜私人伴随 AI：第一次“我看见两边，却仍看不见中间”

`LOCKED CHARACTER / CAPABILITY DELTA`

EP03 的私人 AI 仍然很强。

她仍能：

- 读取大量跨区资料；
- 同时看到 A、B 两边系统状态；
- 参与路线、风险、流程分析；
- 给男主大量有效建议。

她不能被写成：

- 延迟到近乎没用；
- 频繁错误；
- 卡顿；
- 人格退化。

真正变化是：

> **她可以同时读到两边都“完成”，却仍然无法仅凭这些数据拥有“两边之间此刻是否真的物理接触”的完整现实。**

这比 EP01 更进一步：

### EP01

> 她看得很广，但男主眼前有一个没有进入统一模型的具体存在。

### EP03

> **她连两边都看见了，却仍缺少“中间关系”本身。**

她不需要震惊，也不需要嘴硬。

正确反应是：

> **快速接受男主新的现场事实，并重新计算。**

这给她后续：

> **我知道 → 我不知道 → 我相信你**

继续铺路。

# 11｜Correctness / Justice / Legitimacy — 本集保持轻量

`LOCKED CREATIVE LENS / NOT EXPOSITION`

## Correctness

两个区域系统都可以正确。

男主的现场判断也可以正确。

关键是：

> **不同层级的“正确”并没有自动组成一次共同动作。**

## Justice

本集第一次显示：

> **等待完整程序恢复的成本会落在具体病人身上。**

所以“继续等最完整流程”不是零代价中立选择。

## Legitimacy

只种一颗小种子：

> **完整规则暂时无法提供答案时，女科长凭什么允许这一次？**

当前答案只是：

- 她拥有窄范围应急公共授权；
- 事实已经足够支持当前动作；
- 她对这个具体例外承担责任。

不能把本集提前写成 EP08 的完整公共正当性辩论。

# 12｜成功本身开始制造未来问题 — EP03 V2 最大新增

`LOCKED / PRESERVATION PARADOX / HIDDEN SOCIAL DYNAMICS`

EP03 的关键新增不是让送药更复杂。

而是重新定义这次成功的长期因果：

> **正因为这条临时低容量路径真的救了人，它以后才会变得难以只存在一次。**

第一次成功以后，未来自然可能出现：

- 下一次医疗刚需；
- 关键维修件；
- 生命保障维护人员；
- 食品 / 必要物资；
- 少量真实跨区人员需求。

每一个后续请求都可能有完全合理的事实基础：

> **上一次可以完成，这一次为什么不能？**

这不要求在 EP03 正片里演成社会辩论。

它只需要作为城市 State Delta 存在。

### 隐形制度沉积链

内部结构：

> **一次成功救援**
> → **证明路径具有公共价值**
> → **其他必要需求开始复用**
> → **线路必须被维护**
> → **容量有限，因此必须排序**
> → **人员 / 物资通过，因此必须安全确认**
> → **两边分别形成自己的管理流程**
> → **临时例外逐渐变成事实公共走廊**
> → **EP08 两套公共秩序在同一条生命线上重新重叠。**

所以：

> **EP08 的问题不是 EP03 失败造成的。**
>
> **恰恰是 EP03 成功以后才可能出现。**

这就是“保全悖论”的早期强案例：

> **一次正确的救援不会把世界恢复到原状态；成功会改变城市从此必须继续维护什么。**

`LOCKED / INTERNAL ONLY`

EP03 是当前“临时措施 → 例外重复 → 制度沉积”链条最重要的起点。

但绝不能做成现实疫情 / 封控影射。

正片不要出现：

- 现实健康码式 UI；
- 检测 / 核验隐喻；
- 防护服群像；
- 通行码；
- 栅栏式现实隔离视觉；
- “封控 / 解封 / 清零”等现实语言；
- 角色讨论社会学理论。

本集表面上只有：

> **药必须过去。**

以及：

> **他们把药送过去了。**

制度沉积是跨集后果，不是 EP03 的显性议题。

`LOCKED / STRONG CALLBACK`

强回调不是“观众认出她”。

> **过去的成功救援，数集之后成为约束公共暴力的现实证据。**

`LOCKED / V2`

> **当年救人的生命线已经成为事实公共走廊；为了让它长期安全工作，双方都形成了自己的公共管理与安全秩序，最终两套正确秩序在同一处彼此识别为威胁。**

女孩再次通过时：

> **过去的一次共同成功，让双方仍保留一个最低共同约束。**

因此基础设施回调 + 人物回调 + 公共规则回调三者合一。

| Investigation | 男主不修全系统，只重新测现场真实通行窗口；AI同时读两边数据并接受现场新事实 | 男主 / AI 的感知边界继续分化 |
| Dominant Turn | 七分钟真实窗口被找到；女科长只授权本次；一次连接真正成立 | “足够事实 + 有限授权”第一次成功完成共同动作 |
| Payoff | 药 / 医疗转移成功，具体病人得到现实结果 | 男主获得强正反馈；科长的有限授权方法被验证 |
| End Meaning | 表面任务结束；路径却因为成功而拥有了未来公共价值 | 打开重复使用、制度沉积、EP08 回调 |

### Ending image / cliffhanger

是否在本集结尾显性出现：

- 下一条必要请求；
- 线路等待队列；
- 一个很轻的系统状态变化；

继续 `TBD`。

不要求为了“伏笔”强行拍出来。

真正重要的是跨集 State Delta 被锁住。
