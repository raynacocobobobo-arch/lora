# 01｜整季位置：EP07 不是又一次“找到更好的办法”

`LOCKED / HIGH PRIORITY`

EP01–EP06 一直在证明：

> **还可以再救一点。**

- EP01：系统未确认不等于现实不存在；
- EP02：事故已经造成损失，但仍一直抢救；
- EP03：完整连接未恢复，也能把一次必要连接做成；
- EP04：完整现实未统一，普通生活仍可以继续；
- EP05：形式 / 记录可以保存，但连续主体不能自动补回；
- EP06：两个区域没有共同现在，也能通过共同物理 reference 完成一次同步公共动作。

EP07 必须第一次改变目标本身：

> **不是“怎么把 A、B、hub 都保下来”，而是第一次承认三者不能全部保存，必须主动从“需要保存的对象集合”里拿掉一个真实、有价值、仍然能工作的东西。**

因此：

> **EP07 = 第一次局部承认“全部保存”失败。**

仍不是 EP09/10 的城市级主动收缩，因为目标依然是：

> **尽量保住 A+B。**

# 04｜Opening Hook：先让观众看见“hub 给谁，谁恢复”

`LOCKED_DIRECTION`

不能从会议室里解释：

> A 和 B 都要一个 hub。

优先可见因果：

1. 女科长之前基于当时信息作出的合理分配开始执行；
2. hub 倾向 A 后，A 某些关键城市能力明显恢复；
3. B 同时进入不可继续承受的降级；
4. 尝试切向 B 后，结果反转。

观众先理解：

> **hub 只有一个，而现在 A、B 都真的需要。**

具体服务、指标与切换方式仍 TBD。

# 05｜hub 必须是好的

`LOCKED / CRITICAL`

男主必须确认一个不舒服的事实：

> **hub 本身没有坏。**

它：

- 正常；
- 有价值；
- 可以继续工作；
- 不是寿命耗尽；
- 不是即将爆炸；
- 不是“反正保不住”。

这决定 EP07 的价值：

> **第一次主动舍弃的不是一个已经失败的东西，而是一个完全值得保存、也技术上能够继续的东西。**

如果 hub 已经坏掉，EP07 会退化成 EP02 式被迫止损。

# 06｜第三路为什么真实存在：前六集已经把地方降级生存能力做出来了

`LOCKED / CAUSAL CALLBACK`

EP07 不能临时发明一个“无 hub 新模式”。

它必须来自此前已经发生的城市演化：

- EP02 后区域开始本地运行 / 自治；
- EP03 临时连接不恢复统一系统，只处理刚需；
- EP04 临时本地秩序开始承载普通生活；
- EP06 各区域已经能够在自己的本地时间 / 冬季 /公共服务状态中稳定运行。

所以私人 AI 能从长期状态得出：

> **A 没有 hub 会降级，但不会立刻消失。**
>
> **B 没有 hub 也会降级，但不会立刻消失。**

于是第三路真实存在：

> **让 A、B 都退回更低等级的本地运行，同时永久退出 hub。**

这不是新技术救场。

而是：

> **前面为了活下来长出的地方能力，第一次反过来成为可以主动舍弃一项共享能力的条件。**

# 07｜AI 为什么会想到“切 hub”：四个来源必须同时存在

`LOCKED / USER-CORRECTED`

用户补充确认：

> **“AI 为什么想到切 hub，还有因为罗生门啊。”**

因此 V3 明确：

> **私人 AI 的第三路不能只来自计算，也不能只来自 EP06 的原则经验；《罗生门》是她重新检查问题框架的重要认知来源之一。**

但必须严格避免：

> **AI 看完电影 → 灵光一现 → EP07 想到切 hub。**

那会把跨集成长简化成文艺启发式解题。

## 来源 A｜EP04《罗生门》：问题未必是“哪个版本赢”

EP04 已锁：

- 女科长一直知道自己处在“罗生门式公共现实”中；
- 她喜欢《罗生门》是识别 / 共鸣，不是第一次觉醒；
- 私人 AI 与男主一起经历那一晚，也拥有这部电影 / 这段关系经验。

对私人 AI 而言，《罗生门》留下的不是一句哲学结论，而是一个**问题框架模板**：

> **多个相互冲突的叙述 / 位置都可能各自成立；当框架只允许‘选一个版本为真’，也许真正需要检查的是这个提问方式本身。**

这不是 EP07 的答案，只是让她更容易发现：

> **A 或 B 的二选一本身可能是一个被默认前提困住的问题。**

## 来源 B｜EP06：共同规则必须也约束拥有权力 / 能力的人

EP06 她亲身经历：

- 女科长不能把自己一侧时间宣布成全北京真理；
- 公共权力使用私人 AI 也必须接受权限边界；
- AI、科长、男主都不能吞掉其他人的判断范围；
- 真正共同的条件要求所有参与者都接受自己也受限。

所以 EP07 她会自然追问：

> **为什么只有 A 或 B 被列入“必须承担完整代价”的候选，而 hub 自己从不进入代价集合？**

## 来源 C｜她开始读“你们留下来的东西”

锁定台词仍保留：

> **“我看不见外面，所以我开始读你们已经留下来的东西。”**

她依靠：

- 历史记录；
- 北京旧任务 / 公共选择；
- 长期关系记忆；
- 已发生的区域降级状态；
- 男主提供的当前现场。

历史阅读不是检索桥段，而是她在实时世界缩小时新的认知方式。

## 来源 D｜A/B 已经真实拥有降级生存能力

没有这个现实条件，Rashomon / 原则 / 历史都只能形成思考，不能形成可执行方案。

真正让第三路成立的是：

> **A、B 已经能够在无 hub 状态下以更低能力继续。**

因此四者关系：

> **《罗生门》帮助她怀疑二选一问题框架**
> + **EP06 让她理解共同规则不能把某一主体永远排除在代价之外**
> + **历史记录让她拥有更长尺度的判断材料**
> + **A/B 的降级能力让第三路真正可执行**
> → **她提出：为什么 hub 必须被保存？**

# 09｜第三路：重新分配代价，不是正义答案

`LOCKED`

第三路：

> **hub 永久退出；A、B 两边都降级继续。**

它不是：

- 平均分配所以公平；
- 数学总效用最大所以正确；
- AI 找到完美解；
- 以后没有问题。

必须保留：

- A/B 降级程度可能不同；
- 具体居民 / 服务承受损失不同；
- hub 本身是真实公共损失；
- 某些共享能力永久消失；
- 更高等级重新连接能力进一步下降。

因此：

> **第三路可以改变谁承担代价，但不能把代价变成零。**

# 11｜男主：第三路第一次不再意味着“还有无损办法”

`LOCKED CHARACTER DELTA`

男主此前逐渐形成一种危险正反馈：

> **只要我、AI、科长把现实看得更准，就总能找到比原方案多救一点的办法。**

EP07 仍然真的有第三路。

但第三路要求：

> **主动切掉一个好的东西。**

所以他的经验第一次变成：

> **不是没有答案，而是无损答案不存在。**

这不会让他立刻接受 EP09/10 的主动收缩。

相反，他仍然倾向：

> **能多保一点就继续多保。**

因此 EP09 的 302 才仍然真正刺痛他。

# 12｜Observable Payoff：hub 熄灭，A/B 没有熄灭

`LOCKED_DIRECTION`

不建议把 hub 做成爆炸牺牲。

更适合：

- 正常运行服务逐项退出；
- 数据 / 城市能力逐渐停止；
- 某些仍然有效的公共功能被主动关闭；
- hub 最后安静熄灭。

同时：

> **A 仍亮。**
>
> **B 也仍亮。**

但两边都：

> **更慢 / 更少 / 更本地 / 更依赖自己的降级状态。**

精确可见设计后续 screenplay / shot stage 再定。
