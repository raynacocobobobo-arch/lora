# 01｜Greenlight Contract

## Decision

> **GO_PILOT — PASSED / PROJECT EXPANDED TO 10-EP FIRST SEASON**

This project has already moved beyond the original 3–5 episode pilot-development stage. The following Greenlight fields are preserved as the current series contract.

## Premise

> 月面轨道巨型城市 **第二新北京市** 遭陨石撞击。为了避免城市立即毁灭，各区域 AI 脱离统一城市模型转入本地运行。它们没有发疯、没有撒谎，而且在自己的局部条件下都可能是正确的。问题是，许多个局部正确的北京逐渐无法再组成同一个北京。一个原本正在被自动化边缘化的现场处置员，在少数“现实冲突”案件中重新变得暂时不可替代；最终，他必须参与让那个未来可能再次不需要自己的复杂世界重新回来。

### A Story

> **第二新北京市逐渐失去共同现实，并最终重新成为“同一座北京市”。**

“恢复”不等于恢复成灾前，也不等于一份中央数据库覆盖所有地方历史。

### B Story

> **一个害怕自己不再被需要的人，在灾难中终于在特殊问题上重新被需要，最后却主动参与结束那个证明自己特别重要的破碎世界。**

## Audience Promise

每集最稳定的重复快感：

> **正常生活 → 一个细小矛盾 → 越查越合理 → 多个答案都可能正确 → 人必须做决定。**

更完整地说：

> **每一集从第二新北京市一件极普通的生活事务进入，然后让观众发现：这件事在城市另一个系统 / 区域 / 公共现实里根本不是同一件事。**

本剧不是传统“灾难越来越大、爆炸越来越多”的升级爽剧。升级发生在**选择的性质、责任层级和代价**上。

## Central Cost

没有一个单独的人、AI 或系统能够：
- 看见完整北京；
- 同时拥有物理事实、公共合法性和全部历史；
- 无损保留所有灾后已经真实成立的生活。

因此每一次公共行动都可能制造：
- 输家；
- 新例外；
- 不可逆损失；
- 后续政治 / 伦理债务。

最终成本落到：
- 北京本身必须变小；
- 多个真实城市部分与数字连续性结束；
- 男主失去私人 AI 的连续主体；
- 男主同时失去“坏掉的世界必须需要我”的身份条件。

## Escalation Runway

升级不是“更大的事故”，而是：

> **物理事实 → 多个局部正确答案 → 公共后果 → 区域利益 → 合法性 / 公共暴力 → 城市治理 → 私人代价。**

Pressure Ladder 的正式结构见 `Series-Ladders-Payoff-V0.1-CANONICAL.md`。

## Production Repeatability

可持续的重复生产锚点：
- 3 个核心人物：男主、女科长、私人伴随 AI；
- 去人格化城市系统 AI；
- 男主部门；
- 男主家；
- 302 楼；
- 固定跨区接口 / 交通—维护节点；
- 同一套“成熟城市、普通生活、一毫米不对劲”的视觉语法；
- 每集优先复用既有城市资产，而不是重新造一个全新科幻空间。

每个 recurring location 后续生产统一锁 5 类信息：
1. `Geometry`
2. `Material / Age`
3. `Fixed Anchors`
4. `Camera Anchors`
5. `Mutable State`

## Cheapest Pilot Test — retrospective status

原 Skill 要求的“cheapest pilot test”没有在历史对话中以单独字段最终锁名，但实际开发已经完成了等价验证：

- EP01：卖点是否能在 2–3 分钟内被看懂并形成强钩子；
- EP02：问题能否从单点异常升级成城市级选择；
- EP03：同一机制能否换一个生活领域再次成立；
- EP04：能否在不靠大事故的情况下靠人物 / 日常维持观看；
- EP05：机制能否承载真正的情感和连续性问题。

结论：**Pilot hypothesis 已通过，项目已扩展为 10 集第一季。**

## Character deep questions

> **男主：我是不是只有不可替代才有价值？**  
> **女科长：一座城市能不能把共同现实押在少数“正确的人”身上？**  
> **私人 AI：当我已经无法验证你的世界，我们还能不能共享现实？**

三者是同一个命题的三个尺度：

> **个人价值 / 公共现实 / 私人现实。**

## Character arc guardrails

### 男主
- 不是“人类价值战胜 AI”；
- 终局不是证明“AI 永远替代不了人”；
- 终局必须主动参与结束那个让他重新不可替代的灾难条件。
- 早期提出过“让自己的判断可以被别人重复和继承”的成长方向，当前保留为 `STRONG DIRECTION / NEEDS_REVIEW`，尚未单独绑定具体 episode beat。

### 女科长
她和男主不是简单领导 / 下属：
> **男主确认现实允许什么。**  
> **女科长决定公共现实接下来必须发生什么。**

内部关系演化可理解为：
> 不批准 → 要求确认 → 有限批准 → 主动询问判断 → 把问题从逐案裁决推到公共过程。

这是一条功能弧，不锁为固定对白。

### 私人 AI
核心：
> **AI失去的是“世界”，不是“自我”。**

内部人物弧：
> **“我知道” → “我不知道” → “我相信你”。**

不是变笨、失忆、人格崩坏。

# 05｜Artificial Winter / “北京性”

冬季不是自然季节，也不是一台“下雪机器”。

功能上可以涉及：
- 环境温控；
- 降雪；
- 冰面 / 冬季公共空间；
- 植物周期；
- 湿度 / 供暖；
- 光照周期；
- 交通参数；
- 商业 / 社会活动；
- 春节前后的城市环境切换。

核心：
> **冬天本质上是一件整座城市一起同意“现在是冬天”的事。**

它并非生命保障最高优先级，事故后被延后完全合理；但它被长期保留，因为：

> **北京应该有冬天。**

终局因果：
> 最低共同现实执行  
> → 剩余北京形成持续共同运行  
> → 一个唯一有效北京标准时间  
> → 一个公共“现在”  
> → 统一冬季协议  
> → 雪。

雪是证据，不是解决方案。

# 11｜Hard Prohibitions

- 不把 AI 写成反派 / 弱智；
- 不把男主写成全城唯一人类真理节点；
- 不把女科长写成万能领导 / 会议室结局机器；
- 不把私人 AI 写成嫉妒女友；
- 不把“以现场为准”写成人类优越论；
- 不让统一 AI 恢复后一键覆盖北京；
- 不把本地真实历史格式化掉；
- 不把“最低共同现实 + 最小共同体”重新讲成两套理论；
- 不把 EP07 第三路写成无损最优解；
- 不把 EP08 写成坏人发动内战；
- 不把 EP09 写成男主“终于不需要 AI”；
- 不让私人 AI 通过 upload / fusion / copy 偷偷存活；
- 不让私人 AI 欣然求死替男主卸责；
- 不用最后一秒“大批居民未撤”制造廉价残酷题；
- 不把 handshake 画成两个 AI 人形握手；
- 不等 AI 全死后再做“纪念灯光”；
- 不把雪做成牺牲结束后的庆功礼花；
- 不提前锁对白替代尚未确定的因果 / 工程逻辑。
