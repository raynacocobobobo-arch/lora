# 01｜Why four parallel ladders

早期开发曾把太多东西都塞进 Reveal Ladder。后续已经明确，至少要拆开：

> **1. Reveal Ladder：观众 / 角色如何理解“北京发生了什么”**  
> **2. Public Action Ladder：女科长 / 公共秩序如何从逐案裁决升级到城市治理**  
> **3. Companion Access Ladder：私人 AI 与男主共享现实如何逐步缩小 / 反转**  
> **4. Pressure Ladder：每次选择的压力类型如何升级**

Reveal 不应该“一集一个答案”。

重要真相的正常节奏是：

> **出现 → 重复 → 旧解释失效 → 角色确认新解释。**

## Public legitimacy rule

公共过程不能回答：
> **“唯一真正的北京是哪一版？”**

它最多能合法地决定：
> **“从现在开始，为了还能一起生活，哪些最低事实 / 规则 / 接入条件必须共同有效？”**

上层公共机制不能直接把“最低事实清单”作为神谕发下来。

# 06｜Moment of Grace

`LOCKED`

Moment of Grace 最终不是出生、避难站、公交等旧 brainstorm。

当前唯一 Canon：

> **EP08 检查点 / 两套公共安全 AI 对峙。**

核心：
- 两边不承认彼此公共暴力合法性；
- 但 EP03 医疗女孩进入射界后，两边都承认：
  > **这个受保护人员现在不能被射击。**
- 武器因此短暂停止；
- 这不解决“谁有资格拿枪”，只建立“枪不能对谁开”的共同约束；
- 女科长随后成功剥离孤岛武装控制；
- 外侧 AI 又按合理规则清除失去合法控制链的武装平台。

Moment of Grace 的政治价值：

> **完整公共现实已经彼此冲突，但少量不可单方面推翻的共同约束，仍然可能先约束行动。**

它是 EP09 最低共同现实方案的直接出生点。

# 09｜No duplicate-mechanism rule

中间开发反复暴露一个重要制作 / 结构规则：

> **新一集不能只把“两个系统冲突 → 找参数 → 成功操作”换皮。**

因此每集必须改变至少一项：
- 冲突层级；
- 公共责任；
- 角色关系；
- 决策性质；
- 代价类型；
- 观众对 premise 的理解。

当前差异化：
- EP01：存在 / 身体风险；
- EP02：城市切分 / 公共责任；
- EP03：有限连接 / 不共享现在；
- EP04：日常共存；
- EP05：连续性 / 失去的未来；
- EP06：同步 / 信任链；
- EP07：主动舍弃共享中心；
- EP08：合法性 / 公共暴力；
- EP09：治理 / 承认与舍弃；
- EP10：私人代价 + 城市重组。

# 10｜Final thematic test

Highest theme:

> **秩序与牺牲**

每一个后续新增机制 / scene 都应过这三个检查：

1. **谁在维持什么秩序？**
2. **这个秩序把代价分配给谁？**
3. **做决定的人凭什么认为自己有资格让这个代价发生？**

并保留不适：

> **牺牲不自动高尚；秩序不自动正确。**
