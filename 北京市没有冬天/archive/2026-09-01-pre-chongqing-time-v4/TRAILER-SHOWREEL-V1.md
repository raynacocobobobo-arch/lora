# 01｜定位

这支片不是“EP01–EP10 每集各展示一点”的汇报式预告。

当前锁定定位：

> **以 EP05 婚礼作为声音与空间母体，用一段传统婚礼誓词贯穿整支视觉预告；画面不解释誓词，而持续展示一座正在失去“在一起”能力的北京。**

核心不是交代剧情答案，而是让观众先记住：

- 第二新北京长什么样；
- 这座城市如何冷静地失去共同空间、共同时间、共同秩序；
- 少数真正的人体动作如何在巨大公共系统里突然变得非常有重量。

私人 AI **不是本支预告必须出现的角色**。本支首先卖世界、动作、空间和气质；不得为了角色介绍破坏视觉节奏。

# 02｜誓词声音主轴

当前 V1 使用传统婚礼誓言结构，不写科幻哲学誓词：

> 我愿意与你结为夫妻。
>
> 从今以后，
>
> 无论顺境还是逆境，
> 无论富有还是贫穷，
> 无论健康还是疾病，
>
> 我都会爱你、珍惜你、陪伴你，
>
> 直到死亡将我们分开。

精确措辞仍允许后续根据 EP05 正片人物口吻做窄修，但必须保持：

- 普通婚礼现场可自然说出口；
- 有真实传统誓词原型感；
- 不出现“现实 / 数据 / 同一个时间 / 同一个世界 / 连续性 / 协议”等作者主题词。

整支片的反义逻辑是宏观的：

> **声音一直承诺“在一起”；画面一直展示“在一起正在变得困难”。**

禁止把每一句机械翻译成一个字面反义镜头。

唯一明确保留的强字面反义节点：

> **“直到死亡——” = 婚礼现场最稳定的结合动作。**
>
> **“将我们分开。” = EP01 女科长抓住正在坠落的男主。**

语言说“分开”，动作做“连接”。

# 03｜视觉风格锁定

用户明确偏好：

> **严肃、冷静、电影感的赛璐璐动画视觉。**

这里作为高层视觉方向，不复制任何现存作品的具体镜头、构图或角色设计。

执行关键词：

- hand-drawn cel animation feeling；
- 明确线稿边界；
- 赛璐璐分块阴影，不做大量写实软渐变；
- 机械 / 城市背景细节密集，人物相对简洁；
- 冷灰、蓝灰、钢铁色为大底，红色只做少量公共标识 / 婚礼红毯 / 告警点缀；
- 光影克制，少炫光、少 lens flare、少现代 CG bloom；
- 建筑、站台、公共设施、轨道、气密门、导视系统带旧工业设计层累积感；
- 允许手绘背景中的轻微不均匀质感；
- 不做萌系动漫、偶像 PV、游戏角色展示片、纯写实 VFX 灾难大片。

构图纪律：

> **至少约一半镜头机位应基本不动。**

大事件优先远拍；真正允许突然极近的视觉对象主要是：

- 手；
- 戒指。

# 04｜导演视点纪律

## 4.1 城市动作 > 人物表情

能用城市本身表达，就不加人物“看着它震惊”。

例如：

- 一侧城市逐层亮起，另一侧逐层熄灭；
- 巨构慢慢分离；
- 同一站台两侧显示不同时间；
- 两套安全平台同时进入标准武器准备。

人物不是每个事件的解释器。

## 4.2 系统恐怖来自“正确”

EP08 机器人 / 安全平台不得表现成抽搐、发疯、病毒感染。

正确视觉：

> **识别 → 转向 → 标准警告 → 武器展开 → 瞄准。**

两侧动作都干净、准确、规范。

恐怖来自：

> **它们没有疯。**

## 4.3 人体动作必须稀缺

全片城市和机器不断动作，但人物尽量少做大动作。

真正突出的身体动作只保留：

1. 男主坠落；
2. 女科长抓住他。

此前避免大量奔跑、打斗、尖叫、拥抱、摔倒，以保护抓手的冲击力。

## 4.4 多拍状态，不执着于“事件完成”

优先：

- 桥还在被撑，但已经产生不可逆位移；
- 机器人尚未开火，但彼此已经完成瞄准；
- 新郎仍存在，但投影稳定性出现轻微变化；
- 公共系统仍正常运行。

不要把所有结果都交代完。

# 05｜V1 主镜头池

本支预告主动作只取以下 Canon 事件，不平均照顾十集。

## A｜EP05 婚礼公共观景厅

母空间。

视觉：

- 巨大公共观景厅；
- 中轴对称；
- 红毯；
- 宾客；
- 新娘 / 新郎；
- 巨大舷窗外可见第二新北京巨构与地球；
- 空间中仍有公共导视、公共服务设施、维修痕迹。

婚礼不是与城市隔绝的浪漫结界，而是发生在公共系统内部的私人仪式。

## B｜EP02 跨区巨构缓慢分离

不是爆炸镜头。

视觉：

- 极远固定大全景；
- 一条灾后已经长期被支撑、包覆、抢修的巨大跨区结构；
- 两端仍亮着；
- 临时支撑设施仍在工作；
- 结构非常慢地离开彼此。

动作词：

> **慢慢分开。**

## C｜EP06 双时间 / 双季节火车站台

用户明确修正：

> **时间差必须优先通过火车站台两侧同时显示不同时间来视觉化，而不是先切一个钟再切另一个钟。**

推荐视觉：

- 同一个轨道站 / 对向站台；
- 画面同时容纳两侧；
- 一侧电子公共时钟例如 `16:42`；
- 另一侧例如 `15:57`；
- 数字仅为分镜占位，正片精确时间 TBD；
- 两边人群衣着、灯光、气候痕迹可同时显示不同季节节律；
- 一侧有雪 / 清雪痕迹，另一侧无雪；
- 列车继续正常到发；
- 无人解释。

这是 V1 的招牌设定镜头之一。

## D｜EP07 A/B 城区能力此消彼长

视觉：

- A、B 分居大画面两侧；
- 共享 hub / 系统状态变化后，A 城区逐层恢复；
- B 同时逐层降级 / 变暗；
- 状态反转时，结果反过来。

本支只展示“无法同时满足”的视觉因果。

**禁止展示最终 hub 被永久舍弃的完整结果。**

## E｜EP08 两套公共安全系统镜像式对峙

视觉：

- 同类 / 同体系公共安全平台；
- 双方标准识别；
- 双方同时警告；
- 双方武器组件展开；
- 双方互相锁定。

**不展示最终程序化清除结果。**

## F｜EP01 重力异常与男主坠落

视觉：

- 先出现小物件 / 维修碎屑向错误方向漂；
- 男主失去稳定落脚；
- 超大全景里，他向巨大空间坠落；
- 人在城市结构中越来越小。

坠落必须舍得给时间，不剪成 0.5 秒动作花活。

## G｜EP01 女科长抓手

只在后段出现一次。

动作必须：

- 突然；
- 有真实重量；
- 不优雅；
- 不慢动作美化；
- 手腕、衣物和身体惯性都成立。

落点：

> **“将我们分开。”**

## H｜EP09 302 极小暖窗（可选强静镜）

视觉：

- 巨大黑色城市外壳；
- 临时管线 / 兼容结构 / 修补设施；
- 极小居住单元仍有一盏灯。

不解释 302 的制度结论。

功能：

> 巨构与一个真实生活单位的尺度反差。

# 06｜约 85–90 秒 V1 时间线 / Shot Design

精确秒数为当前剪辑设计，不是最终锁死 timing。

## SEQ 01｜婚礼秩序｜0–10s

### SHOT 01｜约 6s｜超大全景｜固定

婚礼观景厅中轴构图。

声音：

> “我愿意与你结为夫妻。”

人物很小，城市和公共空间很大。

### SHOT 02｜约 3–4s｜低机位 / 中远｜固定

红毯边缘；公共清洁设备缓慢经过；远处婚礼继续。

声音：

> “从今以后……”

私人仪式与城市公务系统同时发生。

---

## SEQ 02｜空间开始裂开｜10–22s

### SHOT 03｜约 6s｜极远大全景｜固定

EP02 跨区巨构非常缓慢地分离。

无爆炸、无快速摄影。

### SHOT 04｜约 2–3s｜普通生活静镜

住宅 / 公共生活小空间里有人继续吃饭或做普通事情；远处通过窗户能看到跨区结构位置已经改变。

没人专门看它。

---

## SEQ 03｜没有共同现在｜22–35s

### SHOT 05｜约 8s｜火车站台 / 轻微横移或固定深景

**核心修正镜头。**

同一轨道站两侧同时进入画面：

- 左侧站台公共时间：一套时间；
- 右侧站台公共时间：另一套时间；
- 两侧季节 / 衣着 / 地面雪迹 / 光照状态不同；
- 列车按各自秩序运行。

不允许“角色解释为什么”。

观众应自己发现：

> **同一北京公共交通空间里，两边已经不共享同一个现在。**

### SHOT 06｜约 2s｜细节静镜

一个画面内同时读到两侧时间，或通过站台纵深同时看到两块时钟。

不做两个钟分别剪切的说明式镜头。

### SHOT 07｜约 5s｜超大全景｜固定

### SHOT 08｜约 3s｜同构图

## SEQ 06｜一个身体失去秩序｜58–69s

## SEQ 09｜城市不为私人消失停机｜78–90s

### SHOT 20｜约 5–6s｜戒指极近景

回婚礼。

新娘继续戴戒指。

不要立刻把“投影异常”做成镜头主体。

### SHOT 21｜约 2–3s｜尽量同镜延续

- 电子爆响；
- 悲情音乐 hit；
- 新娘夸张反应；
- 宾客惊呼；
- 揭露新娘也是重建主体。

### SHOT 22｜约 3–4s｜回到开场同构大全景

构图几乎与 SHOT 01 相同。

但新郎位置已经空了。

大厅、地球、第二新北京仍在。

可让一列公共轨道车从巨窗外经过；公共系统继续正常运行。

不追加哲学对白。

CUT TO BLACK。

> **《北京市没有冬天》**

# 07｜节奏波形

不是线性 crescendo。

当前节奏：

> **静 → 静 → 巨变 → 普通生活 → 空间/时间异常 → 程序化加速 → 长坠落 → 极静 → 抓手瞬间爆发 → 极静。**

原则：

- 前 20 秒必须敢慢；
- 中段只有一小段真正快切；
- 男主坠落反而重新拉长时间；
- 抓手只打一拳；
- 结尾不继续升级动作，而回到公共系统照常运行。

# 08｜声音设计

声音三层：

## A｜婚礼誓词

最前层，正常、克制、真实婚礼语气。

## B｜城市持续运行

贯穿：

- 轨道；
- 通风；
- 风雪；
- 气密门；
- 机械锁止；
- 公共广播；
- 机器人标准提示。

允许声音先于画面跨切，让不同区域听起来仍属于一个北京，同时视觉上已经彼此错开。

## C｜结尾

“将我们分开”以后，誓词结束。

新郎消失不再加解释对白。

最后留下：

> **城市继续运转的声音。**

- EP01 男主坠落；
- EP01 女科长抓手，但只能后段一次；
- EP02 巨构最终会分开这一视觉事实；

- EP08 最终程序化清除结果；
- EP09 302 最终公共边界决定；
- EP10 私人 AI 最终握手 / 连续性结局；
- EP10 完整共同北京时间恢复；
- EP10 最终统一冬季 / 完整雪结局。

原则：

> **展示问题已经大到什么程度，不展示人物最后如何回答。**

# 10｜本文件与 Canon 的关系

`TRAILER-SHOWREEL-V1.md` 是：

> **获用户批准的预告执行设计。**

它不是：

- 新的剧情 Canon；
- 对各集 TBD 工程机制的提前锁死；
- 对 screenplay shot timing 的强制继承。

例如 EP06 站台双时间是当前预告的具体视觉设计；它建立在“两地拥有不同有效本地时间 / 冬季”的 Canon 上，但不自动要求 EP06 正片必须逐帧复制本预告镜头。

后续修改此预告可以迭代 V2，不应默默改 Master 或 Episode Snapshot。
