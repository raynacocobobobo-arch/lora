# 《北京市没有冬天》TRAILER / TEASER V2

- Updated: 2026-09-01
- Status: `APPROVED V2 / NON-CANON EXECUTION LAYER`
- Target duration: `~56s`
- Basis: Trailer Showreel V1 + active Canon + user revisions
- Purpose: high-density visual teaser with environmental storytelling, spectacle, crisis pressure, and deliberate ordinary-life contrast.

---

# 01｜V2 定位

V2 不再是 85–90 秒的缓慢 showreel，而是：

> **45–60 秒高密度视觉 teaser。**

核心目标：

1. 奇观强度显著提高；
2. 信息密度显著提高；
3. 仍保留冷静赛璐璐电影感，不剪成普通灾难片 / 游戏 PV；
4. 危机感来自环境与公共系统，而不只来自爆炸；
5. 保留少量慢节奏普通生活镜头作为反差，不做长篇铺垫。

因此 V2 的节奏不是“全程快”，而是：

> **稳 → 奇观 → 日常 → 异常 → 奇观 → 日常 → 程序化危机 → 人体危机 → 婚礼极静 → 抓手 → 极静。**

普通生活不是要删，而要压成 **1.5–3 秒的对照针脚**：

> **城市越坏，生活越照常，危机越重。**

---

# 02｜视觉方法

用户希望强化的高层电影语言：

- 严肃赛璐璐；
- 手绘机械背景；
- 静态巨构；
- 城市 / 公共系统优先于人物表情；
- 环境叙事；
- 程序化动作制造恐怖；
- 人体大动作稀缺；
- 日常与灾难相邻形成反差。

本文件不复制任何现存作品的具体镜头、构图或角色设计。

## 2.1 赛璐璐方向

- 2.39:1；
- 明确线稿边界；
- 2–3 档硬边 cel shading；
- 冷灰蓝 / 钢铁色主导；
- 红色仅用于婚礼红毯、公共标识、告警；
- 背景机械细节密集，人物造型相对克制；
- 少 bloom / lens flare / 写实软渐变；
- 允许旧工业设备、维修补丁、临时结构、导视系统累积。

## 2.2 环境叙事

每个奇观镜头至少携带 1–2 个“生活仍在继续”的信息：

- 维修臂还在工作；
- 清雪设备照常运行；
- 通勤者继续等车；
- 公共广播仍然正常；
- 清洁机器人继续拖地；
- 小店继续营业；
- 自动门 / 气密门按程序关闭；
- 安全平台以标准流程互相警告。

危机感公式：

> **灾难状态 × 正常运行 = 不安。**

# 03｜誓词声音骨架

V2 继续使用传统婚礼誓词，不改为科幻主题台词。

为适配 56 秒，可在录音 / 剪辑层压缩中段停顿，但保留结构：

> 我愿意与你结为夫妻。
>
> 从今以后……
>
> 无论顺境还是逆境，
> 无论富有还是贫穷，
> 无论健康还是疾病……
>
> 我都会爱你、珍惜你、陪伴你。
>
> 直到死亡——
>
> 将我们分开。

继续禁止：

- 同一个现实；
- 同一个时间；
- 数据；
- continuity；
- 协议；
- 世界等解释主题的作者词。

唯一明确的强字面 counterpoint 保留：

> **“将我们分开。” → 女科长抓住坠落男主。**

# 05｜节奏控制

## 5.1 不是全程快切

56 秒里必须保留三类速度：

### 慢 / 稳（2–4s）
- 婚礼；
- 巨构分离；
- 双时间站台；
- 普通生活；
- 戒指。

### 中快（2–3s）
- A/B 此消彼长；
- 暴雪设施；
- 安全平台响应。

### 爆点（3–4s但动作猛烈）
- 男主坠落；
- 女科长抓手。

V2 的高密度不是靠所有镜头都 0.5 秒，而是：

> **每镜至少传递 2–3 层信息。**

## 5.2 普通生活镜头保留原则

只保留 3 个“日常针脚”：

1. 婚礼里的清洁机器人；
2. 巨构分离后的居民 / 小店；
3. 程序化危机前的维修工 / 小店 / 服务设备。

单镜 1.5–3 秒。

它们不负责叙事推进，而负责建立：

> **北京还活着。**

只有北京还活着，危机才不是“世界末日 CG”，而是：

> **一个仍有人生活的城市正在坏掉。**

# 06｜环境危机设计

每个主要视觉都必须带“危机证据”。

## 婚礼厅

- 维修补丁；
- 公共导视；
- 清洁机器人；
- 轨道车；
- 远处施工灯。

## 第二新北京外景

- 局部结构断开；
- 临时桁架；
- 外壳补板；
- 非均匀照明；
- 维修臂持续工作。

## 双时间站台

- 两个公共时间同帧；
- 两套季节状态；
- 两边广播 / 列车照常运行；
- 人群完全习惯。

## 暴雪

- 清雪设施仍工作；
- 警示灯仍亮；
- 公共设施没有停摆，只是越来越吃力。

## 机器人对峙

- 标准警告；
- 标准动作；
- 标准队形；
- 没有狂暴状态。

危机来自：

> **正常系统已经无法保证共同秩序。**

# 07｜V2 Key Visual 优先级

## KV-01｜双时间 / 双季节火车站

最高优先。

必须一帧读到：

- 同一北京公共交通设计体系；
- 两个时间；
- 两个季节；
- 正常通勤。

这是最有作品辨识度的一张。

## KV-02｜婚礼公共观景厅

负责整支 teaser 的视觉圣经：

- 中轴；
- 红毯；
- 地球；
- 第二新北京；
- 公共系统；
- 带伤运行。

## KV-03｜公共安全平台互相瞄准

要求：

- 同体系；
- 非机甲大战；
- 标准动作；
- 公共空间；
- 程序化恐怖。

## KV-04｜跨区巨构慢分离

重点不是断，而是：

> **维护还在继续，连接仍然丢失。**

## KV-05｜男主坠落 + 女科长抓手

两帧一组：

- A：极远坠落 / 城市压倒人物；
- B：极近抓手 / 真实身体重量。

## KV-06｜普通生活反差帧

不是“主海报”，但必须有一张风格测试：

- 小店 / 住宅 / 维修工 / 清洁机器人；
- 后景存在巨大异常；
- 前景人物继续生活。

目的：避免整支 teaser 变成纯 CG 奇观合集。

# 09｜V1 → V2 变化

V2 相比 `TRAILER-SHOWREEL-V1.md`：

- 85–90s → **~56s**；
- 提高奇观密度；
- 双时间站台继续作为第一设定奇观；
- 环境叙事被提升为硬规则；
- 危机必须通过公共系统 / 城市状态可见；
- **恢复并保留慢节奏普通生活反差，但压缩为 3 个短针脚**；
- 不再让普通生活形成长段落；
- 抓手保留为唯一人类动作高潮；
- 结尾更快，不展开完整剧情反转。

V1 保留为历史批准版本，不删除；V2 为当前优先 teaser 执行稿。
