# 00｜Purpose

This file locks the visual language for subsequent scene generation while preserving real scene diversity.

Core rule:

> **Canon decides WHAT exists, WHERE the scene is, WHEN it occurs, and WHAT is happening.**
>
> **This Visual Bible + approved KV anchors decide HOW those facts are visualized.**

A scene fails if either layer fails:

- visually consistent but contradicts Canon / episode action;
- Canon-correct but visually belongs to another science-fiction production.

New V1.1 principle:

> **“像同一部片”与“像这场戏”必须同时成立。**

---

# 01｜Required Reading / Canon Handshake

Before generating ANY new scene image, KV, storyboard keyframe, environment concept, or generation segment frame, the executing ChatGPT / Codex / Agent MUST read the relevant project state.

Minimum read order:

1. `CURRENT.md`
2. `ACTIVE-DOCS-INDEX.md`
3. `BEIJING-NO-WINTER-MASTER-CANON-V3.2.md`
4. all active narrow Canon patches affecting the scene
5. the highest-numbered active `Pilot-EPXX-LATEST-CANON-SNAPSHOT-V*.md` for the relevant episode
6. current execution-layer document, currently `TRAILER-TEASER-V2.md` for teaser assets
7. this file: `VISUAL-CONSISTENCY-BIBLE-V1.1.md`
8. `SCENE-PROMPT-TEMPLATE-V1.1.md`
9. approved visual anchors available in the current working context

When a current active Episode Snapshot compresses an older scene design but leaves execution details `TBD`, older detailed episode documents MAY be read for scene-space provenance, but only if they do not conflict with the active snapshot. Active Canon always wins.

Do not rely on memory alone when the repository can be read.

### Authority split

For factual / story conflicts:

> **later explicit user confirmation > narrow Canon patch > highest active Episode Snapshot > Master Canon > execution docs > visual prompt.**

For style / rendering conflicts:

> **approved KV visual anchors + this Visual Bible > one-off prompt wording > model-default science-fiction aesthetics.**

The model MUST NOT use visual style as permission to alter plot facts, and MUST NOT use plot text as permission to invent a new art direction.

# 03｜Approved Visual Ground Truth

The following approved KVs are the current visual anchors. Future images are judged against them as a SET, not against generic genre references.

## KV-01｜第二新重庆车站 / dual-time station

Locked lessons:

- monumental enclosed / semi-enclosed railway public infrastructure;
- strict frontal architectural perspective and strong central axis for THIS station scene;
- old white passenger carriages, not green passenger trains;
- vehicles visibly used and slightly worn, never showroom-new;
- dry environment; no rain;
- left = dusk / warm residual daylight; right = night / public lights on;
- aged steel, dark blue-gray structure, restrained public lighting;
- rigid industrial metal signage integrated into architecture;
- station title: `第二新重庆车站`;
- 2.35:1.

## KV-02｜婚礼公共观景厅

Locked lessons:

- monumental public interior;
- strict central axis because the ceremonial space supports it;
- architecture controls composition; people remain small;
- restrained ceremonial red accent;
- Earth / orbital exterior is framed by public architecture and remains subordinate;
- blue public signage, old steel structure, dense but readable mechanical background;
- solemn, controlled cel-animation atmosphere.

## KV-03｜公共安全检查点

Locked lessons:

- symmetrical public-security checkpoint grammar;
- white aged municipal security machines belong to one equipment family;
- blue public guidance panels and industrial barriers;
- procedural order rather than combat spectacle;
- heavy public-infrastructure scale;
- no mecha-war aesthetic;
- order itself creates pressure.

## KV-04｜EP02 跨区可开合连接桥 / APPROVED

Locked lessons newly added in V1.1:

- location is **inside the orbital city**, not a terrestrial bridge and not an open space dock;
- a city-scale opening bridge / connector spans an internal industrial-maintenance chasm;
- the bridge still carries evacuation / transport / logistics function while approaching forced separation;
- mechanical separation is controlled, slow, structural and procedural — never an explosion;
- bridge deck may carry old white municipal transit vehicles, evacuation vehicles, people, logistics carts and active guidance;
- below the bridge is a **bounded internal structural chasm**, with visible walls, service levels, pipes, catwalks, rooms and maintenance layers;
- the distant void must NOT feel infinite: the orbital city has enclosure, shell depth and a finite internal volume;
- the final approved spatial feeling is large enough to be a megacity infrastructure cavity but clearly small enough to remain inside an engineered space-city;
- visual style remains the same aged municipal steel / white equipment / blue signage / restrained warning-light family as KV01–03.

### Anchor usage rule

Do NOT copy one anchor composition into every new scene.

Preserve shared visual DNA:

> **same civilization + same municipal design system + same material age + same animation production + same public-system logic.**

But also preserve scene-specific spatial identity:

> **same art department ≠ same room.**

A new scene should not imitate the station, wedding hall or checkpoint merely to appear consistent.

# 04｜World Visual Identity

The world is:

> **Chinese socialist / municipal retro-futurism inside a mature orbital megacity.**

The key feeling is NOT:

- sleek spacecraft;
- generic cyberpunk megacity;
- NASA-style station;
- generic hard-SF shipyard;
- luxury sci-fi interior;
- post-apocalyptic wasteland.

The key feeling IS:

> **Chinese urban public infrastructure, municipal order, transport, maintenance, housing and public-service logic expanded into an orbital megastructure and kept alive through years of use, repair and modification.**

The city is inhabited, institutional, layered and operational.

---

# 05｜Spatial Grammar — V1.1

Recurring space families may include:

- railway stations / platforms;
- public observation halls;
- checkpoint / transit-control corridors;
- inter-district connectors and opening bridges;
- maintenance and logistics spaces;
- residential / shop / service spaces embedded in infrastructure;
- approved exteriors when the shot function requires them.

### A. Same visual system, different space grammar

Visual consistency MUST NOT force every scene into:

- strict symmetry;
- the same central hall;
- the same platform width;
- the same ceiling structure;
- the same camera height.

Use the geometry required by the actual scene.

Preferred camera discipline remains:

- stable;
- architectural;
- readable;
- deliberate;
- public-space oriented.

### B. Orbital-city enclosure / finite-volume rule

This is a HARD V1.1 correction from KV04 iteration.

The orbital city can contain huge internal cavities, but the viewer should normally still feel:

- enclosing structural walls or shell layers;
- finite service depth;
- repeated internal decks / floors / shafts;
- structural boundaries that terminate perspective;
- artificial, engineered volume rather than endless atmosphere.

Avoid turning every deep interior into an apparently kilometer-after-kilometer open abyss with no enclosing shell.

Rule:

> **巨构可以大，但不能失去“我仍然在一个人工太空城内部”的尺度上限。**

### C. Exterior / cosmic suppression

Earth, stars, orbital exterior and celestial bodies may establish truth, but must normally remain subordinate to the municipal scene.

Prefer exterior views to be:

- framed by windows / apertures / structure;
- small in frame;
- background context rather than hero spectacle.

# 06｜Composition Grammar — V1.1

Default:

> **2.35:1 / stable / architectural / large-scale / readable.**

Priority:

1. choose the composition that best communicates the scene action;
2. use central axis only when the architecture / action supports it;
3. maintain stable perspective and clear public-space function;
4. keep people / mobile equipment small unless human action is the scene subject;
5. one dominant spatial idea and one dominant action per frame;
6. organize mechanical complexity into readable functional systems.

New anti-repetition rule:

> **A new KV must have a clear `scene uniqueness` statement relative to existing approved KVs.**

If the new image could be mistaken for “the station again with different props,” the scene design is not sufficiently differentiated.

---

# 07｜Material Grammar

Primary family:

- thick painted steel plates;
- dark blue-gray structural steel;
- old white municipal machines / rail vehicles;
- welded seams;
- bolts / rivets / panel joints;
- repair plates and reinforcement;
- exposed pipes / service conduits;
- catwalks / guard rails;
- maintenance hatches;
- thick framed industrial signs;
- practical lamps / work lights.

Everything important should feel:

> **maintained, used, repaired, still working.**

Use mild fading, scratches, grime at joints, repaired sections, replacement panels and mismatched maintenance generations.

Do not make the city uniformly rusty, derelict, abandoned or dirty.

---

# 08｜Municipal Equipment Family — V1.1

Recurring equipment must feel procured and maintained by the same municipal system.

Family traits:

- aged white / light-gray shell;
- robust non-luxury geometry;
- visible seams / maintenance panels;
- small municipal markings;
- practical wheels / bogies / mounts;
- slight wear / repair history;
- no humanoid mecha silhouette;
- no glossy concept-car finish.

Current recurring candidates:

- old white passenger / transit carriages;
- white municipal shuttle / evacuation vehicles;
- white maintenance vehicles;
- white cleaning robots;
- white / gray security platforms.

This equipment family is a continuity anchor across otherwise different spaces.

---

# 09｜Public Signage System

Preferred system:

- rigid industrial metal / enamel-like panels;
- visible thickness, frame and fixing hardware;
- blue / dark-blue background + white lettering for municipal guidance;
- muted red only for warning / civic / ceremonial approved uses;
- Chinese main title + restrained small English subtitle where appropriate;
- signs physically attached to walls, beams, barriers, platforms and machines.

Avoid fabric banners, floating holographic text, giant neon commercial signs and decorative slogans across vehicle bodies.

---

# 10｜Color + Lighting

Base palette:

- cold blue-gray;
- deep steel blue;
- charcoal / dark metal;
- aged white;
- restrained warm-white practical light;
- limited muted red accents.

Lighting is primarily municipal and functional:

- ceiling fixtures;
- platform lamps;
- work lights;
- machine lights;
- controlled skylight / exterior spill;
- limited warnings.

Avoid default orange-teal grading, arbitrary neon, excessive bloom, lens flare and showroom reflections.

Plot-required local time / season divergence may override the neutral state, as in KV01.

---

# 11｜Rendering / Animation Language

Target:

> **serious cinematic cel animation with hand-drawn mechanical-background discipline.**

Required tendencies:

- clear line boundaries;
- 2–3 major hard-edged cel-shadow steps;
- structured mechanical detail;
- readable foreground / middle / background;
- restrained gradients and bloom;
- characters visually simpler than architecture;
- no photoreal-concept-art takeover;
- no premium 3D-game-screenshot look as the default.

---

# 12｜Environmental Storytelling Hard Rule — strengthened

Every major spectacle frame MUST contain **1–3 concrete ongoing public operations**.

Examples:

- evacuation continues;
- commuters still wait;
- trains / shuttles still operate;
- maintenance vehicles still move;
- workers still inspect;
- cleaning robots still clean;
- logistics continues;
- service counters / small shops remain open;
- automatic doors / safety systems follow procedure.

Core formula:

> **abnormal city state × normal system behavior = unease.**

For each scene, write the required continuing operations BEFORE generating.

---

# 13｜Crisis Grammar

Primary crisis language:

> **loss of shared space + shared time + shared order while systems remain locally rational.**

Favor:

- structural misalignment / controlled separation;
- incompatible times / seasons;
- duplicated but incompatible public rules;
- infrastructure functioning under degradation;
- maintained connections reaching physical limits;
- orderly systems producing dangerous outcomes through correct procedure.

Avoid explosions, random collapse, robot rebellion, villain displays and generic screaming-disaster imagery as default shorthand.

---

# 14｜Connection / Bridge Scene Grammar — NEW

For city-scale connector / bridge scenes, favor a real mixed public-infrastructure function rather than a decorative sci-fi bridge.

Possible layers:

- people / evacuation;
- public transit;
- service / maintenance vehicles;
- logistics;
- embedded utility conduits;
- structural locking / release mechanisms;
- hydraulic / mechanical supports;
- guidance and safety systems.

Separation should read as:

> **a controlled municipal / engineering action under physical constraint.**

Not:

> explosion / cinematic bridge collapse / arbitrary broken platforms.

For EP02 specifically, the emotional fact is:

> **the connection was kept alive for people and city function until continuing to save it threatened larger structural stability.**

# 15｜Two-Layer Scene QC — NEW

Every generated image must pass BOTH layers.

## Layer A — Visual continuity

1. same civilization?
2. same municipal design family?
3. same material age?
4. same signage family?
5. same equipment family?
6. same rendering production?
7. correct 2.35:1 output?
8. spatial volume plausible for an orbital city?

## Layer B — Dramatic / scene continuity

1. does the image show the actual core action of this scene?
2. is the physical location correct?
3. is the episode timeline state correct?
4. is the conflict readable without generic sci-fi spectacle?
5. are the required ongoing public operations visible?
6. is the background subordinate to the dramatic subject?
7. is the new scene spatially distinct from previous approved KVs?
8. are protected reveals still protected?

Rule:

> **视觉正确但戏不对 = FAIL。戏正确但世界不对 = FAIL。**
