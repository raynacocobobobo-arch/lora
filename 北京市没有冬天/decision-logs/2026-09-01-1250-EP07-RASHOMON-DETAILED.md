# 05｜第三路不能是新技术：它来自 EP02–06 已经长出的地方生存能力

本轮整季回看后强调：

- EP02 开始本地运行 / 区域自治；
- EP03 完成有限连接而非全面重联；
- EP04 临时秩序进入普通生活；
- EP06 各区域已经能在自己的时间 / 冬季 / 服务状态里稳定运行。

所以 EP07 的第三路不是突然发明：

> “无 hub 生存模式”。

而是发现：

> **A/B 其实已经具备无 hub 的降级生存能力。**

因此可以：

> hub 永久退出 → A/B 都回到更低能力但继续存在。

这也是 Preservation Paradox 的重要跨集结果：

> **前面为了救城市长出的地方能力，后来反过来使共享能力可以被放弃。**

# 07｜为什么《罗生门》不能写成“看完电影灵光一现”

EP04 V2 已经明确锁定女科长：

> **她早就知道自己工作在罗生门式公共现实里。**

《罗生门》对她是：

> **识别 / 共鸣 / 熟悉感。**

不是：

> **启蒙 / 顿悟 / 解题。**

本轮不能破坏这条。

同时用户说 AI 想到切 hub “还有因为罗生门”，所以需要给 AI 一个不同但兼容的人物功能。

最终定义：

> **《罗生门》不是给 AI 答案，而是给她一个“既有问题框架本身也可能问错”的认知模板。**

也就是：

> 多个冲突版本都可能各自成立；如果问题一直被写成“哪个版本赢”，也许应该先检查为什么只允许这个二选一。

这个模板到 EP07 映射为：

> **为什么所有人只讨论 A 还是 B，却默认 hub 必须永远被保存？**

# 08｜EP07 AI 第三路的四来源链

当前最终锁定为四部分共同作用：

### 1. EP04《罗生门》

作用：

> **让 AI 更容易怀疑“二选一框架本身”。**

不是提供切 hub 答案。

### 2. EP06 共同规则经验

作用：

> **共同规则也必须约束有权 / 有能力的人自身，不能默认某一主体永远不进入代价集合。**

于是她会问：

> 为什么只有 A/B 承担完整代价，而 hub 被自动豁免？

### 3. 历史阅读 / “你们留下来的东西”

作用：

> **实时北京越来越看不见后，她开始从历史、记录、长期关系和旧公共选择获得更长尺度判断。**

### 4. A/B 已有降级生存能力

作用：

> **让重新框架后的第三路真正可执行。**

所以整体关系：

> **《罗生门》帮助她怀疑 frame**
> + **EP06 提供原则结构**
> + **历史提供证据与尺度**
> + **地方降级能力提供现实可行性**
> → **“为什么 hub 必须被保存？”**
