# 01｜进入本轮时唯一已知开放宏观机制

EP10 V2 完成后，十集宏观结构只剩一个明确未锁项：

> **EP05 真人新娘具体怎样失去连续性。**

此前已经锁定：

- 开场从 EP02 男主 / 女科长开始，再把 POV 转给擦肩而过的新娘；
- 新郎已经在最初陨石事故中失去；
- 新娘在 EP02→EP03 之间只是继续生活，不是在准备婚礼；
- EP03 成功必须成为她后续人生的结构因果之一；
- 但不能简单解释成“男主 / 女科长造成她死亡”；
- 婚礼新郎可以较早被看出是 AI；
- 唯一 Dominant Turn = 新娘也是人格重建；
- 观众必须通过叙事时间省略自己补出 continuity；
- 私人 AI 是整季真实连续存在的正面对照。

# 02｜本轮提出的首选方案：迁居后的孤岛失联

提出的核心不是：

> **她在 EP03 那条通道上出了事故。**

而是：

> **EP03 成功让有限跨区移动重新成为可信的生活选择；新娘因此真正重新安排没有新郎的人生，迁居 / 调整到另一个局部区域，并在那里生活了一段时间。随后持续群岛化使该区域再次失去稳定共同连接，她的连续人生从共同可验证现实中中断。后来关于她的数据可以回来，但她作为同一个连续主体没有回来。**

这个方向的目的，是让 EP03 成功成为：

> **改变行为预期的真实成功。**

而不是：

> **隐藏错误 / 死亡陷阱。**

---

# 03｜为什么拒绝“直接通道事故”

方案 B 曾概括为：

> **她在跨区接驳过程中直接失踪。**

优点：

- 短剧效率高；
- 一场戏可直接解决连续性中断。

但被认为层次更弱，因为会形成过度直线化因果：

> **EP03 开路 → 路后来事故 → 新娘死。**

这会让 EP03 的成功被观众回看成“其实不该成功”，破坏整季一直坚持的：

> **局部正确 / 真实成功也会创造新的二阶风险。**

因此不采用为当前 Canon。

---

# 04｜为什么不采用“授权 / 七分钟错位导致失踪”

方案 C 曾概括为：

> **新娘在某次授权 / 时间错位中被困。**

该方向不采用为当前 Canon，原因：

- 容易复刻 EP03 的七分钟 / 协议状态错位；
- 容易提前抢 EP06 的“共同现在”；
- 容易抢 EP08 的“公共授权合法性”；
- EP05 应主要承担私人 continuity，而不是再造一宗系统流程案。

---

# 05｜新娘迁居的意义

本轮明确：

> **她不是奔向死亡。她是在重新开始生活。**

迁居 / 调整生活的具体原因仍 TBD，可以来自：

- 工作；
- 住房；
- 家庭；
- 服务条件；
- 想离开旧共同记忆；
- 其他普通生活原因。

但禁止默认：

> **为了找亡夫、找遗物、继续筹备婚礼。**

这条非常重要，因为 EP05 前半真正要表现的是：

> **未来已经被拿走，但人仍然会重新安排今天和明天。**

---

# 06｜最后一个真人状态不是灾难，而是普通生活

本轮建议并锁方向：

> **真人新娘最后一个明确连续状态应是普通生活，而不是遇险特写。**

她已经：

- 搬到新地方；
- 形成新日常；
- 不再只是 EP02 那个不断哭的人；
- 真的开始把人生往前推。

随后该局部再次转入失联 / 本地运行。

第一次看甚至仍像：

> **又一次暂时中断。**

只是这一次共同连接没有恢复到能够重新确认她的连续存在。

---

# 07｜“数据回来了，人没有回来”成为 continuity 核心

本轮最重要的新锁定之一：

> **后来城市可以重新得到关于她的大量真实数据，但不能因此证明她作为同一个连续主体继续存在。**

内部简写：

> **数据恢复 ≠ 连续性恢复。**

允许的数据来源方向：

- 缓存；
- 延迟数据；
- 本地档案；
- 存储 / 设备回收；
- 后续有限读取；
- 其他自然残留。

具体技术实现继续 TBD。

这些数据后来成为婚礼 AI 新娘人格重建的资料来源之一。

必须防止误读：

> **不是她生前上传自己，也不是她预先制作“数字遗体”。**

---

# 08｜EP03 的两条后果分支正式区分

本轮形成一条非常重要的跨集结构：

### EP03 → EP05｜私人生活分支

> **一次连接成功 → 有限跨区流动重新成为可信生活选项 → 普通人重新安排真实人生 → 新依赖 / 新暴露面 → 新娘 continuity break。**

### EP03 → EP08｜公共制度分支

> **一次连接成功 → 路径复用 → 运营习惯 → 管理 / 安全 / 排序 → 两套地方公共秩序重叠 → 正当性冲突。**

因此同一成功的二阶后果被拆成：

> **私人生命史 + 公共制度史。**

不会重复。

---

# 09｜Fairness Rule 不变，而且现在更清楚

真人新娘最后一个可确认状态之后进入叙事空白。

婚礼阶段出现高度一致的“她”。

观众会自动推断：

> **她后来回来了 / 出来了 / 活到今天。**

但剧本不能提供真正证明 A→B 连续主体存在的证据。

禁止：

- 虚假时间戳；
- 反悔式闪回；
- 把早期真人画面后来宣布成 AI；
- 在空白期之后展示只有连续真人肉身才能完成的明确证明。

本集真正让观众犯的错误必须是：

> **看到真实 A + 相似 B，就自动把中间连续时间补出来。**

# 11｜本轮锁定范围

正式锁定：

1. EP03 成功改变人的生活预期，不是直接错误；
2. 新娘因普通生活原因重新安排人生并迁居 / 调整到另一区域；
3. 她在那里真实生活过一段时间；
4. 后续持续群岛化使该区域再次失去稳定共同连接；
5. 她最后明确真人状态是失联前的普通生活，不要求拍遇险；
6. 后来部分真实数据可以重新取得；
7. **数据恢复 ≠ 连续性恢复**；
8. 这些数据成为婚礼 AI 新娘重建资料之一；
9. EP03→EP05 = 私人生活后果；EP03→EP08 = 公共制度后果；
10. 终极 Reveal 和 Wedding Mirror 结构不变。
