# 01｜用户意图

用户要的不是传统剧情预告，而是：

> **EP01–EP10 的视觉 showreel / concept reel。**

目标优先级：

1. 先证明《北京市没有冬天》“看起来是什么”；
2. 视觉必须有独特城市气质，不做普通 AI 科幻大片；
3. 重大剧情答案不得泄露；
4. 婚礼誓词作为声音脊柱；
5. 画面使用完全反义 / counterpoint 原则，但不能机械到“一句词配一个反义镜头”。

---

# 02｜婚礼母空间

用户提供视觉参考后确认：

- 开片就是婚礼现场；
- 婚礼发生在大型公共观景厅 / 巨构公共空间；
- 可见地球与第二新北京轨道巨构；
- 中轴、红毯、公共系统、巨大空间构成主要视觉秩序；
- 婚礼是全支预告的稳定基准，不只是 EP05 单独一个镜头。

因此 V1 使用：

> **婚礼 = 声音母空间 + 构图母空间。**

开头与结尾尽量使用同构图回环。

---

# 03｜誓词

用户认可传统婚礼誓词骨架，并明确要求：

> **不要瞎编哲学誓词，要有真实婚礼原型。**

当前 V1 暂用：

> 我愿意与你结为夫妻。
>
> 从今以后，
>
> 无论顺境还是逆境，
> 无论富有还是贫穷，
> 无论健康还是疾病，
>
> 我都会爱你、珍惜你、陪伴你，
>
> 直到死亡将我们分开。

措辞允许后续人物口吻窄修，不改传统骨架。

明确禁止在誓词里塞：

- 现实；
- 数据；
- continuity；
- 同一个现在；
- 协议；
- 世界分裂等作者主题词。

---

# 04｜反义蒙太奇修正

早期尝试错误：

> 顺境 = 灾难；逆境 = 幸福；健康 = 暴雪；疾病 = 救人……

用户反馈镜头、场景、节奏都不对。

最终修正：

> **反义应存在于整支片的声音—画面关系，而不是逐词做小游戏。**

声音：

> **承诺在一起。**

画面：

> **北京逐渐失去共同空间、共同时间、共同秩序。**

仅保留一个明确字面反义 payoff：

> **“直到死亡——”留在婚礼。**
>
> **“将我们分开。”切 EP01 女科长抓住坠落男主。**

语言 = 分开；动作 = 连接。

该节点由用户明确提出并批准。

# 05｜视觉选段来自 GitHub active Canon

重新通读当前最高读序后，优先筛出：

- 重力异常；
- 男主长时间坠落；

### EP09

EP03 / EP04 / EP10 本支不承担主动作；可作为世界状态或声音来源，但不为十集平均曝光而硬塞。

# 06｜导演 / 镜头纪律

当前批准的高层方法：

> **城市先于人物；系统动作先于人物表情；静态巨构压住时间；程序化秩序制造恐怖；真正的人体动作极少。**

落实为：

- 至少约一半镜头机位基本不动；
- 大事件优先极远 / 远景；
- 少用航拍穿梭、旋转、爆炸、现代 CG 炫光；
- 不用人物震惊表情替城市解释；
- 机器越正确、越标准、越可怕；
- 人体大动作稀缺，保护“坠落 / 抓手”两次动作重量；
- 多拍事件前状态和事件后余波，不把每个结果都演完。

---

# 07｜赛璐璐视觉修正

用户新增明确意见：

> **喜欢赛璐璐画风，希望这一方向更强。**

V1 因此锁为：

> **严肃、冷静、电影感的赛璐璐动画视觉。**

执行特征：

- 手绘线条边界；
- 硬边 / 分块 cel shading；
- 机械背景高细节；
- 人物相对克制；
- 冷灰蓝底；
- 少量红色公共标识 / 红毯；
- 少写实软渐变、少 bloom / lens flare；
- 旧工业公共系统层累积感；
- 不做萌系、偶像 PV、常规现代二次元商业插画。

该方向是高层视觉描述，不要求复制任何现存作品具体镜头或角色设计。

# 08｜EP06 时间镜头用户修正

用户明确否定之前“先切一个钟，再切另一个钟”的做法。

新锁：

> **火车站台两侧同时显示不同时间。**

优先设计：

- 同一轨道站 / 对向站台；
- 同一画面可同时读到两套公共时间；
- 两侧时间不同；
- 两侧还可表现不同季节 / 雪迹 / 衣着 / 光照；
- 列车继续各自正常运行；
- 无人解释。

这使“没有共同现在”从 UI 说明升级为一个公共空间事实。

精确时间数字仍是 shot-design 占位，不写入 Episode Canon。

# 09｜节奏最终方向

不是一直 crescendo。

批准波形：

> **静 → 静 → 巨变 → 普通生活 → 时间/空间异常 → 程序化加速 → 长坠落 → 极静 → 抓手瞬爆 → 极静。**

重要控制：

- 开头婚礼敢慢；
- EP02 巨构分离也慢；
- EP06 双时间站台是观察镜头；
- EP08 才出现短时密集快切；
- 随后突然用 6 秒左右固定大全景看男主下坠；
- “直到死亡”回婚礼；
- “将我们分开”抓手；
- 结尾重新冷下来。

---

# 10｜结尾方向

用户早期不满意“戴戒指 → 新郎消失 → 黑”的剧情短片式结尾。

V1 修正：

> **新郎消失不是高潮，而是高潮以后一个没有得到城市特别尊重的事实。**

推荐：

1. 抓手后回婚礼；
2. 戒指仍是近景视觉主语；
3. 新郎在背景 / 次焦点轻微消失；
4. 不做强 glitch、不做惊呼、不做新娘反应戏；
5. 回开场同构婚礼大厅大全景；
6. 新郎位置空了；
7. 公共轨道 / 公共系统继续正常运行；
8. 黑；片名。

不锁正片中投影与实体戒指交互的具体工程机制。
