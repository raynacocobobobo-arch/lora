# 01｜触发修改

用户反馈 V1 / 早期 Shot List 的问题：

1. 视觉奇观还不够；
2. 目标片长应为 45–60 秒；
3. 信息密度要非常高；
4. 原剪辑节奏太慢；
5. 仍希望强化冷静赛璐璐、环境叙事、公共系统压迫感；
6. 必须让观众明确感到城市处在危机里；
7. 但用户随后明确补充：**慢节奏普通生活铺垫仍然喜欢，因为需要反差。**

因此 V2 不是“把所有慢镜头删掉”，而是：

> **高密度奇观 + 短时普通生活针脚 + 环境危机。**

---

# 02｜V2 节奏修正

目标片长：约 56 秒。

节奏不做全程快切，而是：

> **稳 → 奇观 → 日常 → 异常 → 奇观 → 日常 → 程序化危机 → 人体危机 → 婚礼极静 → 抓手 → 极静。**

普通生活反差被保留，但压缩为 1.5–3 秒的小针脚，不形成长段。

原因：

> **如果没有人继续吃饭、通勤、营业、维修，城市危机就容易退化成纯 CG 世界末日。**

普通生活的存在让观众知道：

> **这是一个仍有人生活的北京，而它正在坏掉。**

---

# 03｜三处普通生活反差

当前 V2 优先保留三处：

1. 婚礼红毯边缘，清洁机器人继续工作；
2. 巨构分离后，住宅 / 小店里的人继续普通生活；
3. 机器人对峙前，用维修工 / 小店 / 自动服务设备做 2 秒静针。

这些镜头不负责剧情解释，只负责制造反差。

---

# 04｜奇观主轴

V2 的奇观优先级：

1. EP06 双时间 / 双季节火车站；
2. EP05 婚礼公共观景厅 + 地球 + 第二新北京；
3. EP08 北京公共安全平台互相瞄准；
4. EP02 跨区巨构慢分离；
5. EP01 男主从巨构城市坠入宇宙 / 深部空间；
6. EP07 A/B 城区能力此消彼长；
7. 暴雪吞没仍在工作的基础设施。

奇观不等于爆炸；优先表现：

> **空间错位 / 时间错位 / 季节错位 / 能力分配 / 程序化对峙 / 人体尺度失控。**

---

# 05｜环境叙事锁

每个大场面至少带一个“城市仍在正常运行”的副动作：

- 维修臂；
- 清雪设施；
- 轨道车；
- 通勤者；
- 公共广播；
- 清洁机器人；
- 标准识别 / 警告流程。

危机感不靠“所有人都在尖叫”，而靠：

> **正常系统继续履职，但共同现实正在丢失。**

---

# 06｜EP06 双时间站台继续强化

用户此前明确要求：

> **时间不同必须在火车站台两侧同时出现。**

V2 继续把它设为第一主 Key Visual：

- 同一轨道站 / 对向站台；
- 同一帧同时看到两个公共时间；
- 一侧积雪 / 冬装；
- 一侧无雪 / 轻装；
- 两侧列车正常到发；
- 人群完全习惯；
- 禁止 split screen / 传送门 / 解释对白。

这不是 UI 说明，而是公共空间现实。

---

# 07｜危机层级

V2 让危机从三个层面递进：

### 空间危机
- 巨构分离；
- 同城双季节；
- 双时间站台。

### 系统危机
- A/B 此消彼长；
- 暴雪中基础设施硬撑；
- 两套公共安全系统互相瞄准。

### 身体危机
- 重力异常；
- 男主坠落；
- 女科长抓手。

这样 teaser 不只是“酷设定”，而是明确让观众感到：

> **这座城市的共同空间、共同时间、共同秩序都在变得不可维持。**

---

# 08｜结尾与反义节点

继续保留：

> **“直到死亡——” = 婚礼戒指。**
>
> **“将我们分开。” = 女科长抓住坠落男主。**

抓手是全片唯一真正的人类动作高潮。

其后迅速回婚礼：

- 戒指继续；
- 新郎轻微异常 / 消失；
- 不做大 glitch；
- 不做反应戏；
- 回开场同构大全景；
- 公共系统继续运行；
- 黑 / 片名。

---

# 09｜视觉风格

继续使用 V1 已批准的方向：

> **严肃、冷静、电影感的赛璐璐动画视觉。**

强调：

- 手绘线条；
- 硬边阴影；
- 冷灰蓝；
- 机械背景高细节；
- 人物简洁；
- 少 bloom / lens flare；
- 旧工业公共设施层累积；
- 静态巨构与短促动作并置。

不复制任何现存作品具体镜头或角色设计。
