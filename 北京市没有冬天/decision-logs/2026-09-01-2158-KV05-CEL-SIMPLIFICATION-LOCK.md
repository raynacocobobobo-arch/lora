# 02｜KV05 场景选择

结合 Teaser V2 与 EP07 active Canon，KV05 选择：

> **A / B 双区域 + 中央共享 Hub 的大型公共基础设施内部空间。**

场景目标：

- 中央 Hub 是明显共同设施；
- 左右 A/B 两侧真实依赖它；
- 一侧高等级运行、另一侧降级；
- 不依赖台词即可读懂“共享能力无法同时完整覆盖两边”；
- 仍然是同一座轨道太空城内部，不是两座独立城市；
- 人和车辆只作为尺度 / 运转痕迹。

---

# 03｜KV05 第一版问题

第一版生成后，用户指出：

> **有点不塞露露，过度复杂了。**

问题被确认不是世界逻辑，而是视觉密度 / 渲染语言：

- 微小机械细节过多；
- 小灯、小窗口、屏幕、标牌同时抢信息；
- 管线过密；
- 金属反射和微高光偏写实；
- 整体接近高密度 3D / hard-SF concept art；
- A/B/Hub 的大关系反而不够干净。

---

# 04｜用户批准的修正设计

修正方案：

- 机械细节减少约 40–50%；
- 改成更大的钢板、梁柱、粗管线和平台块面；
- 强化 2–3 档硬边阴影；
- 减少小灯、小窗口、小文字和密集屏幕；
- 中央 Hub 轮廓保持巨大但简洁；
- A / B 能力差优先通过整体明暗和运行状态表达；
- 人和车辆进一步减少，只留尺度参照；
- 保持冷灰蓝、旧白、少量暗红；
- 背景层级压缩，避免无限复杂巨城。

用户确认：

> **确认。**

# 06｜KV05 新增视觉规则

1. 大场景优先大轮廓，不优先微小机械细节；
2. 大场景优先硬边赛璐璐块面，不优先写实金属反射；
3. 一个画面优先一个核心空间关系 / 核心状态；
4. 市政设备、导视、材质家族保持一致，但不要求每个元素都高细节；
5. 状态差异应先靠结构、照明、活动量表达，再由文字确认；
6. 大空间仍保持轨道城内部有限人工体积；
7. 当前 KV 阶段只优先制作大场景设定图。
