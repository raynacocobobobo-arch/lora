5. route through `SCENE-PROMPT-TEMPLATE-V3.md`;

9. choose composition family intentionally;
10. apply **OSHII ANIMATION STYLE V1**;
11. apply scene-specific light/time state;
12. perform Seedance structural compression;
13. generate one production reference image;
14. run thumbnail / relabel / story-action / Seedance-motion QC.
