# 04｜Removed-setting no-gap rule

`LOCKED / USER EXPLICIT`

当移除旧设定时：

> **不能只删文本。必须确认它原来承担的剧情、工程、人物或视觉功能由新机制完整接替。**

当前关键替换：

- 多层无限巨构感 → **有限环形船坞 + 不同年代城区模块 + 多尺度桥网**；
- 深层穿越到外壳 → **302本身位于主环外缘，一面朝城、一面临空**；
- generic safe-point support tear → **小型外缘附属维护/接口段在T0旧伤+异常载荷下意外断接**；
- 嘉陵江无限峡谷 → **环形城市内部有限、百米级开放公共城市带**；
- lifeline physical growth → **始终小型Level-4，但社会/制度意义持续增大**；
- EP10小桥容量漏洞 → **大规模迁移在EP09后已分批进行；正片小桥只是最后active connection**；
- 城市战略收缩 → **退出城区模块/连接，不切永久主环骨架**；
- winter/snow old mechanism → **Local Public Time差异与最终common now**；
- 一次性重力奇观 → **Local Gravity Frames + EP01 Extreme / later Level1–3**；
- 抽象群岛化 → **桥连接密度/能力持续下降**；
- 抽象 legacy branch → **302 + bridge/service/time/gravity/protocol compatibility stack**。

删除旧功能但没有 successor function = migration failure。

# 05｜Organic integration rule

`LOCKED / USER EXPLICIT`

执行优先级：

1. 人物当前需求 / 公共动作；
2. 已形成跨集因果债；
3. 实际城市空间；
4. 时间 / 重力是否真的改变动作；
5. 最后才是视觉母题。

空间额外规则：

> **一个主区域 + 一个明确连接 / 接口 + 必要时一个子空间。**

禁止把每集写成：

> 新巨构场景 + 桥展示 + 时间异常 + 重力异常 + 嘉陵江奇观 + 主题对白。

默认：

> **复用地点，改变状态。**
