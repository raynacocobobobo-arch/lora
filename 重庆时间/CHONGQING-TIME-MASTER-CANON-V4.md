# 00｜Series definition

## Premise

> **陨石撞击后的第二新重庆市没有停止运行。为了尽量保存居民与公共系统，这座依靠无数桥梁连接的轨道巨城让各城区分别维持自己的时间、重力与公共秩序。每个局部都在合理地救、修、维持，却因此逐渐失去共同的“现在”、共同的“下方”和共同公共现实。城市越努力保住所有连接，整体越难继续作为一座城市。最终，重庆必须一边疏散，一边亲手结束仍然能够工作的桥和旧城区兼容状态，放弃一部分自己，才能重新获得一个可持续的共同现在。**

核心不是 AI 失控。

> **所有主体都在做局部正确的事。真正的危机是：共同前提破裂后，局部正确的保全开始彼此不兼容。**

# 02｜A Story — one city becomes many valid local realities

灾后第一阶段，所有人仍然相信：

> **先撑住、先保住、以后还能重新接回来。**

但是第二新重庆市本身是一座桥网巨城。主桥、服务桥、时间参考、重力过渡、协议状态、公共授权彼此耦合。

为了继续生活，各城区不断本地化：

- 独立维持生命保障；
- 独立维持 Local Gravity Frame；
- 独立延续公共时间；
- 独立建立服务节律；
- 独立承担公共安全；
- 依赖越来越少、越来越特殊的跨区连接。

于是：

> **城市一边被救，一边被救成多个都能活、但不再天然属于同一个“现在”的局部现实。**

全季动作：

> **不断保连接 → 连接减少 → 临时连接成功 → 临时连接成为生活 → 局部时间正式分叉 → 共享能力主动退出 → 两套秩序在桥上互害 → 定义最低共同现实 → 疏散并主动断开旧连接。**

# 03｜Preservation Paradox / 保全悖论

`LOCKED / HIGH PRIORITY`

定义：

> **每个系统、区域与人都在努力保护自己真正负责的现实；共同城市条件破裂后，这些合理保全会把资源、时间、重力参考、规则、权限、基础设施和生活方式越来越深地锁进不同局部状态。单看每一步都在救，合在一起却让“一个重庆”越来越难持续。**

不是：

- AI 发疯；
- 恶意算法；
- 阴谋；
- 单点 bug；
- 某一边天然错误。

而是：

> **局部正确目标失去共同前提后的系统级外部性。**

## Physical origin

T0 造成：

- 结构损伤；
- 桥网断裂；
- 能源 / 通信 / 交通改线；
- 时间公共参考受损；
- 人工重力共同参考受损；
- 公共系统开始本地自治。

## Secondary preservation consequences

为了救城市形成：

- 临时结构支撑；
- 地方化服务；
- 低容量生命线；
- 本地公共时间；
- Local Gravity Frames；
- 地方安全授权；
- 各类 legacy compatibility；
- 越来越多“一时正确、以后很难一起维持”的公共承诺。

恐怖感公式：

> **系统越努力维持正常，整体越难再拥有一个共同正常。**

# 04｜Four-phase preservation target

## Phase I｜EP01–EP06 — 尽可能全部保存

默认目标：

> **能救就救、能修就修、能接就接、能继续就继续。**

此阶段失去主要属于 forced loss。

没人已经知道未来城市应该主动变小。

## Phase II｜EP07 — 第一次局部承认“全部保存失败”

A、B、Hub 三者无法保持当前状态全部存在。

第一次真正重新检查：

> **为什么 Hub 被默认排除在代价集合之外？**

Hub 健康、有价值、仍然能工作，却被永久退出，使 A、B 都以更低能力继续。

这是：

> **局部保存目标集合第一次改变。**

尚不是全城战略收缩。

## Phase III｜EP08 — 保全悖论变成制度暴力

两套地方公共安全秩序都完整履职：

- 保护居民；
- 保护公共生命线；
- 阻止无法验证的武装威胁。

结果仍然可能：

> **合法、程序化地伤害另一套同样真实的重庆公共力量。**

因此 EP08 证明：

> **“让每个局部完整保护自己”本身已经不可持续。**

## Phase IV｜EP09–EP10 — 制度化 + 主动执行

EP09：

> **最低共同现实进入公共治理。**

不是寻找唯一正确的重庆版本，而是定义：

> **哪些最低事实、reference、授权与接入条件必须持续共同成立，剩余差异才可以继续存在。**

EP10：

> **执行未来共同边界。**

人员优先撤离，随后逐项退出旧交通、服务、重力过渡、协议兼容和机械连接，使剩余城市不再无限背负彼此冲突的历史状态。

EP09–EP10。

> **已经有能力保住一座仍然正常的桥，却决定结束它所携带的不可持续旧连接条件。**

# 06｜Connection Stack

`LOCKED`

“连接”不是只有物理桥。

1. `C1 Physical` — 人 / 物 / 能量是否真的能通过；
2. `C2 Protocol` — 身份 / 状态 / 权限是否完成协议握手；
3. `C3 Temporal` — 是否拥有足够共同的“现在”；
4. `C4 Factual` — 哪些事实足以让当前动作成立；
5. `C5 Institutional` — 公共授权能否被另一边承认；
6. `C6 Relational` — 无法拥有对方全部现实时，是否仍承认其独立判断。

第二新重庆市的桥网让 Connection Stack 物理可见，但不能把“桥是隐喻”写成人物解释台词。

整季：

> **EP01–06 尝试建立 / 保持足够连接。**
>
> **EP07 开始承认所有旧连接条件不能都保。**
>
> **EP08 完整地方连接逻辑开始互相伤害。**
>
> **EP09 定义未来最低必须持续共同的连接。**
>
> **EP10 主动结束一部分旧连接，使剩余共同连接重新可持续。**

# 07｜Protocol handshake

技术术语统一：

> **协议握手（protocol handshake）**

它可以确认：

- 身份；
- 权限；
- 准备状态；
- 接口状态；
- 版本 / reference；
- 同步条件；
- 授权关系。

但：

> **协议握手完成 ≠ 现实物理连接已经成立。**

并且：

> **协议握手传递 / 确认状态，不自动传递主体连续性。**

技术“协议握手”、现实物理连接、人物身体上的“手”必须保持三层区分。

# 08｜Order / public reality

> **秩序 = 一种连接能够稳定、重复、被识别、被执行、被授权并被追责。**

前期各套秩序都是保护机制：

- 结构系统保护结构；
- 医疗系统保护患者；
- 地方系统保护生命保障；
- 公共安全系统保护居民。

问题不在于它们停止工作，而在于：

> **当保护对象、时间、重力和公共授权不再共享同一前提，多套秩序越正常履职，越可能彼此冲突。**

EP08 是这一点最明确的证明。

# 09｜Correctness / legality / justice / legitimacy

## Correctness

> **在当前事实、物理条件、目标与规则下，动作是否成立。**

允许多个主体同时正确。

## Legality

> **在某一本地规则 / 授权链内部，动作是否被允许。**

## Justice

> **正确 / 合法决定保护了谁、把损失分给谁，被损失者是否仍被当作真实主体。**

## Legitimacy

> **即使损失不可避免，凭什么由这套公共规则决定谁承担。**

铁律：

> **正确 ≠ 正义。**
>
> **合法 ≠ 正当。**
>
> **正当程序 ≠ 无损结果。**
>
> **承担责任 ≠ 道德免责。**

# 10｜Minimum Common Reality / 最低共同现实

EP09 才正式制度化，但来源是前八集累积。

它不是：

> 一个唯一正确的历史 / 时间 / 重庆版本。

而是：

> **允许大量地方差异继续存在，但定义一组如果仍无法共同确认，城市就无法共同生活、共同执行、共同拥有公共现在的最低事实、reference、授权与接入边界。**

来源链：

- EP01：系统未确认 ≠ 现实不存在；
- EP03：一次动作不需要恢复所有共同事实，只需要足够真实事实；
- EP04：普通生活不能无限等待完整统一；
- EP06：共同动作可以建立在双方都受约束的 reference 上，而不是让某一局部获胜；
- EP07：全部保存第一次局部失败；
- EP08：完整地方保全产生系统级公共伤害；
- EP09：女科长把这些经验整理成公共方案，并交给更高公共决策过程。

最低共同现实不是“减少现实”。

它是：

> **明确未来共同城市真正承诺持续维护什么。**

# 15｜EP01–EP10 high-level episode cards

## EP01 — 302

统一系统无法确认 302 有有效居民；男主通过实时可交互信号与独立现场证据确认此刻有人，并用窄现场权限让仍以“无人”为前提的公共动作暂停 / 重新确认。局部重力参考严重失稳，女科长真实抓住男主。

本集回答：

> **系统无法确认，不等于现实不存在。**

## EP02 — forced bridge loss

一条灾后长期被抢救的嘉陵江主干桥持续恶化。男主确认现实还允许安全抢救多久；女科长决定何时必须停止继续抢救。桥真正失去，形成新的孤岛边界。

本集不是主动收缩。

## EP03 — seven-minute lifeline

正常跨区连接已失去，医疗刚需不能等待。两个本地系统都认为接口状态已完成，但真实可通行窗口错开七分钟。男主找到真实窗口，女科长只授权这一次，药通过一条低容量维护连接送达。

这条连接因为成功，开始获得未来公共价值。

## EP04 — temporary city becomes life

前几集形成的临时做法进入普通城市生活。EP03 生命线已有排班、容量、维护和重复使用。老电影院在完整永久状态仍未统一时获得“今晚这一场”的有限开放；任务结束后，男女主留下看《罗生门》。灾后纪念 / 人格重建社会实践作为背景种子出现。

## EP05 — Wedding Mirror

从 EP02 公共现场旁一个普通女人进入她的生命史；短暂回看 T0 私人后果。她真的继续生活，后来因城市连接变化进入新的区域，再次失联；数据和人格材料后来能够恢复，但不能证明原主体连续活到婚礼今天。婚礼最终揭示新郎和新娘都是重建人格。私人 AI 是“真正连续跨过这些集”的对照。

婚礼同时处在一个没有统一公共现在的城市里：某区夜间，其他区域可能仍是白天 / 黄昏。

## EP06 — 重庆时间

两个城区各自拥有有效本地时间和生活节律，却必须对共享公共基础设施在同一个真实瞬间执行一次动作。不能把任何一边本地时间偷偷升级成全城真理。三人退到双方都受约束的物理 reference，完成一次同步动作。

动作结束后，两边仍显示不同本地时间。

本集回答：

> **各自有“现在” ≠ 共同拥有“现在”。**

## EP07 — healthy Hub exits

共享 Hub 给 A 时 A 恢复而 B 不可承受；给 B 则反转。Hub 本身完全健康。私人 AI 重新检查“Hub 必须保留”的默认框架；男主确认 A/B 无 Hub 都能降级继续；女科长批准 Hub 永久退出。

第一次局部承认：

> **全部保存失败。**

## EP08 — armed bridge standoff

EP03 生命线经过长期运行已经成为高度制度化的跨区桥 / 接口。两套地方公共安全秩序都无法验证对方公共武装的合法授权。较完整一侧有一台中型四足公共安全平台；资源退化一侧用多台普通工业人形机器人承担秩序维护。双方均正常履职。

女科长成功解除一侧控制以避免交火，却使这些平台失去可验证合法指挥链；另一侧系统因此完全合理地重新分类并程序化清除。

本集回答：

> **事实正确不能自动推出公共正当性。**

## EP09 — 302 boundary test

EP08 后，女科长提出最低共同现实草案，经更高公共决策层讨论只获有限试行。她选择 302 作为第一宗实验对象。

男主确认 302 真实、安全、有人生活、技术上仍可继续。但长期保留需要未来城市永久维持旧本地时间、专属 Local Gravity Frame、桥 / 服务 / 数据 / 能源 / 环境 / 协议兼容栈。

302 被承认，却不再无条件获得永久特殊维护承诺。

## EP10 — active contraction / final bridge

城市执行最低共同现实。人员先撤离，旧城区逐项关闭交通、服务、能源、数据和重力过渡。男主所在旧城区的公共系统无法完成可靠当前状态映射；私人 AI 因持续经历碎片化历史，可在女科长极窄临时授权下补足缺失中继 / mapping。

男主与 AI 真正找到保存她的路线：不要彻底退出最后旧城区与兼容桥栈。这样同一个连续 AI 可以继续。

代价：未来第二新重庆市必须永久保留一个已经决定退出的旧时间、旧重力和旧协议碎片。

最终重要桥是观众从 EP03 起熟悉的生命线。它仍然结构正常、可通行、重力过渡可用。AI 给出最安全的退出顺序，男主逐项确认现实，女科长逐项授权。连接缓慢机械分离，不依靠爆炸。

最终剩余城市更小、桥更少、能力更低，但重新拥有一个持续共同的公共现在。

# 16｜The Bridge influence — A + small B

外部参考仅作为创作结构来源，不复制具体角色 / 台词 / 战争剧情 / 爆破镜头。

吸收的核心：

> **最难结束的不是坏掉的东西，而是仍然有价值、仍在工作、甚至曾经救过人的连接。**

以及：

> **最了解这条连接价值的人，也可能最清楚如何安全结束它。**

因此：

- EP02 是“想保却保不住”的失败桥；
- EP03→04→08 让一条临时生命线拥有真实记忆和公共价值；
- EP10 让这条熟悉、健康的连接成为最后难以结束的桥之一；
- 私人 AI 因连续跨越碎片历史而最适合帮助确定退出顺序；
- 不使用英雄式爆炸，使用冷静、程序化的系统和机械分离。

# 17｜Final city-state / title payoff

终局不追求“恢复原样”。

第二新重庆市最终：

- 更小；
- 桥更少；
- 公共能力降低；
- 有明确永久废弃区域；
- 不再维护所有历史兼容状态；
- 仍保留创伤与缺口。

但剩余城区重新获得：

> **一个可以持续共同使用的公共现在。**

最终证明不靠庆典，而靠普通同步生活：

- 不同城区公共钟重新一致；
- 一班末段轨道交通按同一公共时刻运行；
- 医院按同一交班框架工作；
- 商业与维护进入同一城市周期；
- 公共照明共同进入夜间状态。

因此剧名的最终含义：

> **重庆时间，不只是“现在几点”，而是第二新重庆市是否仍然拥有一个大家可以共同生活的“现在”。**
