# 03｜Current series lock that remains valid

## Title / city

> **《重庆时间》**
>
> **第二新重庆市**

## Premise

> 陨石撞击后的第二新重庆市没有停止运行。为了继续保护居民和公共系统，各城区逐渐分别维持自己的本地时间、Local Gravity Frame 和地方公共秩序。每个局部都在合理救城，却因此越来越难共享同一个“现在”、同一个物理参考和同一个公共现实。最终，城市必须先疏散，再主动结束一部分仍然能够工作的桥和旧城区兼容条件，让一个更小但可持续的重庆重新拥有共同现在。

## Active core city architecture

> **第二新重庆是一座长期扩建形成的环形船坞型太空城市。主城呈近似环形 / 甜甜圈总体形态，内部有效城市高度约 200 m、主环半径约 1 km。不同年代、不同规模的舱室与城区模块沿主环生长，通过桥接入共同城市。**

The city should be read as a finite, comprehensible whole, not an infinite vertical megacity.

First-season spatial families are limited to:

- A｜Main Ring Living City；
- B｜Shared Civic / Utility Belt；
- C｜Legacy Module Belt / 302；
- D｜Bridge Connection Family；
- E｜Outer Maintenance Edge.

`嘉陵江` active spatial reading:

> **主环内部最宽、桥最密、共享设施最集中的连续开放结构带 / 船坞式城市空腔。**

It remains the recurring public geography for bridge-network memory, but no longer requires an effectively infinite vertical canyon.

Spatial hard rule:

> **城市可以视觉多层，但角色行动不默认穿越多层城市。跨区域必须通过明确桥、轨道、接口或维护连接。**

## Time

> **不再使用冬季 / 雪作为 active series mechanism。**

EP01 first concrete time crack:

> **302 trusted local time is revealed as `+08:00` relative to the public reference used for the task.**

# 05｜Story causality hard rule

> **人物需求 / 公共行动 first；设定只在改变动作或后果时进入。**

Before screenplay, every episode must pass:

> `Trigger -> Goal -> Obstacle -> Choice -> Turn -> Cost -> State Delta`

and the short-drama shape:

> `Cold Open -> Pressure -> Turn -> Payoff/Progress -> End Image`.

Mandatory questions:

- why now?
- why this character?
- what happens if no action?
- why not the obvious cheaper/easier alternative?
- does the character choice actually change outcome?
- if bridge/time/gravity jargon is removed, is there still a coherent story?
- is there exactly one dominant turn?
- if a clever third path appears, what real cost remains?
- can the audience explain where the character is and how they reached the next space?

EP01 additional architecture lock:

> **task record is a dramatic measuring stick, not a lore dump. It first establishes how the ordinary task is supposed to end, then the episode proves that reality no longer allows the normal procedure to end normally.**

EP01 story-film grammar lock:

> **the outline must preserve a But / Therefore causal chain rather than an “and then” event list; the `早安 → 祝你早安……晚安` motif should return with changed meaning rather than decorative repetition.**
