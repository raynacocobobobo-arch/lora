# 07｜Old-function deletion rule

If future work finds a V3.2 detail not explicitly copied into V4, do not automatically revive it.

Use this decision test:

1. Is it contradicted by V4? → legacy only.
2. Did it serve a function now carried by bridge/time/gravity/Jialing architecture? → use the V4 successor.
3. Is it a non-conflicting character or micro-execution detail not yet covered by V4? → it may be consulted as provenance, but must not override active V4 facts.
4. Is it winter/snow/Beijing active identity? → do not restore as current series mechanism.
