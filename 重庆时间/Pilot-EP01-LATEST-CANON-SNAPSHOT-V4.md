# 01｜Episode function

EP01 是整季第一条现实裂缝：

> **统一系统无法确认 302 有有效居民；男主通过匿名实时交互信号与独立现场物理证据确认“里面此刻有人”，并用有限现场权限迫使一个仍基于“无人”前提运行的公共动作暂停 / 重新进入确认链。**

本集回答：

> **系统无法确认，不等于现实不存在。**

本集不回答：

> **真实存在是否必须被永久保存。**

后者留给 EP09。

# 02｜Timeline / city baseline

`LOCKED`

陨石撞击发生在正片之前。

EP01 开始时，第二新重庆市已经经历：

- 首轮气密隔离；
- 自动结构支撑；
- 能源 / 通信改线；
- 本地生命保障；
- 大量桥梁临时限载 / 改道；
- 局部 Local Gravity Frame 稳定；
- 持续人工维修。

城市仍在运行。

EP01 不是灾难发生集，而是：

> **灾后系统模型与物理现实之间第一宗观众明确看懂的冲突。**

观众从开场即可知道这里是轨道巨城第二新重庆市，不把“在太空”当成悬念。

# 03｜302 location integration

302 位于较老的一片城区，靠近嘉陵江结构体系与旧服务层。

这不是为了强行展示地标，而是为后续工程事实提供自然空间条件：

- 旧城区有多层历史结构；
- 部分数据 / 接入关系在灾后改线中失真；
- 旧服务桥和重力过渡设施仍在工作但不再完全共享统一 reference；
- 男主的现场复核因此具有真实必要性。

EP01 不需要解释整个桥网。

观众只应感觉：

> **302 是庞大立体城市里一个很具体的小节点。**

# 04｜302 evidence chain

统一公共系统当前无法确认：

> **302 内存在有效居民 / 有效公共主体。**

男主到达后获得第一层证据：

> **来自 302 内部的匿名、实时、可交互信号。**

必须满足：

- 不是旧录音；
- 不是预存信息；
- 能对男主当前询问 / 动作产生实时反应；
- 证明里面此刻存在行动主体具有强可能性。

私人 AI 合理指出：

> **单一实时信号不足以证明完整现场状态，也不能证明结构安全。**

她是对的。

男主继续获得第二层独立当前事实，功能可来自：

- 实时生命保障负载变化；
- 当前人工操作痕迹；
- 热 / 空气 / 机械状态；
- 对男主刚刚动作产生的现场物理响应；
- 其他无法用旧缓存解释的实时事实。

精确载体 `EXECUTION_TBD`。

最终只确认一件事：

> **302 里面此刻真的有人。**

# 05｜Not “AI wrong / human right”

私人 AI 在前期仍拥有非常强的广域访问能力。

她掌握：

- 更广结构风险；
- 路径；
- 自动公共系统状态；
- 大量实时城市数据。

她反对男主深入必须合理。

冲突不是：

> 人类直觉打败 AI。

而是：

> **AI 的总体风险判断合理，但男主获得了系统决策空间中尚未纳入的当前物理事实。**

两者可以同时正确。

---

# 06｜Male authority

男主没有权力定义 302 的长期未来。

他只拥有足够窄的现场权限去：

- 冻结 / 延迟仍以“无人”为前提的自动动作；
- 标记系统前提与现场事实冲突；
- 要求重新确认；
- 将新事实送回公共责任链。

他的权限种子是：

> **暂停错误前提。**

不是：

> **定义城市未来边界。**

---

# 07｜Gravity event — no longer a one-off gimmick

302 附近的重力异常正式归入 V4 Local Gravity Frame 世界机制。

功能原因：

> **旧城区本地人工重力参考仍在维持，但邻近服务层 / 桥梁重力交接 reference 经长期灾后改线与损伤出现严重不稳定。**

精确工程故障模式继续 `EXECUTION_TBD`，但不再是与后续世界无关的神秘一次性现象。

本集使用整季罕见的 `Extreme` 级异常：

- 男主失去稳定落脚；
- 认知中的“下方”突然不再可靠；
- 身体真正进入坠落危险。

女科长：

> **真实地抓住他。**

这个动作必须是物理行为，不由机器人、远程系统或抽象安全机制替代。

# 08｜Jialing / city-scale reveal

救援之后，镜头可以第一次把局部身体风险扩展到城市尺度：

- 嘉陵江式封闭巨型结构空腔；
- 不同高度的桥与服务层；
- 明确人工包覆边界；
- 远端结构开口外的遥远地球。

这不是：

> “原来在太空。”

而是：

> **第一次身体化理解：这座城市没有一个天然共同地面，人的正常生活一直依赖复杂人工连接。**

地球保持远、克制、从属。

# 09｜Time seed

时间断层在 EP01 只作为轻量 background seed。

允许：

- 接口 timestamp 轻微不一致；
- 旧服务层时钟与公共系统显示存在小偏差；
- 班次 / 维护记录发生微小错位。

禁止在 EP01 解释“重庆没有共同现在”。

EP03 才第一次把时间裂纹变成主动作可见的七分钟差；EP06 才正式成为片名级问题。

# 10｜Character delta

## Male

获得危险而强烈的外部价值证明：

> **如果我没有到现场，这个具体人可能继续被公共决策当成不存在。**

这强化他的 False Belief：

> **不可替代的现场判断才证明我真正有价值。**

## Private AI

第一次让观众明确看到：

> **访问范围更广 ≠ 拥有全部现实。**

但她没有被证明“不可靠”。

## Female chief

通过实际身体行动进入核心关系：

> **她不会只在程序外面管理风险，也会在现场承担现实。**
