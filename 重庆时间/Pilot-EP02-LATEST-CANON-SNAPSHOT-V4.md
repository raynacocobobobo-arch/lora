# 01｜Episode function

EP02 不是一次新的灾难，而是：

> **一条灾后一直被人、AI 和公共系统支撑、抢救并继续使用的嘉陵江城市主干桥，终于来到“再继续维持会把更大结构拖入风险”的临界点。**

男主负责确认：

> **现实还允许安全抢救多久。**

女科长负责承担：

> **什么时候必须停止继续抢救。**

桥最终真正失去，第二新重庆市被动新增一个孤岛边界。

本集是：

> **Forced Loss / 被迫失去。**

不是主动战略收缩。

---

# 02｜Opening state

撞击后所有系统仍然在“救、撑、修、保”。

主桥已经经历：

- 临时结构支撑；
- 多轮限载；
- 服务改道；
- 撤离；
- 物流优先级重排；
- 局部重力过渡修正；
- 人工维护；
- 不断更新的安全窗口。

它不是今天刚刚坏。

它之所以重要，是因为：

> **大家已经为保住它付出很久，而且它仍然在承担真实生活。**

---

# 03｜Location: one important bridge among many

主现场锁为：

> **嘉陵江结构体系中的城市级主干桥 / trunk connector。**

它横跨巨型封闭人工结构空腔。

桥下：

- 维护层；
- 服务平台；
- 管廊；
- 结构墙体；
- 设备层；
- 明确人工包覆边界。

空间巨大但有限。

本桥不是整座城市唯一的桥。

必须让观众隐约理解：

> **它是庞大桥网里一条关键主干，因此它失去后城市仍能活，但拓扑会真实改变。**

---

# 04｜What the bridge still carries

在逼近极限时，它仍可以承担部分：

- 尚未完成的人员撤离；
- 必要物流；
- 医疗 / 公共服务；
- 普通跨区生活关系；
- 某些能源 / 数据 / 环境服务；
- 重力参考交接的一部分。

具体组合 `EXECUTION_TBD`，但必须使冲突真实：

> **每多撑一点时间，都可能多保住具体人和具体生活；每多撑一点，也可能把损伤继续传给更大城市结构。**

---

# 05｜Gravity is a structural contributor, not the answer

V4 补上长期重力机制，但不能把 EP02 写成“因为重力坏了所以桥坏了”。

两个相邻城区的 Local Gravity Frames 在灾后都努力维持本地稳定。

结果可能导致：

- 两端设计载荷方向不再完全一致；
- 桥梁过渡系统持续补偿；
- 临时支撑承担非设计应力；
- 长期反复调整留下疲劳 / 不对称负载；
- 已有撞击结构伤害更难稳定。

所以重力异常是：

> **让一个已经受损、长期被抢救的桥更难继续维持的现实变量之一。**

不是唯一原因，也不是方便的科幻解释。

# 06｜Time status

EP02 的公共时间仍大体足以支持应急协同。

可以有：

- 局部班次错位；
- 不同维护窗口；
- 临时 reference 更新频率差异。

但时间不是本集主冲突。

真正明确的“七分钟”进入 EP03；“没有共同现在”到 EP06 才成为主问题。

# 07｜Two correct preservation goals

## A｜继续撑

保护：

- 尚未撤完的人；
- 必要物资；
- 医疗；
- 生活关系；
- 桥上仍依赖的公共服务；
- 尽可能多的城市可达性。

## B｜停止继续撑

保护：

- 更大结构；
- 相邻城区；
- 其他桥与服务层；
- 防止损伤继续传播；
- 防止一个正在失败的主干把更多真实主体一起拖进风险。

两边都是真实保全。

本集 conflict grammar：

> **两个合理保全目标开始互相挤压。**

不是：

> “冷酷地牺牲少数来救多数。”

---

# 08｜Male / chief role split

## Male

确认当前现实：

- 受力；
- 临时支撑与实际结构差异；
- 重力过渡带来的额外变量；
- 损伤传播迹象；
- 撤离 / 通行窗口；
- 超过哪一状态以后继续抢救会扩大损失。

他不能决定公共边界。

## Female chief

她根据现场事实、撤离状态与公共责任承担一个时间点：

> **继续多救一点，还是到这里必须停止。**

她不是提前实践“未来城市应该更小”。

---

# 09｜Dominant turn

> **男主确认安全抢救窗口已经逼近极限；女科长最终承担停止继续抢救的公共决定。桥随后进入受控的结构退出 / 分离，重要连接真实失去。**

核心情绪：

> **我们已经尽量保了，还是没能全部保回来。**

桥两侧仍然亮着。

本地系统立刻开始：

- 改道；
- 重新分配生命保障；
- 更新交通；
- 建立新的临时服务边界。

所有人仍然相信：

> **这只是暂时的，以后还能接回来。**

---

# 10｜Mechanical separation language

如果桥具有开合 / 分离结构，动作必须：

- 慢；
- 程序化；
- 机械；
- 可控；
- 与撤离 / 交通同时存在。

不能默认使用：

- 爆炸；
- 火球；
- 战争式毁桥；
- 英雄式按钮。

EP02 的痛来自：

> **大家仍然想保它，但现实已经不再允许继续。**

这必须与 EP10 的“桥完全正常但仍主动退出”形成明确反差。

# 11｜Character delta

## Male

EP01：

> **我的判断改变现实。**

EP02：

> **我的判断也会成为别人承担公共后果的依据。**

他第一次明确体验专业事实的重量并不止于“救到人”。

## Female chief

第一次真正承担：

> **所有人都在努力救，但仍然必须由某个人确认什么时候停止继续救。**

## Private AI

仍然属于前半季“尽可能保存更多”的主体。

她可以根据广域风险支持较早止损，但目标仍是：

> **保住更多第二新重庆。**

不能提前成为主动舍弃倡导者。

# 12｜Causal handoffs

## EP02 → EP03

主桥失去以后，跨区刚需没有消失。

因此 EP03 不是“为了主题重新搭桥”，而是一个具体问题自然出现：

> **完整连接还没修回来，但一个不能等的医疗需求必须过去。**

这迫使角色使用低容量维护连接。

## EP02 → EP05

本集公共现场附近，一个后来成为 EP05 POV 主体的普通女人与男女主擦肩而过。

她当时已经知道未婚夫在 T0 失去。

第一遍不突出，不要求观众记住。

EP05 从同一时点接走她的私人生命史。

## EP02 → EP08

主桥 loss 产生新的实际孤岛。

EP03 的低容量生命线成功并被重复使用，最终自然生长出：

> **运营 → 排序 → 安全责任 → 双方公共秩序在同一接口重叠。**

EP08 不是突然出现的政治边境。
