## 核心世界锁

- 第二新重庆市是一座由多层人工城区和大量桥梁 / 轨道 / 服务管廊连接起来的轨道巨城；
- 城市宏观尺度不是连续地面；
- `嘉陵江` 是贯穿城市的重要超巨型封闭结构空腔，不是真实河流；
- 城市灾后逐渐失去共同的时间参考、重力参考和公共现实；
- 时间异常采用城区之间的白天 / 黄昏 / 夜晚 / 公共作息断层，不再使用冬季 / 雪作为系列机制；
- 重力采用 `Local Gravity Frames`，并在桥梁 / 接口过渡区域形成贯穿全季的物理问题；
- 时间断层与重力异常是独立故障轴；
- EP10 终局是先疏散、再验证、逐层退出服务 / 重力 / 协议兼容并机械断桥，最终废弃一部分旧城区；
- 最后重要桥来自 EP03→EP04→EP08 的熟悉生命线，且工程上仍然健康；
- 设定必须从人物正在完成的公共行动里有机生长，禁止为了展示设定而机械插入桥 / 时间 / 重力奇观。
