# 01｜V3 的最高目标

V3 不是把 V2 的“北京 / 冬季 / 雪”替换成几个重庆地名。

它必须让观众在不到一分钟里自然读到《重庆时间》的四个核心层：

> **桥 = 空间连接**
>
> **时间 = 共同现在**
>
> **重力 = 共同物理参考**
>
> **人物关系 = 连续性是否还能被保住**

但执行原则仍然是：

> **先让每个镜头成立，再让设定从镜头中的行动和环境自己长出来。**

禁止做成：桥展示镜头 + 时间展示镜头 + 重力展示镜头的设定合集。

V3 继承 V2 已经成立的高层语言：

- 45–60 秒高密度，但不是全程快切；
- 严肃手绘赛璐璐；
- 巨构 / 公共系统优先于人物表情；
- 危机主要来自仍在正常运行的系统；
- 人体大动作稀缺；
- 普通生活与城市裂变并置；
- 婚礼誓词继续作为声音骨架，不改成解释主题的科幻台词。

节奏：

> **极静私人承诺 → 城市空间展开 → 被迫失去连接 → 日常继续 → 时间裂开 → 有限连接成功 → 公共能力收缩 → 秩序对峙 → 身体坠落 → 抓住 → 连接开始主动退出 → 极静私人连续性疑问。**

# 04｜V3 视觉优先级

## 第一优先：嘉陵江桥网 Establishing

必须一眼成立：

- 巨大封闭人工峡谷；
- 多层、多尺度桥；
- 上下左右都是城市结构；
- 城市不是建立在连续地面上；
- 远方地球只是稳定外部参照，不是主角。

这是《重庆时间》区别于普通空间站 / 赛博城市的首要空间资产。

## 第二优先：第二新重庆车站时间断层

保留已批准 KV01 的内容基础：

- 同一站厅；
- 左黄昏、右夜间；
- 旧白客运列车；
- 公共系统仍运行；
- 低文字密度；
- 无雪。

## 第三优先：EP08 嘉陵江桥上武装对峙

必须读到资源差异和真实公共接口：

> **一台更专业的中型四足平台 vs 多台普通工业人形机器人。**

不是“双方各摆一支军队”。

## 第四优先：EP02 / EP10 两种断桥的对照

V3 内部视觉逻辑必须清楚区分：

- EP02：桥已被损伤逼到不能继续保，大家想保而保不住；
- EP10 hint：桥仍正常，城市主动结束连接。

## 第五优先：重力身体动作

只让 EP01 的坠落成为最大人体奇观。

其他重力异常靠：

- 悬挂物偏斜；
- 液面倾斜；
- 扶栏；
- 步态修正；
- 货物固定；

建立持续存在感。

# 05｜赛璐璐执行硬规则

采用 `VISUAL-CONSISTENCY-BIBLE-V2.md` 的简化巨构语言：

- 2.35:1 为当前 KV / scene 默认；
- 大钢板、大梁柱、大桥面、少量粗管线优先；
- 机械微细节较高密度 3D hard-SF 方案减少约 40–50%；
- 2–3 档硬边阴影；
- 清晰线稿层级；
- 冷灰蓝 / 深钢蓝 / 旧白为基础；
- 少量暗红只承担公共警示 / 仪式点色；
- 低镜面、低 bloom；
- 禁止高频 greeble、密集小灯、密集窗口、屏幕海、文字海；
- 人和机器人优先作为尺度与公共行动证据，不抢巨构。

危机公式继续成立：

> **异常城市状态 × 正常公共运行 = 不安。**

但 V3 的“正常运行”具体化为：

- 列车仍到站；
- 商店仍营业；
- 桥仍排班；
- 清洁机器人仍清扫；
- 重力转换失败时人已经学会扶栏；
- 安全机器人严格按程序维护秩序；
- 桥在断开之前甚至仍显示可运行。
