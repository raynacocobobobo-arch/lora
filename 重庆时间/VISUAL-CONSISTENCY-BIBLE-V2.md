# 01｜Authority split

> **Canon decides WHAT exists, WHERE, WHEN and WHAT happens.**
>
> **Visual Bible + approved anchors decide HOW those facts are visualized.**

视觉统一必须同时通过两个测试：

> **像同一部片。**
>
> **像这场戏。**

禁止为了统一风格把所有场景重新画成同一个中轴大厅。

---

# 02｜Highest production rule

大场景统一采用：

> **简化赛璐璐巨构语言。**

核心：

> **少一点设计炫技，多一点空间逻辑；少一点写实复杂度，多一点赛璐璐结构感。**

优先：

- 巨大清晰的建筑块面；
- 大钢板；
- 大梁柱；
- 桥面 / 平台；
- 少量粗管线；
- 大设备剪影；
- 清晰负空间；
- 2–3 档硬边阴影；
- 大块明暗；
- 克制材质高光；
- 少量真正有意义的导视；
- 少量车辆 / 人 / 机器人作为尺度和公共行为。

如果画面开始像：

> **premium 3D hard-SF concept art**

则优先：

> **减少 30–50% 微细节，而不是继续添加设计。**

---

# 03｜Second New Chongqing visual identity

可见城市命名：

> **第二新重庆市**
>
> **SECOND NEW CHONGQING**

英文只在真正需要双语公共导视时出现。

城市视觉不是 generic sci-fi city。

基本 DNA：

- 中国式公共基础设施尺度与秩序；
- 长期使用、维护、修补后的轨道巨城；
- industrial brutalism + municipal retro-futurism；
- 不崭新的大型市政系统；
- 成熟城市而非新建太空基地；
- 技术很先进，但很多外露设备具有“修过、补过、继续工作”的历史感。

---

# 04｜Macro city rule: bridge network, not continuous ground

第二新重庆市城市级画面不得默认使用：

> **连续大地板 + 一排建筑。**

局部城区内部可以有正常地面。

但当镜头表达“城市整体 / 跨区关系 / 嘉陵江 / 群岛化”时，必须体现：

- 多层人工城区；
- 不同高度的平台；
- 主桥 / 区域桥 / 服务桥 / 维护桥；
- 结构空腔；
- 上下左右均可能存在城市功能；
- 桥是公共生活普通组成，而不是每次出现都像特殊奇观。

一帧优先读懂：

> **哪两个 / 哪几块城市结构正在通过什么连接发生关系。**

再读设备细节。

---

# 05｜嘉陵江 Visual Canon

嘉陵江不是水体。

视觉定义：

> **贯穿第二新重庆市的超巨型封闭人工结构峡谷 / 城市结构空腔。**

必须同时成立：

- monumental；
- enclosed；
- engineered；
- inhabited / maintained；
- finite。

## Mandatory spatial cues

至少出现若干：

- 近 / 中 / 远层桥梁；
- 巨型舱壁；
- 结构梁；
- 服务层；
- 内部楼板；
- 维护平台；
- 粗管组；
- 设备区；
- 明确远端结构边界。

禁止把“巨大”画成：

> 无限城市深渊 / 开放宇宙船坞 / 没有边界的世界。

## Earth aperture

部分嘉陵江视角远端可以通过：

> **大型结构观察口 / 外层维护开口**

看到遥远地球。

地球：

- 小；
- 远；
- 不抢主体；
- 作为稳定外部 reference 和空间尺度。

不能使用巨大蓝色地球占据半个画面来制造“科幻感”。

# 06｜Jialing degradation states

## Early / connected

- 多层桥可用；
- 公共交通 / 维护 / 物流正常；
- 人流不需要密集，但城市 connection density 明显高；
- 结构灯光连续。

## Mid / fragmented

- 一部分桥关闭；
- 某些桥低容量；
- 部分服务层变暗；
- local day/night 差异明显；
- 临时生命线开始承担过多功能。

## Late / institutionalized fragmentation

- retained connections 少；
- 地方公共系统 / 机器人在接口出现；
- 一侧资源退化可见；
- 桥上同时承担交通 + 维护 + 管理 + 安保。

## EP10 / contraction

- 疏散 / 改线持续；
- 桥一组组退出；
- 连接密度明显下降；
- 嘉陵江画面越来越空；
- 废弃城区逐渐退出公共灯和交通；
- 仍然健康的最后重要桥可以处于受控机械分离。

关键：

> **空间没有扩大，是城市连接减少了。**

# 07｜Material family

主材质：

- 厚重喷涂钢板；
- 深蓝灰结构钢；
- 旧白市政设备；
- 暗色橡胶 / 复合材料；
- 焊缝；
- 铆接 / 螺栓；
- 补丁板；
- 更换过的结构件；
- 局部磨损；
- 工程编号与少量警示色。

状态：

> **maintained / used / repaired / still working**

不是：

- 废土锈蚀；
- 全新洁白未来主义；
- 豪华 spaceship interior；
- 镜面金属展厅。

---

# 08｜Palette

主色：

- 冷灰蓝；
- 深钢蓝；
- charcoal；
- 旧白；
- 暖色工作灯；
- 少量暗红 / muted red 作为警示、仪式或公共焦点。

红色必须克制。

例如婚礼红毯可以成为该场唯一强色焦点。

不要用霓虹紫 / 青 / 粉建立 generic cyberpunk 氛围。

---

# 09｜Signage

导视家族：

- 硬质蓝 / 深蓝金属或珐琅板；
- 白字；
- 简洁箭头；
- 大区 / 线路 / 接口编号；
- 少量英文。

导视功能：

> **确认空间和公共状态，而不是解释剧情。**

如果删掉文字以后画面就完全看不懂动作，说明空间设计失败。

禁止：

- 每个设备都贴一串字；
- 用大段屏幕说明世界观；
- 在 EP08 直接写“医疗转运通道”；
- 用“跨时序接口”之类自我解释性词汇；
- 为了可读性把正常公共接口写成概念展板。

---

# 10｜Local Public Time visual grammar

不同 local now 主要通过人工城市行为表现。

允许：

- 一区明亮日间公共照明；
- 一区黄昏过渡光；
- 一区夜间低照度；
- 商铺开闭差；
- 轨道班次 / 站台活动差；
- 清洁 / 维护班次；
- 医院交班；
- 公共钟。

重要：

> **默认不需要天空。**

特别是封闭接口 / 桥 / 嘉陵江内部画面，必须让观众知道这是同一巨大人工城市内部的不同公共时间状态。

## State contrast rule

A/B 差异优先通过：

1. light level；
2. public activity；
3. transit frequency；
4. open / closed service zones；
5. workers / robots；
6. clocks / signage 最后确认。

不要只靠文字写 `DAY / NIGHT`。

---

# 11｜Gravity visual grammar

重力异常必须视觉可读但克制。

## Level 1

- 液面倾斜；
- 悬挂物偏向；
- 松散物件慢滑；
- 轻微不同垂线。

## Level 2

- 行人扶栏；
- 工业机器人改变步态；
- 担架 / 货箱固定；
- 桥过渡处姿态改变。

## Level 3

- 大型运输受限；
- 临时固定装置；
- 桥通行窗口明显受约束。

## High / extreme

只用于少量真正的戏剧动作，如 EP01 身体坠落。

禁止把每个场景做成：

- Escher maze；
- 360° 人在墙上走；
- 持续失重 spectacle；
- 纯视觉奇观而不改变动作。

重力最好的使用方式通常是：

> **一个非常普通的人或机器已经学会如何适应。**

---

# 12｜Time / gravity visual independence

不要把：

> 夜晚 = 重力异常

或：

> 白天 = 重力正常

做成视觉编码。

两者独立。

EP06 可明确展示：

> 两边公共时间完全不同，但桥的重力过渡大体稳定。

EP03 / EP08 则可在桥上表现重力差，而时间承担不同层级压力。

---

# 13｜Municipal equipment family

公共设备统一像同一座城市采购 / 维护体系：

- 旧白外壳；
- 深色底盘 / 关节；
- 蓝色小面积状态标识；
- 暗红安全标识；
- 结构简单、厚重；
- 长期维修留下替换板和编号。

优先：

> **功能轮廓先于表面 greeble。**

机器人也遵循：

- 不做高端玩具机甲；
- 不为“酷”添加过多武器和装甲；
- 公共安全设备是市政系统，不是军队。

---

# 14｜EP08 security visual lock

EP08 主场景：

> **嘉陵江上方的悬空跨区公共桥 / 接口。**

不是地面大厅。

资源较完整一侧：

> **一台中型四足公共安全机器人 / 平台。**

退化孤岛一侧：

> **多台普通工业人形机器人，被本地系统协调承担秩序维护。**

视觉要求：

- 四足平台明显更大、更专业；
- 普通人形机器人数量更多但单体更弱；
- 退化一侧结构、照明、设备维护程度更差；
- 两边都仍是同一城市文明家族；
- 有武装 / 强制能力压力，但不是 battlefield；
- 桥仍然承担实际公共通行。

锁定：

> **无轮式安保车辆。**

# 15｜Composition

默认 2.35:1。

优先：

- 稳定；
- 建筑性；
- 第一眼可读；
- 结构关系明确；
- 大尺度空间通过人 / 机器人 / 车辆 / 栏杆等参照建立。

中轴只在场景本身支持时使用。

不能因为某些 KV 成功，就把所有场景复制为中央大厅正对称构图。

## Readability hierarchy

1. major spatial relationship；
2. one dominant dramatic / functional state；
3. large circulation / equipment；
4. signage / status；
5. small people / robots / maintenance；
6. micro-detail。

一帧原则：

> **一个主要空间关系 + 一个主要场景状态。**

---

# 16｜Rendering style

目标：

> **严肃电影感手绘赛璐璐动画背景。**

必须：

- 清晰线稿边界；
- 结构化机械轮廓；
- 2–3 档硬阴影；
- 大阴影块；
- 受控渐变；
- 克制 bloom；
- 材质反射简化。

禁止：

> **3D render with anime filter。**

如果微细节、镜面反射、体积雾和灯点开始承担主要“高级感”，说明方向跑偏。

---

# 17｜Environmental storytelling

每个大奇观镜头最好保留 1–3 个正在继续的普通公共行为，例如：

- 清洁机器人继续工作；
- 维修人员更换结构件；
- 轨道车进站；
- 医疗箱通过；
- 店铺营业 / 关门；
- 小型服务机器人运行；
- 公共导视更新；
- 工人交班。

这些行为证明：

> **城市不是概念模型，它还在生活。**

但不要为了“生活感”把画面塞满 NPC。

---

# 18｜Crisis grammar

《重庆时间》的危机不以爆炸为默认语言。

优先表现：

- 连接逐步失效；
- 服务仍正常但彼此不兼容；
- 灯仍亮着；
- 桥仍可用但被限制；
- 机器人仍按规则工作；
- 系统程序化分离；
- 公共行为继续。

EP10 尤其要避免英雄式炸桥动作。

正确：

> **交通 / 数据 / 环境 / 重力 / 协议逐项退出，机械锁缓慢释放。**

---

# 19｜Global negative direction

Do not use as positive style drivers:

- generic cyberpunk；
- sleek spacecraft；
- NASA clean-room aesthetic；
- luxury sci-fi lobby；
- endless space dock；
- infinite abyss；
- premium hard-SF greeble density；
- every-surface micro-panels；
- dense tiny lights；
- countless thin pipes；
- mirror metal；
- screens explaining everything；
- neon city；
- photoreal metallic reflection noise；
- giant Earth as spectacle；
- generic battlefield / military base；
- same central-axis hall copied across scenes。

# 20｜Large-setting QC

每张大场景生成后必须检查：

```yaml
major_shape_reads_before_micro_detail: pass/fail
one_dominant_spatial_relationship: pass/fail
one_dominant_scene_state: pass/fail
scene_geometry_matches_actual_function: pass/fail
bridge_network_logic_if_macro_city_view: pass/fail/not_applicable
finite_engineered_volume: pass/fail
jialing_is_enclosed_if_present: pass/fail/not_applicable
local_public_time_reads_through_behavior: pass/fail/not_applicable
gravity_visualization_matches_severity: pass/fail/not_applicable
time_gravity_not_accidentally_coupled: pass/fail
micro_detail_not_competing: pass/fail
hard_cel_shadow_masses_clear: pass/fail
photoreal_metal_reflection_suppressed: pass/fail
signage_confirms_instead_of_explains: pass/fail
ongoing_public_behavior_present: pass/fail
same_city_not_same_room: pass/fail
```

只有“画得像”不够。

> **画面必须把本场真正发生的动作和城市物理逻辑都读对。**
