# 01｜Second New Chongqing: modular ring-shipyard city

第二新重庆不是连续地面城市，也不是无限向上下叠加的巨构迷宫。

> **它是一座建立在永久环形船坞骨架上的模块化太空城市。**

总体近似不规则甜甜圈 / 环形船坞。

设计尺度方向：

- 主环半径约 `1 km`；
- 主要城市内部最大有效净空约 `200 m`。

环形只定义城市拓扑，不定义人工重力来源。

城市有三个物理尺度：

1. `Permanent Ring Backbone` — 长期承力、扩建和接驳骨架；
2. `District Modules` — 居民实际生活的城区舱段；
3. `Attached Service / Maintenance Modules` — 维修、EVA、重力服务、接口等小型附属结构。

一个城区舱段内部仍然可以拥有普通意义上的：

- 街道；
- 住宅；
- 医院；
- 学校；
- 商业空间；
- 车站；
- 公共大厅；
- 工业区；
- 广场和局部“地面”。

居民首先感到自己生活在一座城市里，而不是生活在设备舱里。

第二新重庆经过长期建设、扩建、换代和维修，所以不同年代、不同规模的舱段会通过大量桥、轨道、服务连接和接口结构接入共同城市。

城市最终变小时：

> **退出的是附属城区、旧接口和它们的共同连接条件，不是把永久主环骨架切断。**

# 02｜Spatial orientation / ordinary gravity readability

第二新重庆不要求存在一个工程意义上绝对统一的城市水平面，但视觉和日常生活必须保持可读。

> **绝大多数可居住城区的 nominal down 在视觉上大体一致。**

普通居民不会默认面对“隔壁城区旋转90度”的日常城市。

Local Gravity Frame 的差异主要在以下位置变得身体可见：

- 桥 / Gravity Handoff；
- 旧接口；
- 损伤服务区；
- 特定异常窗口。

允许局部：

- 高低错层；
- 小角度方向差；
- 重力强度差；
- 接口处明显过渡；
- 极少数事故中的方向性失稳。

但以下旧理解不再 active：

> 每个城区默认拥有大角度不同“下方”；角色需要理解整座城市为多方向翻转巨构。

空间复杂度必须服务动作，而不能要求观众学习工程剖面才能理解人物移动。

# 03｜Bridge hierarchy — physical scale and narrative value are separate

桥不是一种单一造型，也不是所有连接都一样大。

## Level 1｜城市主干桥 / Trunk Bridge

大型城市级复合连接，可同时承担：

- 重型轨道；
- 大规模人员通行；
- 物流；
- 能源；
- 数据通信；
- 环境循环；
- Gravity Handoff；
- public/reference connection。

EP02 的嘉陵江主干桥属于这一层级。

## Level 2｜区域交通桥 / Regional Bridge

承担中等规模：

- 通勤；
- 区域物流；
- 公共服务；
- 部分医疗/工业交通。

第一季不要求某一条 Level-2 桥成为主要角色资产。

## Level 3｜服务 / 管廊桥 / Utility Bridge

承担：

- 电力；
- 水与循环介质；
- 数据；
- 生命保障；
- 环境控制；
- 重力控制联络；
- 其他市政服务。

## Level 4｜维护桥 / Maintenance Bridge

承担：

- 技术人员；
- 维修机器人；
- 检测；
- 小型运输架；
- 局部检修；
- 少量应急人员 / 物资。

**EP03→EP04→EP08→EP10 的 Familiar Lifeline 物理上始终保持 Level 4。**

它后来有排班、公共价值、安保冲突和终局意义，但不因为叙事重要就变成一座大桥。

> **生命线物理尺度很小，叙事尺度很大。**

关键规则：

> **桥不仅运人，也运城市状态。**

一条桥 / 接口可以组合承载交通、结构、能源、数据、环境、公共时间 reference、Gravity Handoff 和协议状态。

因此“断桥”可以意味着某一组共同连接条件退出，而不一定是爆炸或结构坍塌。

# 04｜嘉陵江 / Jialing

`嘉陵江` 是第二新重庆最重要的固定城市地理之一。

它不是真实河流，也不等于环形结构中央的大孔洞。

> **嘉陵江是环形城市内部一条连续、有限、百米级的开放公共城市带。**

它沿城市弯曲延伸，两侧为可生活城区，中间/附近集中出现：

- 城市主干桥；
- 区域桥；
- 服务桥；
- 小型维护桥；
- 轨道；
- 公共交通接口；
- Gravity Handoff；
- 热管理 / 环境设施；
- Shared Hub 等跨区基础设施。

居民自然使用：

- 过江；
- 江桥；
- 江这边 / 江对面；
- 上游 / 下游；
- 临江区。

这些词已经从地球水文意义转化为第二新重庆的城市生活语言。

## Space rule

嘉陵江必须大，但必须始终可读为：

> **有限、有结构边界、桥梁尺度清楚的城市开放空间。**

不能默认成为无限深渊，也不能依靠“上面下面无穷叠城”制造尺度。

一眼最好能同时看到：

- 一座较大的公共连接；
- 一两条较小服务/维护连接；
- 两侧城区体量；
- 一处共享基础设施或结构边界。

## Central shipyard void

环形城市中心可以存在更大的船坞/结构空域，但它只是总体构型的一部分。

> **不把中央空域命名为嘉陵江。**

## Exterior reference

部分临江/外缘结构允许通过观察口或维护开口看到遥远地球/太空。

外部世界只承担：

- 稳定参照；
- 空间尺度；
- 城市与外部世界的距离感。

不能压过重庆本身成为主视觉奇观。

# 05｜Jialing season-state progression

嘉陵江是一处跨集重复出现的城市记忆，但不是每集必拍同一宽景。

## Early

- 桥连接密度高；
- 公共交通和维护动作丰富；
- 各城区仍被感知为一座完整城市；
- 时间/重力差异主要被技术和流程吸收。

## EP02

一条 Level-1 主干桥在长期抢救后退出。

这一失去不会让全城所有路线瞬间消失，但会：

- 让正常绕行变长；
- 让小型本地连接获得新的现实价值；
- 在嘉陵江留下可持续观察的拓扑缺口。

## Middle

- 部分桥关闭、限载或降级；
- 不同区域进入不同 Local Public Time 状态；
- 某些 Gravity Handoff 只在有限窗口工作；
- EP03 那条小型 Familiar Lifeline 被重复使用并获得生活价值。

## Late

- 桥连接明显减少；
- 地方系统承担更多独立责任；
- 同一条小维护桥可以同时成为交通、维护、公共安全和制度接触面；
- EP07 后共享高阶公共能力减少。

## EP10

- 大规模迁移在 EP09 后已经开始；
- 其他临时/绕行连接逐步退出；
- Familiar Lifeline 到正片时只是**最后仍 active 的旧兼容连接**；
- 它承担最后人员/服务/cutover，而不是在一集里吞吐整个302人口；
- 最后仍有价值、仍健康的连接也可以被主动结束。

# 06｜Local Public Time / 本地公共时间

灾后，第二新重庆失去持续可靠的统一公共时间参考。

各城区为了让居民继续生活，没有停止全部公共系统等待统一参考恢复，而是维持自己的本地运行连续性。

因此不同城区可能同时处于不同的：

- 白天公共模式；
- 黄昏模式；
- 夜间模式；
- 深夜维护周期；
- 清晨交班周期。

这不是多个太阳，也不依赖外部天空。

大量空间是人工封闭城市环境，所以本地“昼夜”主要体现在：

- 城市照明；
- 公共时钟；
- 交通班次；
- 商业开闭；
- 医院交班；
- 工业维护窗口；
- 能源负载；
- 人工天顶光；
- 居民行为节律。

核心定义：

> **一个城区拥有有效本地时间，不等于第二新重庆仍拥有共同“现在”。**

# 07｜Time-fragmentation dramatic rule

时间差异必须改变实际动作，否则只做背景。

例如：

A 区把某共享桥视为公共通行时段；B 区同时把它视为低容量维护窗口。两边内部都合理，问题发生在它们必须对同一个现实对象执行共同动作时。

时间断层可以影响：

- 交通优先级；
- 维护权限；
- 环境负载；
- 安保班次；
- 医疗交接；
- 共享设施切换；
- 协议握手中的 reference。

但不得把所有冲突简化成“校准时钟即可”。EP08 的公共暴力合法性是明确反例：时间可以加剧冲突，但不能生成公共正当性。

# 08｜Local Gravity Frames

灾后人工重力不是随机全城失控。

各城区优先稳定自己的：

> **Local Gravity Frame / 本地重力参考。**

因此城区内部大多数时候仍然可以正常生活。

真正容易出现身体可感差异的位置是连接结构：

> A Gravity Frame → bridge/interface Gravity Handoff → B Gravity Frame

灾后：

> A 在本地正确；B 在本地也正确；共同过渡 reference 不再天然可靠。

所以接口可能出现：

- 小角度方向差；
- 重力强度差；
- 过渡算法无法确认同一 reference；
- 临时限制窗口；
- 结构长期承受非设计载荷。

默认普通城区不使用大角度彼此翻转的视觉奇观。

# 09｜Gravity anomaly severity ladder

## Level 1｜生活可见

- 悬挂物轻微偏斜；
- 液面显出角度；
- 松散小物件缓慢滑向非预期方向；
- 居民已经形成习惯性应对。

## Level 2｜动作受限

- 行人使用扶手；
- 工业机器人调整步态；
- 担架、运输架、货物需要固定；
- 过桥流程需要考虑 Gravity Handoff。

## Level 3｜公共能力受限

- 大件物流不能任意通过；
- 桥只能在窄窗口运行；
- 医疗/运输动作需要额外确认；
- 结构长期承受非设计载荷。

## Level 4｜短时失重 / 明显减重

只用于较高危事件，不作为日常默认。

## Extreme｜方向性失稳 / 反转级危险

EP01 可以使用。

高强度异常之后不应每集重复。整季更多利用 Level 1–3，使重力成为身体规则而不是重复奇观。

# 10｜Time and gravity are independent axes

`LOCKED`

时间分裂不导致重力分裂，重力分裂也不自动导致时间分裂。

两者都来自共同城市 reference 受损后，各城区为了继续生活形成的本地稳定机制。

因此允许：

- 两区时间不同但 Gravity Handoff 相对兼容；
- 两区时间相近但重力接口严重失配；
- 某连接结构受损，而时间/重力都暂时兼容；
- 某接口物理完好，却因公共授权或本地时间无法完成共同动作。

EP06 是最明确例子：时间问题处于前景，重力故意保持低权重。

# 11｜Islanding / 群岛化

群岛化不是行政地图突然分裂。

它在物理层体现为：

> **一个城区逐渐失去连接密度与连接能力。**

例如原有连接逐渐变成：

- 结构关闭；
- 单向运行；
- 只传数据；
- 只允许维护；
- 只能在特定重力窗口使用；
- 只能绕行；
- 只剩一条低容量小维护连接。

一个城区可以仍然：

- 有人生活；
- 本地重力稳定；
- 本地公共时间有效；

却越来越少地属于同一个共同城市运行状态。

观众应通过桥网与路线变化理解群岛化，而不是靠角色反复解释。

# 12｜Bridge as physical + civic interface

一座桥 / 接口可以同时拥有六层连接：

1. `C1 Physical` — 人 / 物 / 能量是否真的通过；
2. `C2 Protocol` — 身份 / 状态 / 权限是否能完成协议握手；
3. `C3 Temporal` — 两边是否拥有足以完成共同动作的共同现在；
4. `C4 Factual` — 哪些事实足以让当前动作成立；
5. `C5 Institutional` — 对方是否承认本地公共授权；
6. `C6 Relational` — 主体无法拥有完整对方现实时，是否仍承认其独立判断。

桥把 Connection Stack 物理化，但不能让人物说“桥就是关系/时间的隐喻”。

# 13｜Organic integration / blocking rule

世界设定永远不能压过当前剧情动作。

优先级：

> **人物需要 / 公共任务 → 前集因果债 → 实际城市空间 → 时间/重力是否改变动作 → 最后才是视觉母题。**

空间调度规则：

> **一个主区域 + 一个明确连接 / 接口 + 必要时一个子空间。**

因此：

- EP01：同一302城区从公共面进入外缘服务/附属接口，不穿越多层城市；
- EP02：大型主桥 forced loss；
- EP03：附近独立的小型 Level-4 maintenance bridge；
- EP04：同一小桥进入日常；
- EP05：普通城区生活，不增加工程大场景；
- EP06/07：同一嘉陵江共享基础设施家族；
- EP08：同一小生命线，主要发生在桥头维护平台；
- EP09：302作为完整生活城区被重新观看；
- EP10：迁移已长期进行，小生命线成为最后 active connection 再退出。

规则：

> **复用地点，改变状态。**

# 14｜302 / EP01 spatial chain

302 是：

> **挂在主环外缘的一组旧城区舱段，一面朝城，一面临空。**

EP01 动线：

> normal city → 302 → Gravity Service / legacy relay → small attached outer maintenance/interface segment → space。

EP01 最终物理事实：

> **Plan B 已真实开始成功后，男主所在的小型外缘附属段因 T0 潜在旧伤 + 异常方向载荷失去有效结构连接并意外断接。**

不是：

- 整个302脱离；
- 系统主动弹射有人舱室；
- 男主穿过许多城区/壳层；
- 真空把他“吸出去”。

302本体保留，才能继续承担 EP04 / EP09 / EP10。

# 15｜Final city-state

EP10 之后，第二新重庆不会恢复灾前规模。

它会：

- 更小；
- 桥更少；
- 公共能力更低；
- 保留明确伤痕；
- 一部分旧城区永久退出共同运行；
- 不再承诺维护所有历史兼容状态；
- 永久主环骨架仍维持 retained city。

剩余城市重新获得：

> **一个可持续的公共“现在”。**

通过普通同步生活证明：

- 交通使用同一公共时间框架；
- 医院进入共同交班框架；
- 商业与维护进入共同城市周期；
- 跨区协议重新依赖持续共同时间 reference。

第二新重庆没有恢复原样。

它通过结束一部分真实、仍有价值的旧连接，重新成为一座能够共同生活的城市。
