# 01｜Second New Chongqing: a bridge-network orbital megacity

第二新重庆市不是建立在一整块连续城市地面上的巨城。

城市由大量巨型人工城区、结构层和公共设施模块组成。每一个城区内部依然可以拥有普通意义上的：

- 街道；
- 住宅；
- 医院；
- 学校；
- 商业空间；
- 车站；
- 公共大厅；
- 工业区；
- 广场和局部“地面”。

但从城市尺度看，各城区之间被巨大的人工结构空腔、维护层、热管理层、重力设备层、压力边界和服务结构分开。

因此城市尺度真正的道路系统不是一张连续平面路网，而是：

> **多层桥梁、轨道桥、服务管廊、接口结构和维护栈桥组成的连接网络。**

重庆的城市空间经验被转译为轨道巨城的工程逻辑：

> **山城的上下层关系 → 多层人工城区。**
>
> **跨江的城市关系 → 跨巨大人工空腔的桥网。**

这不是复刻地球重庆建筑，而是继承“立体、跨越、上下皆城、桥是日常”的空间 DNA。

# 02｜No universal horizontal plane

第二新重庆市没有城市级统一水平面。

一个城区从自身 Local Gravity Frame 看完全正常，但在更大的巨构参照中，它的结构面可能相对另一个城区呈现：

- 高低错层；
- 斜向关系；
- 侧向关系；
- 不同“下方”方向。

灾前，人工重力与桥梁过渡系统把这种复杂性隐藏得足够好，普通居民只需要把自己所在城区理解成正常生活空间。

灾后，共同参考网络受损，各城区为了继续生活开始优先维持本地稳定。这使原本被技术消隐的空间差异逐渐成为可感知的现实。

# 03｜Bridge hierarchy

桥并非一种单一造型，而是四级公共基础设施家族。

## Level 1｜城市主干桥 / Trunk Bridge

承担城市级复合连接，可同时包含：

- 重型轨道；
- 大规模人员通行；
- 物流；
- 能源；
- 数据通信；
- 环境循环；
- 重力参考交接。

EP02 的主要失去属于这一层级。

## Level 2｜区域交通桥 / Regional Bridge

承担：

- 通勤；
- 小规模物流；
- 医疗转运；
- 公共服务；
- 工业机器人；
- 区域安全与维护。

EP03 形成并在后续不断制度化的生命线最终进入这一功能层级。

## Level 3｜服务 / 管廊桥 / Utility Bridge

承担：

- 电力；
- 水与循环介质；
- 数据；
- 生命保障；
- 环境控制；
- 重力控制联络；
- 其他市政服务。

## Level 4｜维护栈桥 / Maintenance Bridge

承担：

- 技术人员；
- 维修机器人；
- 检测；
- 局部检修和紧急工程动作。

关键规则：

> **桥不仅运人，也运城市状态。**

一条桥可以在同一结构中同时承载交通、能源、数据、环境、公共时间同步、重力交接和协议状态。因此“断桥”不是简单封路，而可能是一整块城区从共同城市状态中退出的过程。

# 04｜嘉陵江 / Jialing River

`嘉陵江` 是第二新重庆市最重要的固定城市地理之一。

它不是真实河流。

它是贯穿大片城区的：

> **超巨型封闭人工结构峡谷 / 城市纵向结构空腔。**

其内部包含：

- 多个高度的城市桥；
- 轨道桥；
- 服务桥；
- 维护平台；
- 重力控制基础设施；
- 热管理与环境设备；
- 城市结构层；
- 公共交通和市政维护空间。

居民长期把它叫作“嘉陵江”，官方公共语言也逐渐接受这一称呼。

因此居民自然使用：

- 过江；
- 江北 / 江南；
- 上游 / 下游；
- 过江线；
- 江桥；
- 临江区域。

这些词已经从地球水文意义转化为第二新重庆市的城市生活语言。

## Space rule

嘉陵江必须巨大，但必须始终可读为：

> **有限、封闭、工程化的人工体积。**

画面中应能找到结构边界、舱壁、楼板、服务层、桥梁支撑或远端包覆，不允许默认成为无限城市深渊。

## Earth aperture

嘉陵江远端允许存在巨型结构观察口 / 外层维护开口，使人在部分角度看到遥远地球。

地球只承担：

- 稳定外部参照；
- 空间尺度；
- 城市与外部世界的距离感。

它不能压过嘉陵江本身成为主视觉奇观。

# 05｜Jialing River season-state progression

嘉陵江是一处可以跨集重复出现的城市记忆，但不是每集必拍地标。

## Early

- 桥的连接密度高；
- 公共交通和维护动作丰富；
- 各城区仍被感知为一座完整城市；
- 重力与时间差异主要被技术和流程吸收。

## Middle

- 一部分桥关闭或降级；
- 不同区域进入不同公共时间状态；
- 某些重力交接变成有限窗口；
- 临时生命线获得越来越重要的公共价值。

## Late

- 桥连接明显减少；
- 被隔离区域公共能力退化；
- 地方系统承担更多独立责任；
- 同一桥上可能同时出现交通、维护、安全和行政边界功能。

## EP10

- 疏散先于最终退出；
- 服务桥、轨道桥、主桥按城市切换顺序逐项退出；
- 连接密度下降使嘉陵江显得更空，而不是更无限；
- 最后仍保留价值的桥也可能被主动结束；
- 被废弃城区最终不再属于共同城市桥网。

# 06｜Local Public Time / 本地公共时间

灾后，第二新重庆市失去持续可靠的统一公共时间参考。

各城区为了让居民继续生活，没有停止全部公共系统等待统一参考恢复，而是维持自己的本地运行连续性。

因此不同城区可能同时处于不同的：

- 白天公共模式；
- 黄昏模式；
- 夜间模式；
- 深夜维护周期；
- 清晨交班周期。

这不是多个太阳，也不依赖外部天空。

第二新重庆市大量空间本来就是封闭人工环境，所以本地“昼夜”主要体现在：

- 城市照明；
- 公共时钟；
- 交通班次；
- 商业开闭；
- 医院交班；
- 工业维护窗口；
- 能源负载；
- 人工天顶光；
- 居民行为节律。

核心定义：

> **一个城区拥有有效本地时间，不等于第二新重庆市仍拥有共同“现在”。**

# 07｜Time-fragmentation dramatic rule

时间差异必须改变实际动作，否则只做背景。

例如：

A 区把某座共享桥视为早高峰主交通结构；B 区同时把它视为夜间维护窗口。两边内部都合理，问题发生在它们需要对同一实体执行共同动作时。

时间断层可以影响：

- 交通优先级；
- 维护权限；
- 环境负载；
- 安保班次；
- 医疗交接；
- 共享设施切换；
- 协议握手中的 reference。

但不得把所有冲突都简化成“校准时钟即可”。EP08 的公共暴力合法性就是明确反例：时间可以加剧冲突，但不能生成公共正当性。

# 08｜Local Gravity Frames

灾后人工重力不是随机全城失控。

各城区为了维持居民生活，会优先稳定自己的：

> **Local Gravity Frame / 本地重力参考。**

因此城区内部大多数时候仍然可以正常生活。

真正危险的地方往往是连接结构，尤其是桥。

灾前：

> A Gravity Frame → bridge gravity transition → B Gravity Frame

灾后：

> A 在本地正确；B 在本地也正确；桥的共同过渡参考不再天然可靠。

所以不同城区之间可能出现：

- 重力方向差；
- 重力强度差；
- 过渡算法无法确认同一参考；
- 临时限制窗口；
- 结构受力分布长期改变。

# 09｜Gravity anomaly severity ladder

## Level 1｜生活可见

- 悬挂物轻微偏斜；
- 液面显出角度；
- 松散小物件缓慢滑向非预期方向；
- 居民已经形成习惯性应对。

## Level 2｜动作受限

- 行人使用扶手；
- 工业机器人调整步态；
- 担架、推车、货物需要固定；
- 过桥流程需要考虑重力交接。

## Level 3｜公共能力受限

- 大件物流不能任意通过；
- 桥只能在窄窗口运行；
- 医疗/运输动作需要额外确认；
- 结构长期承受非设计载荷。

## Level 4｜短时失重 / 明显减重

只用于较高危事件，不作为日常默认。

## Extreme｜方向性失稳 / 反转级危险

EP01 可以使用。

高强度异常之后不应每集重复。整季应更多利用 Level 1–3，使重力成为世界事实而非每集奇观。

# 10｜Time and gravity are independent axes

`LOCKED`

时间分裂不导致重力分裂，重力分裂也不自动导致时间分裂。

两者都来自共同城市参考网络受损后，各城区为了继续生活而形成的本地稳定机制。

因此允许：

- 两区时间不同但重力过渡相对兼容；
- 两区时间相近但重力接口严重失配；
- 某连接结构受损，而时间/重力都暂时兼容；
- 某接口物理完好，却因公共授权或本地时间无法完成共同动作。

EP06 应成为最明确例子：时间问题处于前景，而重力大体兼容。

# 11｜Islanding / 群岛化

群岛化不只是抽象行政分裂。

它在城市物理层可以被直接看见：

> **某个城区正在失去连接密度。**

例如一个城区原有多条可用桥，随后逐渐变成：

- 结构关闭；
- 单向运行；
- 只传数据；
- 只允许维护；
- 只能在特定重力窗口使用；
- 只承担低容量生命线。

连接数量、能力和共同状态不断减少后，城区即成为事实孤岛。

观众应能通过城市拓扑变化理解“孤岛化”，而不是依赖角色重复解释。

# 12｜Bridge as physical + civic interface

一座桥可以同时拥有六层连接：

1. `C1 Physical` — 人 / 物 / 能量是否真的通过；
2. `C2 Protocol` — 身份 / 状态 / 权限是否能完成协议握手；
3. `C3 Temporal` — 两边是否拥有足以完成共同动作的共同现在；
4. `C4 Factual` — 哪些事实足以让当前动作成立；
5. `C5 Institutional` — 对方是否承认本地公共授权；
6. `C6 Relational` — 主体无法拥有完整对方现实时，是否仍承认对方的独立判断。

桥把这一抽象 Connection Stack 物理化，但并不要求人物讨论“桥是隐喻”。

# 13｜Organic integration rule

世界设定永远不能压过当前剧情动作。

优先级固定：

> **人物需要 / 公共任务 → 前集因果债 → 实际城市空间 → 时间/重力是否改变动作 → 最后才是视觉母题。**

因此：

- EP01 可以让重力成为身体危机，而桥网只通过位置和结尾尺度显露；
- EP03 桥、时间、重力同时存在，但主事件仍是一次不能等待的医疗连接；
- EP04 重力只作为居民习惯背景；
- EP05 时间只作为情感反衬，不转成工程解题；
- EP06 时间是主问题，重力故意保持低权重；
- EP08 桥是公共秩序真实重叠地点，时间/重力只是压力；
- EP10 多轴汇流，因为终局动作本来就是关闭整个旧连接栈。

规则：

> **设定必须从角色正在做的事情里长出来。**

# 14｜Final city-state

EP10 之后，第二新重庆市不会恢复灾前规模。

它会：

- 更小；
- 桥更少；
- 公共能力更低；
- 保留明确伤痕；
- 一部分旧城区永久退出；
- 不再承诺维护所有历史兼容状态。

但剩余城市重新获得：

> **一个可持续的公共“现在”。**

这个结果通过普通生活同步证明，而不是依赖宏大胜利仪式：

- 交通在同一公共时间运行；
- 医院在同一交班框架工作；
- 商业和维护进入同一城市周期；
- 跨区协议可以再次依赖持续共同时间参考。

第二新重庆市没有恢复成原来的自己。

它通过主动结束一部分连接，重新成为一座能够共同生活的城市。
