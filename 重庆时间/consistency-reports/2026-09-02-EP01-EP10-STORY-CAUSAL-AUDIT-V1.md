## 1｜审计标准

每集必须同时通过两组结构：

### Drama shape

> `Cold Open -> Pressure -> Turn -> Payoff/Progress -> End Image -> State Delta`

### Causal shape

> `Trigger -> Goal -> Obstacle -> Choice -> Turn -> Cost`

并逐集回答：

1. 为什么是现在？
2. 为什么必须是这个角色？
3. 如果角色不行动，具体会发生什么？
4. 最明显的替代方案为什么不成立？
5. dominant turn 是否真由角色行动/选择导致？
6. 成功后什么仍然变差、丢失或不可逆？
7. 本集结束留下什么能直接进入下一集的 State Delta？

V4 旧 consistency/no-gap PASS 只证明桥、时间、重力、旧设定替换、人物弧与视觉功能没有明显空缺；**不等于 screenplay causality PASS**。

## 2｜最高优先级冲突：EP01 最新用户修正

当前 V4 仍写：

> 男主进入 302 后确认“里面此刻有人”。

最新用户修正覆盖该实现：

> **男主在最后现场确认中没有发现记录中“仍然活着的人”，因为这是一条过时记录。**

因此以下旧实现全部不得继续作为 active causal fact：

- 男主靠实时信号发现记录中的居民仍活着；
- EP01 的 turn = 救回一个系统漏掉的当前居民；
- EP09 mirror = 回到当年被男主救到的同一 current-resident logic。

保留的季级功能必须换机制补位：

- 系统/历史状态不能自动等于当前现实；
- 男主负责 present physical fact；
- 302 必须成为一个可回访的真实城市节点；
- EP09 仍需形成 `current reality != future preservation obligation` 的反向升级；
- EP01 Extreme Local Gravity Frame / chief physical catch 继续保留，但必须与同一任务因果相连。

推荐修复：

> **过时 occupancy record 把男主带到 302；他确认记录中的人已经不在。就在准备核销记录并完成旧支路 cutover 时，他发现公共模型对 302 当前物理拓扑 / Local Gravity Frame 也同样过时。一个基于旧状态执行的不可逆动作即将对真实结构造成危险。他暂停 cutover，把“当前 302”重新送回公共模型。**

这使 EP01 的问题从“系统没看见一个人”修正为：

> **过去真实过的记录，不能替代现在的现场。**

## 4｜跨集功能遗漏：EP02 人物关系桥

历史对话里曾有一条重要且与 V4 世界观无关的人物功能：

> EP01 抓住男主的女人把自己的身份接入责任链；随后揭示为新科长，并正式给予男主“系统无法完成交叉验证时的有限现场事实确认权”。

V4 EP02 在迁移成主桥 forced-loss 时保留了“男主负责事实 / 科长负责决定”的结果，却弱化了观众看见这套分工**如何建立**的过程。

修复原则：

> 不恢复旧北京设定，只恢复这段人物因果功能；而且必须汇聚到 EP02 主桥 forced-loss，不另开一条独立小故事。

## 5｜全季重复风险

### EP01 / EP03 / EP06

三个都涉及“系统状态不足以完成动作”，必须严格区分：

- EP01：**过去记录不能代替当前现场**；
- EP03：**双方各自 ready 不等于现实连接成立**；
- EP06：**双方各自 local now 有效，不等于跨区 transaction 有共同授权 reference**。

### EP07 / EP09 / EP10

三个都涉及“放弃”，必须严格区分：

- EP07：局部三对象冲突，**第一次战术性放弃健康 Hub**；
- EP09：治理原则第一次作用于真实可继续的 302，**撤回永久特殊维护承诺**；
- EP10：原则落到私人关系与最后健康桥，**执行战略主动收缩**。

## 6｜节拍容量规则

目标每集 2–3 分钟。默认控制：

- Cold Open：10–25 秒
- Pressure / Goal：30–60 秒
- Choice buildup：30–60 秒
- Dominant Turn：20–40 秒
- Payoff / State Delta / End Image：15–30 秒

禁止：

- 一个 2–3 分钟 episode 同时承担两个互不依赖的完整故事；
- 会议、工程解释、哲学说明各自占一段；
- finale 在最后一集才第一次解释决定 AI continuity 的关键规则。

## 7｜本轮修复的统一反事实测试

每集修完后必须能回答：

> **如果把桥/时间/重力这些名词全遮住，只看“谁因为什么做什么，哪个选择改变了结果”，故事还成立吗？**

如果不成立：设定仍在替代剧情。

> **如果角色采用最明显、最便宜的替代方案，剧情是否立刻消失？**

如果是：必须在因果层解释替代方案为何不可行，而不是靠角色忽略。

> **如果删除结尾的视觉奇观，turn 是否仍然成立？**

如果不成立：高潮只是 KV，不是剧情。
