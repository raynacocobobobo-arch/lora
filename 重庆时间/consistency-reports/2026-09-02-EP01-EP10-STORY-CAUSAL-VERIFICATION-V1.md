# 01｜Verification method

Drama Skill gates used:

> `Trigger -> Goal -> Obstacle -> Choice -> Turn -> Cost -> State Delta`

and:

> `Cold Open -> Pressure -> Turn -> Payoff/Progress -> End Image`

Counterfactual gate for every episode:

1. why now?
2. why this character?
3. what happens if no action?
4. why not the obvious cheaper/easier alternative?
5. does a character/public choice actually change the outcome?
6. if bridge/time/gravity jargon is removed, is there still a coherent story?
7. is there exactly one dominant turn?
8. does success still leave cost/debt?
9. does the State Delta directly constrain the next episode?
10. can the story fit approximately 2–3 minutes without requiring a second independent episode?

# 02｜EP01 — stale record / present physical fact

**Trigger:** unresolved disaster-era occupancy record still says one resident remains in 302; a final physical clearance is required before cutover.

**Goal:** close the historical occupancy state and provide execute/abort facts for the public cutover.

**Obstacle:** the recorded resident is not there; after the stale record is closed, the pre-stage reveals that the public model of 302's current physical topology / Local Gravity Frame is also stale.

**Choice:** male uses narrow authority to `HOLD CUTOVER / PRESENT STATE CONFLICT` rather than letting the irreversible step continue.

**Turn:** 302 is not cut over under an incorrect current-state model and is returned to current remap/review.

**Cost:** cutover is delayed; 302 requires remap/repair; male's false belief that irreplaceable field judgment proves his value is reinforced.

**State Delta:** stale resident record is closed; **the recorded resident is not found alive**; 302 remains as a real node and can later return to use; chief physically catches male.

**Counterfactual:** no action -> cutover proceeds using wrong current frame; obvious “hidden survivor” shortcut is explicitly prohibited.

**Runtime:** 2m20–2m40.

**Result:** PASS.

# 03｜EP02 — relationship authority + forced bridge loss

**Trigger:** EP01 HOLD enters responsibility review while a long-rescued Jialing trunk bridge reaches a new propagation threshold.

**Goal:** establish who owns present fact vs public decision, then determine whether the bridge can still be safely rescued.

**Obstacle:** every extra minute still carries real people/services, but ongoing support begins transferring damage into shared structural interfaces.

**Choice:** male reports the physical rescue window has ended; chief owns the stop decision.

**Turn:** the trunk bridge is deliberately stopped/controlled out because continued rescue is no longer the same preservation problem.

**Cost:** a real island boundary forms; medical/service routes become constrained.

**State Delta:** chief formally enters male's responsibility chain; male gets narrow present-fact authority, not broad public power; trunk bridge is lost.

**Obvious alternatives closed:** further load limiting, another short pause-and-repair cycle, “just ten more minutes” all fail because the risk has changed from bridge load to propagation beyond the bridge.

**Runtime:** 2m20–2m40.

**Result:** PASS.

# 04｜EP03 — seven-minute lifeline

**Cost:** a one-off engineering route gains public value and repeat-use pressure.

**State Delta:** familiar lifeline is proven; medical girl benefits; seven-minute shared-now crack is established.

**Obvious alternatives closed:** main bridge is gone; normal detours exceed the medical window or are physically unavailable for public/medical use.

**Runtime:** 2m15–2m35.

# 07｜EP06 — 重庆时间 / one common instant

**Trigger:** a shared Jialing thermal-storage/environment-exchange node reaches a service-transfer deadline today.

**Goal:** perform one load handoff that physically must occur in the same instant for A/B.

**Obstacle:** both sides have valid local public-time authority domains; each rejects the other's local-timestamp signature as a mutually authorized cross-district transaction reference.

**Choice:** use the shared machine's neutral mechanical phase as the one-shot reference; AI maps local-valid windows, male validates physical state, chief authorizes this transfer.

**Turn:** both sides act at one real common instant without creating one permanent common clock.

**Cost:** the city still returns to divergent local nows after the operation.

**State Delta:** one-shot neutral reference works; chief/AI self-limitation relationship turn occurs; time and gravity are clearly independent axes.

**Obvious alternatives closed:** changing clock displays does not change public state/history; chief cannot administratively manufacture mutual reference; sequential valve action triggers real thermal/pressure protection.

**Runtime:** 2m25–2m50.

**Result:** PASS.

# 08｜EP07 — healthy Hub exits

**Trigger:** A/B divergence has reached the point where a healthy shared high-order Hub's design assumption of one coherent city state can no longer be satisfied.

**Goal:** keep A/B alive without continuously forcing either local reality into the other's shared-state model.

**Obstacle:** the Hub is healthy and valuable; its normal operation improves one side while forcing the other into protective degradation.

**Choice:** private AI reframes the cost set; male verifies both local fallbacks; chief retires the healthy shared-control role.

**Cost:** high-level coordination, efficiency, redundancy, and future reconnection capability are permanently reduced.

**State Delta:** all-preservation first locally fails; A/B local-order autonomy increases and directly creates EP08 conditions.

**Obvious alternatives closed:** rotation/time slicing loses more time to stabilization than the opposite side can tolerate; balanced mode leaves both below sustainable margin; simple split cannot independently control shared physical actuators; splitting the physical resources is functionally localizing/ending the original shared Hub role.

**Runtime:** 2m25–2m50.

**Result:** PASS.

# 09｜EP08 — two valid public orders / institutional violence

**Trigger:** EP07 local autonomy means the familiar lifeline now has two complete local public-safety responsibilities; a better-resourced quadruped accompanies public work while degraded-side bridge-maintenance humanoids are temporarily assigned public-order duty.

**Goal:** avoid force-on-force while keeping the life-line usable.

**Obstacle:** neither side recognizes the other's public-force legitimacy in the same shared transition volume.

**Choice:** degraded side voluntarily revokes its own temporary public-force assignment; better side stops advance.

**Turn:** the humanoids must remain in the central/shared transition maintenance zone to keep the degraded-side life-line open; their industrial force capability remains, so the better-side security order reclassifies them as force-capable platforms without mutually recognized public authorization and programmatically disables them.

**Cost:** direct firefight is avoided, but degraded side loses scarce bridge-maintenance capacity and suffers legitimate-looking institutional harm.

**State Delta:** male learns present facts do not generate legitimacy; chief's case-by-case coordination reaches its limit; EP09 governance necessity is opened.

**Obvious alternatives closed:** robots cannot simply walk away at zero cost—withdrawal closes/abandons the degraded side's life-line; they must service central shared transition equipment inside a physical zone both local orders claim responsibility for.

**Runtime:** 2m35–2m55.

**Result:** PASS at architecture level. Exact security-zone geometry/protocol language remains `VALIDATE_LATER`; screenplay must preserve the shared-transition-zone topology rather than accidentally staging the robots safely deep inside one district.

They do not ask the future city to create this non-generalizable private exception; chief authorizes the existing public boundary step by step.

**State Delta:** retained districts regain enough common public now to operate as one city; historical exited fragments remain acknowledged rather than declared unreal.

**Obvious alternatives closed:** copy/reconstruction ≠ continuity (EP05); partial live migration was attempted and movable state transferred (EP09→10); keeping the last stack is a real survival route but violates the universal public boundary created in EP09.

**Runtime:** episode draft currently states 2m45–3m05. **Screenplay hard editing target: 2m45–3m00; 3m05 is not permission to expand the story.** Citywide contraction stays montage/opening state, not a second independent narrative line.

# 13｜Setting-as-causality check

- bridge is causal where transport/shared jurisdiction actually changes the action;
- time is foreground only when public validity/synchronous action depends on it;
- gravity changes body/structure/cutover conditions but does not solve politics;
- 嘉陵江 is a recurring shared civic volume, not a mandatory spectacle;
- AI is a character with access limits/judgment, not an exposition terminal.

If all setting vocabulary is hidden, every episode still has a legible human/public action grammar:

1. stale record vs current fact;
2. stop rescuing before rescue spreads damage;
3. use one temporary route before a medical deadline;
4. allow one ordinary event before a real opportunity closes;
5. choose current meaning after continuity loss is acknowledged;
6. find a neutral reference for one joint transaction;
7. stop a healthy shared function whose operating premise no longer exists;
8. de-escalation inside incompatible legitimate orders produces harm;
9. acknowledge present value without promising permanent exception;
10. refuse a real private exception when the same public boundary has already been applied to others.
