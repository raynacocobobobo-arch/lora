# Decision Log — Oshii Animation Style V1 becomes Seedance-native

- Date: 2026-09-03 13:35 (+08)
- Status: `APPROVED / ACTIVE`
- Scope: visual execution only

## Decision

The user does not want a separate Seedance simplification patch or a parallel Seedance style.

> **《重庆时间》押井守动画风格 V1 itself is now the Seedance production style.**

## What remains stable

- serious cinematic cel-animation environment;
- old-white / gray-white industrial public structures;
- strong structural lighting and hard-edged cel-shadow organization;
- restrained rust-red civic / maintenance accents;
- visible long-term repair history;
- quiet, severe, procedural public-infrastructure mood.

## What is now integrated into V1

- progressive detail reduction with distance;
- midground simplification;
- background reduced to large masses and major light-shadow planes;
- fewer repeated windows, railings, pipes and tiny lights;
- fewer small signs and distant people;
- large stable geometry and key landmarks prioritized over decorative detail;
- major environment masters default to 2.35:1 unless another ratio is required.

## Lighting clarification

The project still allows day, dusk, night and Local Public Time differences.

> **Style consistency means consistent light-shadow organization, not one fixed color temperature.**

Do not flatten lighting for Seedance stability.

## Future generation rule

Before generating a new environment image:

1. read current episode / Spatial Canon;
2. identify the real parent scene and any approved visual master;
3. preserve story/spatial facts;
4. generate directly in Seedance-native Oshii Animation Style V1.

Ask the user only when the unresolved choice changes important story, space, orientation, time-of-day or scene-function facts. Ordinary art-direction choices should proceed from the established visual system without unnecessary confirmation.
