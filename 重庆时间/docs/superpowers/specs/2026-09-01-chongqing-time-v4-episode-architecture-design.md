# 01｜Highest design rule: organic integration

User explicit direction:

> **尽可能有机结合。**

This is a hard design rule.

The series must NOT mechanically insert every world element into every episode.

Do not write episodes as:

> bridge scene + time anomaly scene + gravity anomaly scene + 嘉陵江 establishing shot + theme dialogue.

Instead:

> **each episode has one dominant dramatic function; bridge / time / gravity / 嘉陵江 appear only where the current action naturally requires them.**

Integration hierarchy:

1. character need / public action first;
2. existing cross-episode causal debt second;
3. physical city architecture third;
4. time / gravity anomaly only when it changes the action;
5. visual motif last.

Rule:

> **设定必须从人物正在做的事情里长出来，而不是人物为了展示设定去行动。**

A background element may recur without becoming the episode's subject.

Examples:

- EP04 may show mild gravity drift only through liquid / robot gait, not create a gravity crisis;
- EP06 may foreground time fragmentation while gravity is nearly compatible, proving the two axes are independent;
- EP05 can use opposite local day/night states as emotional counterpoint without turning the wedding into a time-engineering episode;
- 嘉陵江 can recur as urban geography without every episode stopping for an establishing spectacle.

# 02｜Season-level causal architecture

The V4 season retains the strongest existing V3/V4 episode functions and changes the underlying city logic.

Existing strengths retained:

- EP01: 302 reality conflict;
- EP02: forced loss of a rescued connection;
- EP03: one real medical connection achieved through sufficient facts;
- EP04: emergency methods sediment into daily life;
- EP05: Wedding Mirror / continuity break;
- EP06: two valid local times lack one common now;
- EP07: healthy shared Hub must permanently exit;
- EP08: two valid public-security orders produce institutional violence;
- EP09: minimum common reality becomes public governance;
- EP10: same boundary reaches male / private-AI continuity.

V4 rebinds these to one physical and thematic spine:

> **桥网 → 连接减少 → 临时桥成功 → 临时桥日常化 → 时间分叉可见 → 共享能力退出 → 地方秩序在桥上对撞 → 公共边界制度化 → 疏散并主动断桥。**

The season's hidden four-layer connection structure:

> **桥 = spatial connection**
>
> **time = shared now**
>
> **gravity = shared physical reference**
>
> **protocol / public order = shared civic reality**

Character mirror:

> **male ↔ private AI = continuity between fragmented worlds.**

# 03｜EP01 — 302 / first physical fracture

## Existing function retained

Unified system cannot confirm a valid present resident in 302.

Male finds real-time interactive evidence plus independent onsite fact, pauses a public action still operating on an invalid “empty” premise.

Female chief physically saves him during the gravity event.

## V4 physical integration

302 is located in an older district near / along the Jialing River megastructure and its service layers.

The audience does not need a geography lecture.

The district simply feels like one node inside a much larger bridge-linked city.

## Time

Only seed-level evidence.

Possible background mismatches:

- one public clock slightly different from another;
- local shift schedule lag;
- interface timestamp mismatch.

Do NOT explain the season's time problem in EP01.

## Gravity

EP01 remains the season's most extreme early gravity event.

Cause becomes V4-consistent:

> local artificial-gravity reference / bridge-adjacent gravity handoff instability after the meteor fragmentation.

This is no longer a one-off mystery mechanism.

## Jialing River

End / reveal may widen from immediate danger into the first strong perception of:

> layered internal bridges + bounded megastructure + distant Earth beyond the engineered cavity.

Function:

> first body-level proof that this city is not built on one continuous ground plane.

## Episode progression

> **System state can miss present physical reality.**

Debt created:

- 302 returns in EP09;
- gravity returns in lower-intensity forms;
- bridge-network geography becomes increasingly legible;
- male's false belief that fractured reality proves his usefulness begins.

# 04｜EP02 — first irreversible bridge loss

## Existing function retained

A cross-district structure has been supported and rescued for a long time after impact.

Continuing to save it now threatens wider structure.

Male confirms the remaining safe window.

Female chief decides when rescue must stop.

This is forced loss, not strategic contraction.

## V4 bridge lock

The structure is now concretely a **major Jialing River city bridge / trunk connector family**.

It is one important bridge among many, not a unique plot device.

It carries combinations of:

- evacuation;
- logistics;
- ordinary passage;
- services;
- city-state continuity.

## Gravity integration

Gravity mismatch increases structural complexity:

- bridge loads are no longer distributed exactly as pre-impact;
- two district gravity frames have drifted;
- transition systems are operating under temporary correction;
- support history accumulates asymmetrical stress.

Gravity is a contributor, not the sole cause.

## Time

Still mostly shared enough for emergency coordination.

Only operational mismatch seeds may appear.

## Ending

Bridge separation / loss creates a physically visible new island boundary.

Both sides remain lit and continue local operation.

Key emotion:

> **我们已经尽量保，还是没能全部保回来。**

Debt:

> loss of this main route directly creates EP03's urgent need for a low-capacity substitute.

# 05｜EP03 — seven minutes / the first real lifeline

## Existing function retained

A medical transfer / medicine delivery cannot wait for complete system restoration.

Both local systems can show protocol completion, yet real physical passage still does not align.

Male identifies the real window; female chief authorizes only this action; medicine crosses.

## Bridge integration

The action uses a maintenance / engineering path through the Jialing River network.

This becomes the season's familiar lifeline.

At first it is:

> **low-capacity / temporary / ugly / inconvenient / not designed as a normal public route.**

Do not make it immediately heroic or iconic.

Its importance grows because it works.

## Time integration

The existing seven-minute mismatch becomes the first explicit observable crack in shared “now.”

Important:

> not merely “clock A is seven minutes fast.”

The two local systems each map their valid process / local-history state to the physical interface differently, creating a real seven-minute usable-window offset.

This keeps room for EP06's larger political meaning.

## Gravity integration

Use Level 2 anomaly:

- stretcher / cargo must be strapped;
- people hold rails;
- industrial robots adapt gait;
- crossing procedure accounts for gravity transition.

Gravity increases physical tension but does not cause the seven-minute time offset.

## Long-term debt

Because the bridge actually saves someone:

> **it cannot remain “one-time only” socially.**

It will naturally be used again.

This creates EP04 and eventually EP08.

# 06｜EP04 — temporary infrastructure becomes ordinary life

## Existing function retained

This is the first breathing / daily-life episode.

The core move remains:

> emergency handling methods begin to carry non-emergency life.

Old cinema receives a narrow “tonight only” approval; male and female chief remain after work and actually share the life they helped preserve.

## Jialing River integration

More of the episode may occur in / around a Jialing River public layer:

- old civic corridor;
- transfer platforms;
- small businesses;
- access to the repeated EP03 route;
- ordinary people living beside the huge structural cavity.

Do not turn the whole episode into spectacle.

嘉陵江 should feel like a place people commute through, not a tourist reveal.

## Bridge-life sediment

The EP03 lifeline now shows:

- recurring schedule;
- limited capacity;
- maintenance routine;
- basic queue / priority behavior;
- service workers who already know what to do.

No one declares it a border.

It is simply becoming infrastructure.

## Time

Different local day/night rhythms become perceptible but ordinary.

Male may cross from one district's evening into another district's different civic lighting cycle without exposition.

## Gravity

Only background evidence:

- liquid surface slightly tilted;
- suspended signage not perfectly vertical;
- robot gait correction;
- residents instinctively use certain handrails.

No gravity crisis.

## Episode progression

> **城市不是只要活着；它还要允许生活继续。**

This episode gives emotional value to the connections that later must be severed.

# 07｜EP05 — Wedding Mirror / private time continuity

## Existing function retained

Wedding Mirror remains structurally intact:

- start from EP02 public scene and follow the ordinary bride;
- brief T0 impact-day private consequence;
- groom already lost;
- bride truly continues living;
- EP03 success influences later life choices;
- later isolation interrupts her continuity;
- records/data can return;
- wedding reveals both bride and groom are reconstructed personalities;
- private AI remains the positive continuity counter-example.

## Remove snow / winter completely

Delete:

- artificial snow as seasonal spine;
- real local snow payoff;
- snow bridge into EP06;
- winter-state dramatic logic.

## Time integration

Replace seasonal contrast with urban time contrast.

At the wedding:

- ceremony hall may be in one local night state;
- across Jialing River / another district may still be in daylight or dusk;
- public clocks / light cycles disagree.

The episode should NOT stop to explain this.

It becomes an emotional visual echo:

> reconstructed people attempt to complete one delayed future while the city itself no longer shares one present.

## Bridge integration

T0 and post-impact life history should naturally involve bridge availability:

- bride and groom once depended on ordinary cross-district connection;
- impact destroys / closes that future route;
- later EP03-style low-capacity reconnection makes relocation / new life choices possible;
- later islanding makes that continuity disappear again.

Do not reduce her fate to “the bridge killed her.”

The bridge network shapes available life paths; it is not a melodramatic murder device.

## Episode progression

> **representation / record / restored form do not equal uninterrupted subject continuity.**

This becomes critical for the private AI in EP10.

# 08｜EP06 — the title episode / Chongqing Time

## Existing function retained

Two regions each have valid local time and operating rhythms.

A real shared infrastructure action must occur at the same physical instant.

Neither side's clock can simply be elevated into the city's truth.

Male + private AI + female chief must rely on a mutually constraining physical reference and narrow authority to perform one synchronized action.

## Remove winter from the mechanism

Delete:

- dual winter states;
- seasonal mismatch;
- snow-clearing imagery;
- unified winter language.

Replace with:

> **day / dusk / night fragmentation inside engineered urban environments.**

## Visual / spatial principle

A bridge / interface / shared municipal node may visibly connect:

- one side in civic day mode;
- one side in civic night mode.

No visible sky is required.

The contradiction is expressed through:

- lighting;
- traffic density;
- shift behavior;
- public-service mode;
- opening / closing cycles;
- clocks.

## Gravity independence rule

EP06 should deliberately keep gravity mostly compatible.

Purpose:

> prove to the audience that time fragmentation and gravity fragmentation are separate axes.

## Episode progression

EP03:

> protocol handshake complete ≠ reality connected.

EP06:

> local now A + local now B ≠ common now.

This is the episode where the title **《重庆时间》** becomes fully legible.

# 09｜EP07 — healthy Hub exits

## Existing function retained

A, B and shared Hub cannot all remain at current capability.

Hub is healthy, valuable and working.

Private AI identifies that the hidden assumption “Hub must be preserved” can be changed.

Male confirms A/B can survive in degraded state without Hub.

Female chief approves permanent Hub exit.

## Bridge-network integration

Hub is not an isolated abstract server hall.

It is a shared municipal node inside the bridge-network:

- feeds multiple districts;
- coordinates services;
- supports bridge-linked capabilities;
- may contribute to gravity / routing / environment / compute coordination.

Its exact service mix remains to be engineered later.

Important:

> the audience should understand its shared value through visible district response, not screens explaining everything.

## Time / gravity

Present but secondary.

A/B may already live under different local time states.

Hub exit may force both to rely more heavily on local gravity management and local service schedules.

## Episode progression

First local admission:

> **全部保存失败。**

This is the conceptual bridge from forced loss (EP02) to active future contraction (EP09/10).

# 10｜EP08 — armed bridge standoff

## Existing function retained

Two fully rational local public-security systems overlap without a shared public authorization layer.

A disarmament action prevents direct crossfire but causes one side's platforms to become reasonably reclassified as uncontrolled armed systems, triggering programmatic destruction.

No villain. No rogue AI. No simple bug.

## Location lock

Do NOT stage as a generic ground checkpoint.

The confrontation occurs on / around the same bridge-life family born from EP03 and normalized in EP04.

It is now:

> **a suspended inter-district public bridge / interface over the Jialing River structural cavity.**

This gives the political conflict a physical truth:

> two local orders literally meet on one remaining connection.

## Resource asymmetry lock

One side:

> **one medium four-legged public-security robot / platform.**

Other degraded island side:

> **multiple ordinary industrial humanoid robots repurposed / coordinated to maintain order because dedicated resources are scarce.**

Important:

- no wheeled vehicles;
- no generic military mecha aesthetics;
- no “medical transfer corridor” sign;
- the bridge remains a real public route;
- degraded side visibly has less specialized capability;
- quantity difference reflects resource reality, not moral coding.

## Time

Different public times worsen operational mismatch:

- maintenance window;
- shift status;
- security cycle;
- service priority.

But time synchronization cannot answer:

> who legitimately holds public force here?

## Gravity

Bridge transition contains Level 1–2 gravity mismatch.

This strengthens embodiment without taking over the scene.

## Episode progression

> **事实正确 ≠ 公共正当性自动成立。**

And:

> **地方完整保全可以互相伤害。**

This creates the political necessity of EP09.

# 11｜EP09 — 302 as the first future-boundary test

## Existing function retained

Female chief proposes minimum common reality after EP08.

Higher public layer debates and authorizes limited trial.

Chief herself chooses 302.

Male returns onsite.

302 is real, inhabited, safe and technically continuable.

Private AI accepts the facts but still reaches the conclusion that continued reality does not automatically require permanent future exception.

## V4 maintenance-cost clarification

302's future cost is no longer an abstract “special maintenance condition.”

It depends on a package such as:

- old local-time compatibility;
- dedicated Local Gravity Frame / transition support;
- special bridge access;
- data / energy / environmental compatibility;
- legacy protocol mapping.

Exact engineering remains TBD, but the public logic is concrete:

> **to promise 302 permanent inclusion, future Chongqing must permanently preserve a special connection stack that cannot be generalized to every surviving fragment.**

## Bridge / time / gravity integration

This is the first episode where all three become governance rather than spectacle:

- bridge = permanent access obligation;
- time = permanent legacy local-now compatibility;
- gravity = permanent special physical-reference support.

## Episode progression

EP01:

> **真实存在不能因为系统没确认而被抹掉。**

EP09:

> **真实存在也不自动获得整座城市永久维持专属例外的承诺。**

This is the cleanest 302 closure before EP10.

# 12｜EP10 — evacuation, bridge-cut, abandoned district

## Existing function retained

Citywide execution of minimum common reality.

Male onsite verifies present physical fact.

Legacy public/system AI lacks sufficient reliable present-state mapping.

Private AI can temporarily fill the missing relay / mapping function.

Female chief gives narrow public authorization.

Male and private AI genuinely search for a path that preserves her continuity.

A real preservation route exists.

## V4 physical form

The “legacy branch” becomes physically legible as:

> **a still-functioning old district / city fragment and the final bridge-service stack that keeps it inside shared Chongqing.**

EP10 action is city-scale:

> **evacuate → verify → close services → disconnect bridges → release gravity transition → end legacy compatibility → mechanically separate / abandon district.**

Not every bridge needs to be destroyed.

Different bridges may:

- retract;
- unlock;
- isolate;
- lose service function;
- become permanently closed;
- physically separate.

## Jialing River final state

嘉陵江 becomes the season's largest spatial payoff.

Early season:

> many active bridges.

EP10:

> bridge density visibly collapses as the city contracts.

The cavity feels emptier, not bigger.

The distant Earth remains a stable external reference.

## The familiar final bridge

The final important bridge should be one the audience already knows through the EP03→EP04→EP08 chain.

Its history:

> temporary maintenance connection → saved a patient → repeated lifeline → ordinary infrastructure → public-order collision point → evacuation lifeline → final connection.

Therefore the final cut is not a random spectacle.

It ends a relationship the audience has watched become valuable.

## The Bridge influence: A + small B

Do not copy the 1969 film's plot, dialogue or explosive staging.

Absorb the dramatic principle:

> **the hardest connection to end is one that still works and has proved its value.**

And:

> **those who understand the connection best may also be the ones most capable of ending it safely.**

Private AI, because she has continuous cross-fragment history, may provide the safest shutdown sequence:

- which services exit first;
- which state mappings must be preserved until last;
- when gravity transition can unload;
- when data / energy can disconnect;
- when final mechanical separation is safe.

Male verifies reality.

Chief authorizes each public step.

This keeps the final action triadic.

## Final bridge condition

Critical V4 reversal:

> **the final bridge is technically healthy.**

Possible status:

> STRUCTURE: NORMAL
>
> TRANSIT: AVAILABLE
>
> GRAVITY TRANSITION: AVAILABLE

This contrasts with EP02.

EP02:

> they try to save a failing bridge and cannot.

EP10:

> they can keep a working bridge, but choose not to preserve the incompatible future condition it carries.

This is the season's mature Preservation Paradox.

## Private AI survival alternative

Concrete preservation route:

> **keep the last legacy district / compatibility / bridge stack active.**

Then:

- same continuous private AI can survive;
- old local time remains;
- old gravity reference remains;
- legacy compatibility remains;
- future Chongqing must permanently carry one unresolved fragmentation condition.

The route is real.

The AI wants to survive and helps search for it.

Only after confirming the real city-level cost does the final choice exist.

## Final city image

Remove snow completely.

Remaining Chongqing is:

- smaller;
- lower-capability;
- visibly wounded;
- connected by fewer bridges;
- but finally able to share one public now.

Ordinary synchronized life proves the result:

- a late train arrives;
- nurses change shift;
- shops close;
- civic lighting enters one night cycle;
- clocks in separated retained districts read the same time.

Candidate recurring value:

> **22:17 / 22:17 / 22:17**

Exact final clock time remains a screenplay decision, not Canon yet.

An abandoned district does not display a competing public time.

It is no longer part of the shared city.

Final meaning:

> **重庆没有恢复原样，但重新拥有了“重庆时间”。**

# 14｜Cross-episode progression locks

## Bridge progression

> network background → failing trunk → temporary lifeline → daily infrastructure → life-path dependency → synchronized interface → shared-node dependency → armed boundary → future-maintenance obligation → deliberate bridge cut.

## Time progression

> seed mismatch → operational drift → seven-minute visible crack → ordinary divergent rhythm → emotional day/night counterpoint → explicit loss of common now → local normalization → authorization mismatch intensified by local time → future-common-time governance → one public now restored.

## Gravity progression

> extreme body danger → structural loading → crossing constraint → daily adaptation → background / absent as focus → deliberately independent from time → degraded local service → embodied bridge boundary → permanent support obligation → final transition shutdown.

## Preservation Paradox progression

> system misses reality → cannot save every failing connection → enough reality can save one action → exceptions become life → form can return without continuity → difference can cooperate once → healthy value may need to exit → complete local protection can cause violence → real does not mean permanent exception → working connection may still need to be ended.
