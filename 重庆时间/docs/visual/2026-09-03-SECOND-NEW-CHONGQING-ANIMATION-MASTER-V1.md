# 02｜Locked macro composition

Preserve in future exterior derivatives unless the user explicitly approves a new structural state:

- full ring city visible in one frame;
- slightly elevated three-quarter exterior view;
- central engineered asteroid core clearly visible;
- limited number of heavy radial structural/service links;
- thick modular outer ring-city body;
- one major historical impact / repair sector;
- old off-white / gray structural masses;
- selective rust-red repair / identification bands;
- very small, distant Earth / deep-space relation;
- no hollow-center reading;
- no centrifugal-gravity visual logic.

The central asteroid is part of the city's original construction history and is not the T0 impactor.

---

# 03｜Locked visual treatment

The master is intentionally simplified for animation:

- strong black negative space;
- graphic manga-like architecture lines;
- large old-white surfaces;
- 2–3 hard value tiers;
- sparse rust red;
- reduced panel / pipe density;
- repair history shown through large shapes instead of debris noise;
- Seedance-friendly stable silhouette.

Future exterior images should not increase micro-detail merely to look more realistic.

# 05｜Impact / repair landmark

The historical impact sector must remain easy to recognize across exterior shots.

Read it as:

> old severe damage → emergency closure → structural reinforcement → long-term civic maintenance.

Visual signals:

- missing / ruptured outer shell in large readable areas;
- dark exposed framework;
- rust-red reinforcement and replacement plates;
- mismatched repair generations;
- stabilized / operational state.

Do not turn it into an active battle or fresh explosion.
