# 《重庆时间》女科长 FACE LOCK V2 — 修脸执行规范

- Updated: 2026-09-04
- Status: `ACTIVE / TASK SPEC`
- Character: Female Chief / 女科长
- Purpose: 把当前“平均化主角脸”修成稳定、可识别、可长期复用的主角脸。
- Important: **这是资产修订任务，不是重新设计角色。**

---

# 01｜任务目标

基于当前已确认的女科长近景 + 全身资产，只修脸，不重做人。

目标：

> **保持当前人物 80–85% 的身份连续性，只用约 15–20% 的结构调整建立可辨认的主角脸。**

预期：第一眼仍是当前女科长；第二眼能记住；未来换服装、镜头、光线仍有稳定识别能力；不依赖伤疤、痣、异色瞳、发色等外部符号。

---

# 02｜问题诊断

当前问题不是“不漂亮”，而是“平均”：

1. 标准椭圆脸，轮廓转折太少；
2. 眼睛偏圆、虹膜偏大，容易幼态；
3. 眉眼距离偏松，判断力不足；
4. 鼻梁体积表达弱；
5. 嘴偏小，表情容量不足；
6. 下颌过顺；
7. 左右过度美容式对称；
8. 面部低对比进一步压平五官。

当前更接近“漂亮、安静、温柔的动画女性 NPC”，目标是“漂亮、克制、清醒、有判断力、有一点疲惫与距离的《重庆时间》女主角”。

---

# 03｜优先级

## P0 — 绝对锁定

人物身份、头型、发际线、脸宽大关系、五官基本落点、视觉年龄、低马尾、宇航服、身体比例、背景空间、当前动画电影帧画风。

## P1 — 必须修改

1. 眼裂比例；
2. 虹膜大小；
3. 上下眼睑结构；
4. 眉毛厚度 / 眉眼关系；
5. 鼻根—鼻梁体积；
6. 嘴部横向比例；
7. 下颌轻微转折；
8. 默认注视与微表情。

## P2 — 可微调

颧骨受光、极轻微自然左右不对称、唇部明暗、眼窝层次。

---

# 04｜量化修脸建议

以下是视觉执行尺度，不是机械像素变形要求。

| 项目 | 当前问题 | V2 方向 |
|---|---|---|
| 眼裂 | 偏圆 | 横向 +5–8% |
| 外眼角 | 太中性 | 轻微上扬 1–2° |
| 上眼睑 | 圆弧 | 更平、更利落 |
| 下眼睑 | 圆润 | 减少圆弧 |
| 虹膜 | 偏大 | 视觉尺寸 -8–12% |
| 眉毛 | 细淡 | 略粗，自然，不攻击 |
| 眉眼距 | 偏松 | 收紧约 3–5% |
| 鼻梁 | 体积弱 | 加强鼻根—鼻梁结构 |
| 嘴宽 | 偏小 | 横向 +5–8% |
| 下颌 | 太顺 | 增加轻微转折，不加宽 |
| 对称性 | 过于标准 | 允许极轻微自然差异 |

# 05｜表情锁

默认不是“冷脸”，而是：

> **低表情幅度 + 高注视感。**

必须读出：她在观察；理解很快；不需要用表情证明权威；有一点疲惫但没有失控；并不凶。

禁止瞪眼、皱眉装强、嘴角刻意下压、性感挑逗、商务微笑、空洞娃娃感。

---

# 06｜光影锁

沿用当前低调方向性硬光：

- 亮侧约 `-1 EV`；
- 暗侧约 `-2 EV`；
- 一侧眼窝可进入暗部；
- 鼻影明确；
- 不做美容式正面补光。

必须保留：

> **额头 → 眉骨 → 眼窝 → 鼻梁 → 鼻翼 → 唇 → 下巴。**

禁止把克制误做成整张脸灰掉、眼睛无结构、鼻子消失、嘴和皮肤没有层次。

## Stage 1 — 近景修脸

只有用户明确要求开始后：

- 使用原始近景图作为绝对身份母图；

- 改动限制在 15–20%。

## Stage 2 — 近景通过后更新全身

用户确认近景脸通过后：

- 将通过脸升级为新 Face Master；

- 只统一脸部身份；
- 全身比例、服装、姿态、背景保持不变。

## Stage 3 — 长期身份锁

全身通过后再制作：正面近景、左 45°、右 45°，必要时正侧面。不得跳过 Stage 1 验收直接批量扩图。
